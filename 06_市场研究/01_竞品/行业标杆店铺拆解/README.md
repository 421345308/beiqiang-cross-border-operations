## 凯顺：店铺定位与商品结构

本轮[凯顺首页](https://kaisuntd.en.alibaba.com/)可见公司名Xiamen Kaisun Trading Co., Ltd.、`Multispecialty Supplier`、7年、福建、主营Shoes及SGS核验标识。首页自述经验和合作品牌不等于我们核实过合作关系或自产能力；不沿用旧报告将其认定为制造商、矫形鞋专店或贝强能力参照的说法。

已采集目录包含跑鞋、球鞋、童鞋、户外鞋、赤足概念鞋、乐福鞋和鞋底部件。按标题规则初筛：赤足/极简141、休闲及其他123、球类79、跑步72、童鞋47、针织套脚/乐福28、户外21、部件15、水鞋11、拖鞋5、正装2。分类有优先规则，针织赤足鞋先归赤足；这不是平台类目，也不是材质核验。

针对贝强针织、套脚、休闲方向，再筛成人且标题命中针织/套脚/袜套/乐福的33条，其中20条显示sold。此池只用于缩小详情核验范围，部分鞋图有系带或搭扣，不能仅凭标题认定与A507同结构。

以下统计分母均为已采集544条；各词可同时出现，不相加为100%。

标题字符中位数122，316条超过120字符。这是可读性观察，未认定违反平台限制。长标题可能覆盖多个意图，也可能让采购商难以识别；没有对照数据证明越长越有效。

建议标题组织为：**真实鞋型与闭合方式 → 最相关使用需求/结构 → 有证据的定制采购信息 → 款号**。例如A507突出Knit、Slip-On、Walking、Easy On and Off；A116突出Knit、Lace-Up、Daily Walking。不要把Barefoot、Wide、Hands Free、Anti-Slip、Medical或竞品品牌合作词移植到无证据款。

## 采购门槛应分开拆

344条明确写300 pairs起订，占63.2%；同时62条写2 pairs，5条写1 pair。另有pieces及bags字段，尚未详情核计价单位。该混合结构支持“分别研究小量试单入口和批量定制入口”的假设，但不能证明其库存、样品政策或履约能力。

对贝强后续核验应问：这一条是现有款批发还是定制开发？卡片MOQ如何对应详情数量档？标价适用什么数量、颜色、材料和包装？样品与生产订单如何衔接？先把本店现行SOP及单款条件讲清，不据同行降价或改MOQ。
