每项研究保留来源URL、采集日、报告窗口、原件和观察/推断。累计销量、不同市场/币种、商品与供应商口径不能混算；没有统计周期不自行填月销量。旧报告用于恢复当时依据，涉及当前价格、排名、规则或需求时重新核验。

具体竞品使用 `competitor-research-firecrawl`，需求与方向判断使用 `market-demand-research`；按本次实际需要选择。结论链接到原产品、页面、内容或客户问题，不另外维护产品事实或长期优先级。非鞋类视频叙事参考回内容项目，不混入鞋类市场库。
