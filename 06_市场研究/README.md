# 市场研究总入口

本目录保存竞品、关键词、买家需求和市场方向研究。研究结论必须注明采集日期、来源和适用任务；旧报告用于历史参考，不能直接当作当前平台价格、排名、热度或买家需求。

非鞋类的 AI 叙事、镜头和制作方法参考不属于本目录，统一放在 `../05_内容与视频/03_通用AI视频实验/04_参考视频研究/`。

## 研究如何进入经营闭环

1. 从明确决策开始：选品、标题关键词、主图、落地页、视频选题、买家名单或P4P测试。
2. 记录研究日期、平台、URL和可观察事实，把推断与事实分开。
3. 只把竞品做法用于发现买家意图和内容结构，不复制其材料、认证、MOQ、价格、产能或销量为贝强事实。
4. 输出必须链接到具体SKU、页面、活动或下一动作；没有执行去向的泛研究降为低优先级。
5. 涉及当前市场需求时使用`market-demand-research`；具体竞品页面使用`competitor-research-firecrawl`，不可用时保持相同证据结构。
