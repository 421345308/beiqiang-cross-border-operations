# 贝强跨境 B2B 经营系统

本工作区按“产品事实 → 渠道发布 → 内容与获客 → 询盘跟进 → 数据复盘”的经营链路组织，用于泉州贝强鞋业服饰有限公司的 Alibaba.com、独立站、主动获客、客户跟进和 B2B 内容运营。

## 开始工作

1. 阅读 [`00_总控台/当前状态.md`](00_总控台/当前状态.md)，确认正在推进的主轴和阻塞项。
2. 阅读 [`00_总控台/产品经营主表.md`](00_总控台/产品经营主表.md)，选择下一款需要推进的 SKU。
3. 阅读 [`AGENTS.md`](AGENTS.md)，遵守贝强定位、证据和报价边界。
4. 进入对应经营环节工作，不在根目录创建临时交付物。

## 经营链路目录

| 目录 | 角色 |

| `04_客户开发/` | 线索、目标名单、邮件、发送记录、客户项目、产品册 |
| `05_内容与视频/` | 贝强商品视频、TikTok 运营、独立的通用 AI 视频实验 |
| `06_市场研究/` | 竞品、关键词和市场研究 |
| `07_知识库与Skills/` | 运营知识、模板及全局 Skills 清单 |
| `08_工具链/` | 业务脚本、视频工具、网站运行时、MCP 与 Workctl |

| `99_临时区/` | 可再生成的短期工作文件 |

## 版本管理边界

- 根仓库只管理总控文件、SOP、运营记录、主数据、文本交付物和自研脚本。
- 商品原图、可发布图片、视频、压缩包、运行时、依赖和构建缓存保留在本地，不进入普通 Git 历史。
- `03_独立站/03_网站源码/` 是独立 Git 仓库，继续使用 `421345308/beiqiang-footwear-site`，不纳入根仓库。
- 客户和线索资料只能进入私有仓库，不得公开。

## 内容边界

所有对外内容必须面向进口商、批发商、Amazon/TikTok 卖家、采购代理和品牌买家。未经确认不得承诺材料、鞋底、尺码、MOQ、交期、库存、认证、最终价格或医疗功效。
