# 国际站竞品公开数据分析

当前使用对象：[行业标杆店铺拆解](../../06_市场研究/01_竞品/行业标杆店铺拆解/README.md)。输入是浏览器可见商品卡的正式留存，不请求账户接口、不绕过验证、不假定成交周期。

`alibaba_competitor_analysis.py <原始JSON> <数据输出目录>`：标准库清洗标题、MOQ原单位、公开成交显示、重复ID及意图分类；保留缺失，不填零。若输出目录上一级已有主图实看和资产清单，则复用观察记录及本地原图。分类只是标题筛选，不证明实物事实。原始JSON的pages须包含page、observed_at、cards；cards包含title、url、text、price_text和image。

`alibaba_competitor_workbook.mjs [研究目录] [预览目录]`：用Codex已配置的工作区Node运行时和artifact-tool，从清洗数据、候选店铺和主图观察生成一个四页工作簿。默认研究目录为当前项目的`06_市场研究/01_竞品/行业标杆店铺拆解`，预览放`99_临时区/行业标杆研究`；商品采集日期换算为北京时间。先通过应用查询当前依赖路径，不继承历史环境的凭证或API配置。

抓取原件不可由清洗结果反向伪造。补齐页面后必须同步原始status、missing_pages和覆盖说明；当前分析阶段为544条、34/55页，不是全店完成。工作簿和原图留本地，公开字段及工具代码可按工作台已授权范围同步。
