# 贝强本地工作台

当前入口：[打开工作台](http://127.0.0.1:8765/)。服务未启动时双击[启动工作台.cmd](启动工作台.cmd)。

**2026-10-31产品方向已重定：当前界面是技术试验，整个运营系统需要重构。** 新产品围绕商品、客户、渠道、创作及其工作与成果组织，资料和Agent共用；项目只用于复杂目标，画布只是创作视图。全产品取舍、参考与交付顺序只读[PRODUCT.md](PRODUCT.md)。

## 当前实际可用

| 能力 | 实际范围 |
| --- | --- |
| 本机Agent | 现有Codex登录、Sol运行及记录；当前仅能对选中单篇文档提出精确替换，工具与搜索被禁用，尚不能承担通用经营委托 |
| 本地画布试验 | 文本/镜头/素材卡片保存、媒体预览与播放；交互将被项目工作区替换 |
| LibTV | 官方CLI读取工作区/画布/节点、创建画布与文本；未接完整生成和成果管理 |
| 国际站 | 商品和订单查询；标题差异/确认提交/回读/同步入口，实际提交只在模拟环境验收；历史经营档案读取 |
| 网站 | 原在线询盘与私有后台继续运行，尚未接入本地客户与工作视图 |

**还没有做成的核心**：跨业务查找与关系、可处理的经营首页、客户/商品内完整工作、真正调用工具的Agent、成果直接回业务、自动更新。画布改好也不能代替这些能力。

## 当前任务

统筹负责全产品取舍与使用验收，Sol按业务服务、界面、执行器/连接器分工。停止接口菜单扩建及只优先重做视频的顺序。

第一包：统一入口、查找、商品/客户详情及真实Agent执行，走通“真实商品→可编辑选款资料”和“真实询盘→有依据的回复草稿→原业务接续”。随后贯通渠道修改与创作、持续更新及反馈；具体路线只见PRODUCT。当前完成的是方案修订，网页尚未重构。

## 运行与数据

- 本地Python服务在127.0.0.1:8765；SQLite位于`.local/runs.sqlite3`。项目文件是事实来源，数据库保存运行、草稿和操作状态。
- 原始商品/视频资料不因重构迁走；部分素材经项目Junction访问E盘。新界面索引原件，避免重复素材库。
- 官方CLI和OpenAPI使用原登录及配置，凭证不进入项目或浏览器页面。当前未新增付费服务。
- 已有新加坡主机继续提供网站统一后端、PostgreSQL及8443入口；原VPS代理不变。云端执行器关闭，当前不推进设备登录。本机关机不执行本地任务，官网仍收询盘。
- 私有原件、数据库、请求/回读在`.local/`；可重建界面验收在`99_临时区/工作台应用验收/`，不进入公开Git。

## 代码接续

| 位置 | 职责 / 重构处理 |
| --- | --- |
| `server.py` | 复用HTTP与CLI运行记录；替换单文档提案限制，业务动作供界面和Agent共用 |
| `workspaces.py` | 现有草稿与具名连接器调用；旧画布暂停扩展，待新项目模型接替 |
| `media_assets.py` | 项目媒体读取、Range播放；作为素材库预览底座复用 |
| `product_changes.py` | 标题差异、提交、回读与原商品档案同步；保持内部能力，停止加独立主界面 |
| `connectors/` | Alibaba、LibTV等适配；不重新实现官方客户端 |
| `web/` | 当前试验界面；按商品、客户、渠道及创作重组，替代接口式菜单 |
| `cloud-runner/` | 已有云执行代码与部署说明；当前非主推进方向 |

当前验证范围：本机Sol真实运行、LibTV非生成读写、国际站只读准备、媒体实际播放、模拟标题提交与本地同步。真实平台标题发布、公开页面与派生索引的完整验收尚未完成；旧记录仍在原回执中。

运行相关测试使用`python -m unittest discover -p 'tests*.py'`，连接器各自测试在其目录；仅在对应代码改变时运行相关验证。界面交付必须走真实项目使用流程，不能用测试通过替代好用。

此前部署经过与详细测试日志已从当前入口移除，沿Git历史和原回执追溯；没有移动或删除数据库、客户记录、素材或其他任务文件。
