# 贝强本地工作台

入口：[打开工作台](http://127.0.0.1:8765/)。未启动时双击[启动工作台.cmd](启动工作台.cmd)。

2026-10-31已实现整体重构的第一包：总览、商品、客户、资料查找、对象内Agent与可编辑成果。长期路线及后续范围见[PRODUCT.md](PRODUCT.md)。本次不是全部运营系统交付。

## 现在怎样使用

1. 从商品或客户进入，搜索款号、公司或需求；查看原资料、关联素材及已有成果。
2. 在右侧说明需要的结果，或使用“整理选款资料”“准备回复草稿”。本机Sol通过工作台只读业务工具读取当前对象、关联证据与适用规则，生成本地成果。
3. 在同一页面审阅、编辑并保存；刷新后继续。跨对象任务可以并行，总览显示实际运行与最近成果，不随机推荐产品。

当前读取259款共用产品，关联供应来源、图片和国际站记录；客户接入11个本地CRM/项目对象及网站原询盘。网站当前读取1条非内部测试记录，排除5条测试；该数量随原站变化，不代表全部历史客户已导入。网站在页面打开时按120秒缓存期限后台更新，也可手动刷新，显示实际更新时间与错误。

## 验收与实际边界

- 已实际运行商品资料任务、网站询盘回复草稿任务，核对业务工具的原件读取记录、成果文件及对象归属。
- 已在真实页面审阅修改商品成果，保存、刷新并回读；发现旧尺码计划与最新正式档案冲突后已纠正该草稿。工具默认优先当前档案，历史证据按需搜索；AI成果仍需要内容审阅。
- 已验证HTTP与文件回写、失败/取消/重启中断、网站测试记录排除，以及前端异步导航、保存和编辑不被轮询覆盖。早期未读到依据的草稿保留并标为待补依据，不算成功交付。
- 当前Agent工作范围是资料读取、分析及草稿制作；本轮没有发送邮件、发布商品或付费生成。渠道修改、完整创作工作区、报价订单与自动经营反馈仍属后续包。
- “资料”目前搜索已接商品/客户及其关联内容，不是全电脑文件搜索；既有桌面聊天不会自动全部出现在本地任务列表。

## 唯一来源与运行

产品JSON、供应来源、媒体原件、CRM和项目文档仍在原处。网站询盘通过原后端只读接口访问，仅内存缓存，未再落一套询盘快照。成果正文位于原业务的私有`.local/成果/`或`.local/网站询盘/`，SQLite只存索引、任务和关联；编辑保留上一版`.prev.md`。

本地服务在127.0.0.1:8765，状态库为`.local/runs.sqlite3`。凭证仍取原配置，不传给页面或模型。Codex子进程使用当前已有系统代理，不修改全局网络配置。新加坡网站后端及原VPS代理继续运行；本机关机时本地任务停止，官网继续收询盘。当前无需新增付费服务。

## Agent接续与代码入口

桌面Agent可通过`python -X utf8 desk_cli.py objects list --kind product --query BQ008`查询同一业务对象，`objects get product:BQ008`取详情；`artifacts list --object-id product:BQ008`取成果，`artifacts save product:BQ008 --title 标题 --content-file 文件`保存。命令在本目录运行；正文留业务目录，不能另建一份客户事实库。

| 文件 | 职责 |
| --- | --- |
| `business.py` | 产品/客户源读取、对象关联、成果保存与上一版 |
| `website_inquiries.py` | 原网站只读、内存缓存和真实读取状态 |
| `agent_jobs.py` | Sol任务、实际步骤、取消、结果及读取完成判断 |
| `desk_mcp.py` | 当前对象与关联原件的只读业务工具，默认精简当前来源 |
| `desk_cli.py` | 桌面Agent与页面复用同一业务访问和成果实现 |
| `server.py` | 本地HTTP、共用对象/任务/成果接口；旧运行接口保留历史兼容 |
| `web/index.html`、`desk.js`、`desk.css` | 新默认界面；旧app/workspace文件不再加载 |
| `media_assets.py`、`connectors/`、`product_changes.py` | 复用媒体预览及已有平台能力，后续接入对象内流程 |
| `cloud-runner/` | 既有云端执行代码，当前不启用 |

验证：本目录运行`python -X utf8 -m unittest discover -p 'tests*.py'`及`node --test tests_desk_frontend.mjs`。真实任务日志、读取依据与成果索引在被忽略的`.local/`，不进入公开Git。新会话先看PRODUCT确定下一包，再看本页确认实际能力。
