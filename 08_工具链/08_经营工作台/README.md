监督循环随工作台服务进程启动，同一数据库内使用短租约和递增 fence，在受支持的实际任务写入事务检查版本；意图或人工安排变化、旧租约、冲突及未知回执均保留待核对，不刷新版本盲重试。数据库与独立成果文件不是跨文件事务，也不是跨 VPS 的共享租约。普通任务并非全部只读；自动邮件整理使用受限只读执行器，但最终可保存内部草稿。外部桌面聊天与云端任务不因登记引用而被本机监督器接管。
