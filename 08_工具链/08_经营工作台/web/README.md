# 工作台界面

当前由本地服务提供静态文件。`app.js`负责任务与提案，`workspace.js`负责旧画布和国际站试验入口。

2026-10-31起暂停按旧菜单扩展；当前界面不能代表产品目标。下一版围绕总览、商品、客户、渠道、创作、资料组织；Agent操作当前对象，画布仅是创作视图，具体取舍只在[产品方向](../PRODUCT.md)维护。

可复用底座：本地媒体预览、原业务资料读取、官方连接器、Sol执行与结果保存。需要替换：手填素材路径、装饰连线、主界面的接口控制台、与具体项目分离的空白画布。

第一包以真实商品整理选款资料、真实询盘准备并保存回复草稿验收；后续接渠道修改与内容制作。所有流程都要能找到原资料、直接使用成果、再次打开接续，不单独为每个接口建演示页。当前尚未实现新界面。
