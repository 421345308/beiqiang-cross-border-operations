# 工作台界面

当前由本地服务提供静态文件。`app.js`负责任务与提案，`workspace.js`负责旧画布和国际站试验入口。

2026-10-31起暂停按旧菜单扩展；当前界面不能代表产品目标。下一版围绕项目、素材和项目内Agent重新组织，采用成熟画布组件，具体取舍只在[产品方向](../PRODUCT.md)维护。

可复用底座：本地媒体预览、原业务资料读取、官方连接器、Sol执行与结果保存。需要替换：手填素材路径、装饰连线、主界面的接口控制台、与具体项目分离的空白画布。

新界面验收用一个真实项目完成“打开→选素材→Agent整理→同处编辑→再次打开继续”，不单独为每个接口建演示页。
