# 工作台界面

默认入口index.html加载desk.js/desk.css，围绕总览、商品、客户和资料组织。对象详情带真实资料、素材、Agent任务与可编辑成果。旧app.js/workspace.js仍保留，但不加载到主界面。

第一包实际能力和验证范围见[运行入口](../README.md)，后续渠道/创作与反馈路线见[产品方案](../PRODUCT.md)。不再为每个接口建独立演示页。

导航按hash恢复；列表/详情回包归属当前页面；轮询只更新任务及成果入口，不覆盖正在编辑的内容。主界面使用真实近期对象与运行记录，不按产品排序推荐款式。素材默认少量预览、原文按需展开。

验证使用`node --test ../tests_desk_frontend.mjs`及真实浏览器旅程：查对象→提交工作→看成果→编辑保存→刷新接续。界面正确与业务成果正确分别验收。
