# 平台与呈现位置：只读当前任务对应部分

分类注册和可执行状态由 `commerce_catalog/commerce_strategy` 返回；下面补充专业判断。编辑建议与平台强制规则分开：字段、权限、字数、规格、禁用词等用当前官方Schema/商家门户，不把本页当完整平台规范。当前六个平台可准备，新增平台账号/API均未接通。

## 共同的商品底层

真实商品/家族 → 具体颜色尺码等变体 → 每个平台与账号的商品对象 → 该对象的offer及素材。Alibaba链接ID、Amazon ASIN/卖家SKU、站内产品/variant ID、小红书笔记ID、抖音视频ID不是同一命名空间；不能直接互换。原SKU、源原件和有效主张保持共用，每个平台的内容与商业字段各自取证。资料中的采购价、批发MOQ或平台库存不能自动变成零售售价、实物库存或发货承诺。

从实际请求决定商家经营侧还是网站顾客购物侧。本插件属于经营侧；顾客选购、购物车和订单助手需要面向顾客的商品/库存/政策后端及独立认证，不把内部货源、成本、CRM送进顾客上下文。Anthropic和Shopify参考实现明确分了这两种角色。

## Alibaba listing / product_video

围绕买家准备采购决策的缺口：用途、选款、规格、颜色尺码、真实来源、能证实的定制/供给及样品下一步。标题写明确采购意图，详情和图像各有职责，不堆消费者情绪词。只改标题则不扩成整店整页。生成素材不作为工厂、测试或实物证据。

产品视频可用演示、采购问题解释、结构细节或有原件的流程证明。B2B也可用生活情节建立用途认知，但须说明为何采购者会记住商品；不能所有鞋都拍工厂，也不能用抽象走秀取代选款信息。价格/材料/MOQ/包装按唯一SOP与本款原件，不在本插件写固定数值。

## 抖店 listing / 抖音 short_video / live_clip

这三个位置分别生成商品资料包、短视频创意、可独立理解的讲解片段。商品包核具体款式、规格、图片、履约；不把创作里的人物体验当商品参数。短视频先让观众看懂事件或动作，生活处境与产品参与要早出现，但不硬规定所有片子必须几秒一切。

可选：试穿反应、一个具体问题的演示、日常小剧情、两种场景搭配、细节展示。每条只解决明确的观看问题；需要成交时再承接已核的商品/版本，不为了加CTA打断笑点。直播切片要有完整提问、动作和答复，不能截成只有“舒服”“好用”的空话。

视频OAuth发布和抖店商品创建是不同能力；本次官方动态门户正文读取不完整。当前只做准备/校验与缺口说明，不凭搜索摘要捏造发布载荷、类目属性或权限。

## 小红书 note / video_note / listing

从一个可搜索的生活问题、场合或选择标准进入。标题/封面与实际内容一致；图文笔记重细节组织、使用步骤、搭配或选择取舍，视频笔记让体验通过动作出现。收藏价值来自能复用的信息，而非长清单或夸张“闭眼入”。

真人体验和演员演示分开，不能生成“我买了三个月”“全网真实测评”等未经发生的经历。若资料只支持外观与日常使用，就写这些；功效、耐久和测试缺口保留。笔记、商品和广告合作各自核对应规范，本次未取得开放门户正文，字段/权限仍待实际核验，不宣称笔记发布API已可用。

## Amazon listing / product_video

先区分匹配已有ASIN、创建新商品、卖家offer，以及父子变体。marketplace/productType/locale决定Schema，不能把国际站字段改名后直接提交。审核包包含搜索意图标题、清楚要点、真实属性、图片角色、尺寸/版本选择及不适用边界；准确减少误购比堆关键词更重要。

视频回答静图没说明的使用、尺度、结构或选择问题。产品演示、尺寸指南、真实细节、明确条件比较都可选；情节只有在能帮助理解用途时才用。价格、库存、变体、GTIN/豁免及A+资格都单独核，主图/视频的当前要求以平台原规范为准。SP-API文档可读不等于本机卖家身份或API已接通。

## 独立站 landing_page / listing / brand_video

先选商业模式和技术栈。贝强现有站点为B2B，广告或SEO入口承诺应接真实选款/咨询页；若用户以后做零售站，需要零售offer、价格、库存、物流/退换与结算后端，不能自动沿用批发页面承诺。Shopify只是一个可选提供方，不代表所有独立站都用它。

落地页先解决入口问题，再给商品/证据、适配选择、FAQ及下一步；SEO是有用内容和可理解信息结构，不只是增加关键词。品牌视频可以更重情绪和世界，但商品与行为仍有关系。同一商品可分别做搜索承接演示、品牌故事和选择指南，用来源标记及相同口径回收实际结果。

## TikTok short_video

海外平台不能自动套英语B2B，也不能把零售观众与采购商混在同一个任务目标里。用当次项目的语言、地域、角色和CTA。贝强当前身份/工具约束回全渠道增长总控；没有可用发布连接时照常完成内容与审核包，不报已发布或新增采购效果。

## 内容迁移

迁移先保商品和主张，再改受众、开头、信息顺序、场景、声音、节奏和结尾。不能只改画幅、翻译标题或把同一稿发五个平台。跨平台任务每个target交付自己的实际内容和衡量办法，共用素材只表示可复用来源，不表示成片或发布结果一样。
