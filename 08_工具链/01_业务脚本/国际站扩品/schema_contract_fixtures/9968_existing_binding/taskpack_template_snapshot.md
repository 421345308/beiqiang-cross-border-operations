# 工厂店外新款数据采集模板（单款经营任务包）

沿用原采集入口，服务现行[生命周期 SOP](../00_运营SOP/国际站商品全生命周期SOP.md) §2.1；数量目标、批量大小及执行方式以当次任务为准，不继承历史“缺44款”或 Excel 优先流程。每款在既有执行目录填写一份；引用原证据而非复制整库。窄范围工作只填写适用部分。

## A. 身份、任务与来源

| 字段 | 填写内容 |
| --- | --- |
| task_id / 日期 / 负责人 / 唯一写入者 | 待填；多角色研究可并行，平台写入归一个角色 |
| 产品角色 / 当前阶段 / 唯一下一动作 | NEW / OPTIMIZE / REPLACE / TEST；不以阶段成功代替全链完成 |
| 内部货号 / 公开型号 / categoryId / productId | 新建前无 productId 写未创建；之后绑定唯一 ID |
| 实鞋、采购入口、原始包 | URL/本地文件、观察日期、货号对应；是否自产另列原始包证据 |
| 色码与 SKU 矩阵 | 来源原始色名/尺码标签、限制、乘积和例外；无实测不换算 US/脚长 |
| 材料/闭合/结构/人群 | 每项值与证据路径；区分整底描述、分层材料和外观观察 |
| 质量依据及未知 | 实拍可见做工、原始规格、已有检测分别记录；平台5分不证明实物性能 |
| IP 与无标判断 | 来源标识/整体设计风险；无标需真实交付证据，不靠涂抹伪装 |
| Schema 必填/可选/未知口径 | 当前接口、类目、日期、成功证据；不得把某类实测泛化所有类目 |
| 商业字段与授权 | 成本/币种/日期、汇率来源/时间、加价与舍入、MOQ/阶梯/包装适用基线；逐单报价确认 |
| 库存处理 | 当次授权写入值或省略可选字段；不得把999当现货或为评分补库存 |
| 去重与覆盖范围 | 来源/结构/采购意图、相近现有 ID、证据路径、覆盖数量及缺口；局部不写全店无重复 |

可选供应商问答、未宣传性能或未取得精确现货数不自动阻断；缺实鞋/有效采购入口，或拟写关键事实、当前必填字段缺证才标对应 HOLD。

## B. 海外需求 → 具体实款匹配

| 市场/方向 | 源 URL 与观察日期 | 原页面信号/数量/时间范围 | DIRECT/PROXY/HYPOTHESIS | 与本款相同与不同 | 决策与边界 |
| --- | --- | --- | --- | --- | --- |
| 待填 | 实际购买提示与评论数分栏，不叠加近似条目 | 未见写未知 | DIRECT仅指该原页面直接信号；映射本款仍需说明 | 结构/材料/人群逐项比较 | 选入/优化/小试/暂缓；不迁移竞品销量、认证、商标或性能 |

“低竞争/蓝海”需可核验竞争数据；未知时只能写试验假设。已有同方向证据填写原采集日期、本次适用性复核与更新触发条件，不强制重复全量研究。

## C. 关键词 → 长尾词 → 标题决策

| 词/短语 | 核心品类/属性长尾/采购服务 | 来源/日期/市场 | 买家查询/广告词/公开词汇 | 搜索量及窗口 | 本款证据 | 采用位置/弃词原因/持久化状态 |
| --- | --- | --- | --- | --- | --- | --- |
| 待填 | 分类不是流量证据 | 记录具体页面或后台导出 | 不将零售措辞冒充后台搜索词 | 未取得就写未知 | 指向A项证据 | 标题/关键词/属性/正文；正式回读空值为待补 |

标题当前值：待填。拟定值：待填。保留理由：待填。弃词及原因：待填。当前 Schema 限制/批次例外：待填。长尾不必然优于核心词；不填满字数、不硬设关键词数量，不因“热词”写假材料/宽楦/性能。内部供应商与采购路径不对买家披露。

| 图片 | 买家问题 | 可见证据/原图路径 | 原生/裁切有效像素与展示尺寸 | 文字与事实边界 | 下一步/验收 |

## E. 执行与独立验收

| 检查 | 预期/实际/状态 | 证据路径、时间、请求或观察来源 |
| --- | --- | --- |
| API能力与载荷 | 当前类目与操作成功证据；create/update范围、冻结字段、单一写入者 | 使用现有工具清单；业务表不意味着工具已接受所有字段 |
| 唯一新旧ID绑定与写入回执 | 创建结果未知先对账，不盲目再创建 | 授权/预检/提交/结果 |
| 正式标题/型号/关键词/属性/报价 | 本地拟稿不算正式持久化；关键词逐项对照 | 当前 get/render/字段回读 |
| 审核状态 | approved / pending / rejected等真实值 | 时间、来源 |
| 图片与SKU | 按SOP §4默认六主/至少四详/五公司及2627BSK明确例外，真实SKU总数与逐色绑定 | 正式CDN及视觉验收 |
| 真实评分 | target_score=5.0；actual_score、observed_at、score_source、diagnostics | 未返回写待评分，不代填目标或猜低分 |
| 公开买家页QA | 标题/款型/图组/逐色/选择与询价入口/详情实际正文 | 独立只读观察；审核中不报完成 |

## F. 旧新映射与普通旧品收尾

| 字段 | 值/证据 |
| --- | --- |
| replacement_plan / 是否适用 | REPLACE必填；NEW未分配替换对象写未分配，不写已完成替换 |
| old_product_ids / new_product_id或复用ID | 每个明确ID，不凭鞋型相似猜绑定 |
| 当前旧品分类 / protected / 当前状态 | 当次商品证据、保护依据与查询日期；HR家族保留链接编号规则另核 |
| 授权来源 / 收尾操作 | 明确范围；仅已授权普通旧品下架，删除另需授权，不自动改其他商品 |
| 发布次序 / 冲突处理 | 现有差异化与授权检查仍适用；不得隐藏旧品绕过冲突。工具未支持写待工程处理 |
| 新品正式/审核/真实≥5分/公开QA | 适用验收全部完成后再执行授权收尾 |
| 旧品操作与回读 / 失败处理 | 时间/回执/旧品实际状态；保留原事实，不扩大操作范围 |
| 经营完成状态 / 唯一下一动作 | 各阶段状态分开；关键词或收尾未完不宣称全链完成 |

## G. 观察与复用

优化记录：优秀同类B2B竞品来源/日期、标题词义和图文采购信息拆解、本款事实/供给/买家需求、独立判断、原值/新值及改动理由。数据用于排序和事后复盘，记录有效采购商机与报价/样品/订单讨论进展；版本用于追溯纠错，不强制A/B、2–3款单变量或等待显著性。成熟方法记录适用范围和失败边界，没有转化数据只报内容验收成功；7/14/30天只作复盘起点，不另建台账。

填写示例：既有执行目录 `9968_API完整新建_2026-10-02/经营任务包.md`、`5998_API新建_2026-10-02/经营任务包.md`、`3522_API完整新建_2026-10-02/经营任务包.md`；海外证据复用[2026-10-02方向与词证](../../06_市场研究/海外鞋类需求与词证_2026-10-02.md)。
