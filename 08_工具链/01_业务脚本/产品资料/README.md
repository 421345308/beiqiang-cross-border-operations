# 产品资料制作

服务[国际B2B精选册](../../../04_客户开发/06_报价与产品册/国际B2B精选册/README.md)及产品中心的内部经济比较。工具只读原源、生成本地资料，不修改平台、不发邮件。

## 运行

在项目根目录运行，使用带ReportLab、Pillow的Python和支持TypeScript导入的Node（Codex内置运行时已具备）：

```powershell
python '08_工具链/01_业务脚本/产品资料/build_b2b_selection.py' --node '<Node可执行文件绝对路径>'
python '08_工具链/01_业务脚本/产品资料/build_selection_economics.py'
```

PDF脚本使用Windows的Segoe UI、Georgia字体。默认系统Python未装ReportLab时用内置Python，无需修改系统环境。

## 输入与输出

- PDF：读取精选册 `selection.json`、产品中心身份、网站同源规格与照片追溯、8款正式回读、已有本地联系人；输出回精选册 `交付/`，哈希与引用清单回 `qa/`。照片只按比例压缩嵌入，源文件只读。
- 经济比较：读取唯一生产成本基线、当前回读、供应页观察与既有价格/经营复核；输出在产品中心受控 `.local/主推组合评估/`，包含HTML、逐档CSV及生成数据。当前读取批次是2026-10-29，不把固定日期脚本当自动更新的行情服务。
- 新回读按对象留存，明确切换本次证据目录后重新生成；不覆盖老回执，不手改生成HTML或CSV作为新的成本来源。

## 验收

PDF需渲染并逐页查看图片、文字、表格、页码与链接目标；程序无溢出不代替目视检查。生成脚本验证所用原图哈希和逐款身份。

经济比较需用实际浏览器操作数量及费用，至少核普通100双、120/600双供应阶梯、低于MOQ不出结果、附加费用改变贡献、无效比例输入。本次11款/33档，7项实际交互核验通过。未观测到经营数据的款显示“无”，不填0；费用默认0表示未录入。

公式中的贡献额仅覆盖已输入费用，不等于净利润。供应商公开价与负责人生产基线保留各自含义；目标贡献率反推价只是情景，没有写回平台。采购现金总额不等于定金或现金峰值。
