# LibTV 模型与成本核验

画布、素材及模型操作使用已安装 `libtv-cli` 和官方 CLI，以当前帮助为准。2026-10-12只读查询 CLI 1.1.3：先 `libtv model search --type video seedance`，再对唯一modelKey获取schema。[模型原始规格](模型/)保存实际回读；没有创建画布、上传或提交生成。

| 已发现模型 | key | 清晰度 | 时长 | 已核与待核 |
| --- | --- | --- | --- | --- |
| Seedance 2.5 | star-video2.5 | 480/720/1080P，默认720P | 4–30秒 | 搜索回读注明按秒计价，参考视频时长计入总时长；支持全能参考/视频编辑。schema无每档积分数 |
| Seedance 2.5样片 | star-video2.5-draft | 480P | 4–30秒 | 搜索介绍可先样片再高清；升级价格、是否锁动作及累计费用未核，不默认比直接720P便宜 |
| Seedance 2.0 Fast VIP | star-video2-fast | 480/720P，默认720P | 4–15秒 | 规格已核，积分价待核；不根据Fast名称推断效果/单价 |
| Seedance 2.0 Mini | star-video2-mini | 480/720P，默认720P | 4–15秒 | 搜索介绍高性价比；具体成本和本片成功率未验证 |

720P可作成本比较的优先候选，织纹特写另看细节，不默认全片1080P。720P到1080P的尺寸是1.5倍，普通缩放与AI超分不同。本机AI视频超分链及连续织纹稳定性尚未实测，不把FFmpeg放大称为已验证AI超分；后处理不能修好缺腿、鞋型漂移或接触错误。

预算按同一模型、模式、生成时长、参考视频总时长、清晰度、音频与账号优惠核对。720/1080P折扣比和积分数未由CLI确认，不拿宣传低价当实际扣款。当前CLI没有估价子命令，schema只含活动标记而无数值；不捏造HTTP计价接口、不为探价付费生成。

复刻先提炼关键动作/时间段，再决定传参考视频还是关键帧+文字。前者可能增加输入时长费用，后者可能损失动作引导；不为省积分盲删必要参考。正式预算补齐实际报价，比较生成、后处理、可用素材与返工总成本。
