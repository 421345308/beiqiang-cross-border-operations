画布、素材及模型操作使用已安装 `libtv-cli` 和官方 CLI，以当前帮助为准。2026-10-12只读查询 CLI 1.1.3：先 `libtv model search --type video seedance`，再对唯一modelKey获取schema。[模型原始规格](模型/)保存实际回读；未提交生成。2026-10-12后续创建一个未运行报价草稿，沿用现有公开图，仅核价。

720P可作成本比较的优先候选，织纹特写另看细节，不默认全片1080P。720P到1080P的尺寸是1.5倍，普通缩放与AI超分不同。本机AI视频超分链及连续织纹稳定性尚未实测，不把FFmpeg放大称为已验证AI超分；后处理不能修好缺腿、鞋型漂移或接触错误。

预算按同一模型、模式、生成时长、参考视频总时长、清晰度、音频与账号优惠核对。720/1080P折扣比和积分数未由CLI确认，不拿宣传低价当实际扣款。当前CLI没有估价子命令，schema只含活动标记而无数值；不捏造HTTP计价接口、不为探价付费生成。

复刻先提炼关键动作/时间段，再决定传参考视频还是关键帧+文字。前者可能增加输入时长费用，后者可能损失动作引导；不为省积分盲删必要参考。正式预算补齐实际报价，比较生成、后处理、可用素材与返工总成本。

## 2026-10-12当前账号页面实价

CLI不能直接回读数字价格；通过CLI设置未运行草稿，再在已登录页面读取。Seedance2.5、图片参考、9:16、28秒、count1、声音开启：720P为1,288积分，1080P为3,080积分。相同输入差额1,792；720P约省58.18%，1080P约为2.39倍，不把其他项目负责人“四倍”的观察推广为本批价格。

账号页面显示余额16,320积分，会员包标签16,300不能当余额。没有核该账号积分实际购入成本，不由宣传“低至”换算人民币。草稿已恢复720P，无生成输出、无扣款；实际BQ029输入和模式确定后重新查看最终价格。
