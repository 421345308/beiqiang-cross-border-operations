## 运行收尾与资源边界

每次生成/审片/渲染记录自己启动的进程PID、父进程、命令职责、端口与退出状态，任务结束在finally或显式关闭时回收。只关闭已核本任务的闲置服务；不按python/node名称批量结束，不终止Codex界面、其他任务MCP或用户应用。本地语义推理已退出；导出一次一个，不另留预览网站或并行GPU作业。
