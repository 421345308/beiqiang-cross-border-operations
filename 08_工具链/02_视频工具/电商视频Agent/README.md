## 目标与现有基础

把真实商品、创意迭代、参考资产、模型执行、成片复核与用户反馈连成可重复的制作流程。初期服务贝强鞋类电商/品牌短视频，渠道、语言、受众和形式按当次项目确定，不自动套英文B2B或消费者带货模板。

当前已有 SKU 原件/证据、PROJECT、资产与镜头清单、LibTV官方CLI、生成前确认和回读记录，以及视频审片工具；这些可作为首版基础。现有 Skills 的存在不等于整个 agent 已实现、跨款成功率或投放效果已验证。

## 首版模块

| 模块 | 必要输入 | 可审核输出 | 主要判断 |
| --- | --- | --- | --- |
| 商品事实 | SKU原件、来源与已确认信息 | 产品事实卡、可用外观/主张、缺证项 | 不把生成图和竞品内容当自有商品事实 |
| 创意与导演 | 目标、受众、渠道、风格、参考片 | 故事/口语对白/镜头事件、产品参与、完整提示 | 因果可读、节奏、生活关系、产品为何被记住 |
| 资产与连续性 | 人/动物/商品/道具/空景和当前镜头图 | 角色职责、时间状态、身份绑定 | 参考支持什么，不支持什么；不把静态姿势当必然动作 |
| 执行与版本 | 审核方案、Provider当前schema、当次报价和授权 | 精确请求、草稿/任务ID、输出及费用证据 | 不重复上传、不在故障时自动付费重试、可追溯 |
| 成片复核与返修 | 完整音视频、用户评价 | 带时段的问题、已保留优点、原因假设和局部修改 | 故事/表演/步态/接触/商品/声音都要看；文件检查不认证审美 |
| 经验检索 | 已确认偏好、有范围的经验及证据 | 下次任务的少量相关提醒 | 只调取适用经验，不把全部失败堆进长提示词 |

一个制作 agent 可以承担这些模块，不以增加多个 agent 的数量作为质量指标。新工具能力和跨模型选择需实际验证，不在首版自动切换用户选定Provider。

## 最小闭环与验收

真实SKU+一句需求 → 补齐关键选择 → 少量创意方向 → 完整审核包 → 官方入口保存草稿 → 核价/当次授权 → 生成 → 完整审片 → 用户反馈 → 保留基线或局部返修。

首版先接现有LibTV路线，完成当前SKU和另外两款的受控验证，再判断通用化；新增生成批次必须另获当次明确授权，本提案没有付费额度。初期不新建收费平台、不安装本地大模型，不在授权不明的账户执行演示。

验证记录：用户需要纠正了几次、产品身份错误、动作/道具缺陷、保留优点、可用片段比例、返修次数和实际成本。BQ028当前一版满意只能证明本项目方向得到认可，不能据此承诺批量稳定或广告转化。

## 本次反馈怎样变成检查，而非提示词堆叠

- **脚痛不够生动**：下次明确从正常步伐到轻皱眉、减速/卸重、坐下泄气的变化，挑足够可读的机位；仍需成片核表演强度。不能把增加疼痛形容词当修复成功。
- **散步不自然**：核参考姿态、步态/接地、人与犬相对速度、跟拍方式和时间预算，必要时再考虑动作参考或缩小镜头目标；不先把问题全部归因于文字不够细。
- **开盒时盒子歪**：核盒体刚性、支撑面、盖/身方向、手部接触和开合路径，再决定参考图或镜头方案的局部修订。描述刚性不保证模型服从，复杂接触可采用更可控的拍摄/合成路线。

当前仅形成候选检视项，适用范围是相近的人物穿鞋/行走/开盒镜头；未晋级为全项目固定禁令。正常成功项和失败项一起留证，修改时保住已满意的故事与产品表达。
