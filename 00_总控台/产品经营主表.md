# 产品经营主表

产品与平台链接的当前对应统一在[扩品总文件](../02_Alibaba运营/05_扩品工程/国际站合规扩品工程总控.md)，需要按型号、商品ID、供应商或原货号检索时打开[查询页](../02_Alibaba运营/05_扩品工程/供应商产品总表/供应商产品查询.html)。本页只保留跨渠道产品入口，不复制来源、进度和计数。

| 内容 | 唯一位置 |
| --- | --- |
| 款式、来源直链、存量A/B/C链接、候选与待办 | [产品与链接台账](../02_Alibaba运营/05_扩品工程/数据/产品与链接台账.json)；扩品总文件和查询页由它生成 |
| 真实鞋图、原始数据包及技术资料 | [产品资产](../01_产品资产/) |
| 图文、字段、SKU、报价与发布验收规则 | [商品全生命周期SOP](../02_Alibaba运营/00_运营SOP/国际站商品全生命周期SOP.md) |
| 订单实际采购价、可供数量与交付确认 | [客户与订单记录](../04_客户开发/README.md) |

同款共用事实和采购入口；不同商品ID各自记录发布和验收。产品组数、来源数、平台链接数、在线数分别计量，不能互代。
