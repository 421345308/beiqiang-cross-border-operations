# 贝强跨渠道经营总览

本页只维护经营链路、分工与指标。当前事实从[当前状态](当前状态.md)及各业务源核验，目录从[资产索引](资产索引.md)进入，不在本页复制旧平台或项目状态。

## 一、完整经营闭环

`市场与买家需求 → 产品事实 → Alibaba/独立站展示 → 视频与主动触达 → 询盘/RFQ → 报价/样品 → 订单/履约 → 数据复盘 → 知识与记忆更新`

所有渠道服务同一目标：获得可以继续推进到样品、报价和订单的真实B2B买家，不以页面数量、邮件数量、视频数量或商品链接数量代替经营结果。

## 二、业务入口

按[资产索引](资产索引.md)进入产品、Alibaba、独立站、客户、内容、市场、知识与工具目录。每条线只在自己的原始台账维护状态，跨渠道引用该记录。

## 三、渠道之间如何协作

| 上游 | 下游 | 必须传递的内容 | 不允许的断裂 |
| --- | --- | --- | --- |
| 市场研究 | 产品/Alibaba/独立站/内容 | 买家意图、关键词、竞品证据、研究日期 | 把竞品声明写成贝强事实 |
| 产品资产 | Alibaba/独立站/邮件/视频 | SKU身份、真实图片、已确认材料尺码和待确认项 | 四个渠道各写一套不同产品事实 |
| Alibaba | 邮件/独立站 | 正式商品链接、在线图片、可验证的交易入口 | 邮件使用未上线或错误映射商品 |
| 独立站 | CRM/客户开发 | 来源、询盘资料、参考号、下一动作 | 只统计访问，不进入跟进台账 |
| 视频/TikTok | Alibaba/独立站/CRM | 精确SKU、发布版本、CTA和来源参数 | 只产视频，不记录发布和询盘结果 |
| 邮件/多渠道触达 | CRM/产品/内容 | 买家触发信号、回复、异议、样品和资料缺口 | 回复经验停留在邮箱，不反哺产品和页面 |
| 成交与复盘 | 知识与记忆 | 经过验证、可复用的规则或经验候选 | 把一次经历直接升级为长期原则 |

## 四、统一指标

| 阶段 | 核心指标 | 解释边界 |
| --- | --- | --- |
| 发现 | 有效曝光、目标买家访问、内容观看 | 播放或访问本身不是采购兴趣 |
| 承接 | 产品点击、Quote list、表单开始、邮件回复 | 打开、分享或点击不等于询盘 |
| 资格 | Qualified inquiry、明确品类/数量/市场/时间 | 公共邮箱自动回复不算正面线索 |
| 推进 | 样品请求、有效报价、技术资料补齐 | 报价发送不等于接受 |
| 成交 | Trade Assurance或正式合同确认 | 网站状态不能替代真实交易记录 |
| 复购 | 补单、新季、OEM/ODM新项目 | 必须关联新的询盘或订单证据 |

## 五、更新规则

1. 各渠道先更新自己的业务记录，本页只同步摘要和入口。
2. 状态必须写明证据日期；没有实时核验时写“待验证”，不能沿用旧结论。
3. 同一事项跨渠道时使用SKU、询盘参考号、客户名或活动ID关联，不复制正文。
4. 每条经营线始终保留一个明确下一动作和一个可衡量结果。
5. 当前优先级变化时更新`00_总控台/当前状态.md`，长期稳定方法再进入五层记忆。
