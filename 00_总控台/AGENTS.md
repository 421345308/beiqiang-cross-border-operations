# 贝强全局任务路由

本页回答“项目有什么、什么时候读什么、结果放哪里”。公司事实与授权回根 [AGENTS](../AGENTS.md)，业务当前状态回原台账。本页不保存平台数字、客户状态或商品承诺。

## 开始任务

1. 先识别任务：全局协调、单项经营、客户项目或独立创作。全局任务读 [当前状态](当前状态.md)，渠道任务再读 [全渠道增长总控](全渠道增长总控.md)；单款修复不必读全项目报告。
2. 从下表只取所需业务入口，随后读适用的下级 AGENTS 和专项 SOP。需要历史依据再搜相应对象ID或章节，旧报告不自动成为现行规则。
3. 明确实际交付物及验收：研究结论、商品修复、网站发布、正式触达、样品或数据回收分别判断。已确认事实直接复用，缺口才问；局部登录/API故障不阻断独立工作。
4. 工具按 [渠道接口与插件](../08_工具链/04_MCP与Workctl/渠道接口与插件.md)选择：已连插件/官方 API 优先，结构化导出次之，浏览器用于登录、授权、尚无接口的操作与页面终验。

## 结束与回写

先更新真实业务源，再修需要变化的入口和优先级。草稿不记为发布，提交不记为送达，可抓取不记为收录，收录不记为AI引用或采购转化。客户原件和授权凭证不进入公开同步。按根规则检查、提交并推送本任务范围，保护其他任务未提交内容。
