# 贝强工作区资产梳理与目录重构建议

更新时间：2026-08-10  
本轮范围：只读盘点与分类建议。尚未移动、删除或重命名任何现有业务文件。

## 一、结论

当前工作区已经不是单纯的“商品资料文件夹”，而是一个初步成形的跨境 B2B 经营系统，实际包含八类资产：

1. 商品原始数据与可发布素材
2. Alibaba.com 店铺运营与商品优化
3. 贝强 B2B 独立站
4. 海外客户开发、邮件与线索管理
5. AI 商品视频与短视频内容
6. 竞品、市场与关键词研究
7. Codex 外贸 Skills、SOP 与模板
8. 脚本、运行环境、第三方工具和临时数据

当前困难不是成果不足，而是缺少统一总控层：原始资产、正式交付物、执行记录、实验项目、工具依赖和历史压缩包同时出现在根目录或语义相近的 `output/`、`outputs/` 中，导致下一步工作难以判断优先级。

### 1. 商品资产库

- `01_产品资产/01_原始数据包/`：30 个 SKU 原始数据包，约 5,136 个文件、3.787 GB，以原始商品照片为主，并含少量视频。
- `01_产品资产/02_可发布素材/00_最终上传/`：30 个 SKU 均已有独立目录和 `00_上架填写表.md`；主图、详情图、颜色图和参考预览已按用途拆分。
- `01_产品资产/02_可发布素材/99_归档/`：包含主图重建、颜色图修复、图库角色审计和历史候选版本。
- 商品资产是当前工作区最完整、最稳定的一层，应继续作为只读事实来源，不与营销实验混放。

### 2. Alibaba.com 运营

- `90_工具脚本/` 同时包含自研商品图片脚本、Seedance 脚本、FFmpeg 二进制、EdgeOne 运行时等，约 27,639 个文件、0.672 GB。
- `tools/opencut-classic/` 是完整的第三方视频编辑项目，并含构建缓存，不应与贝强自研脚本视为同一类资产。
- `.workctl_tmp/` 是经营数据采集与构建中间文件；应先提炼正式结果，再归档。
- 根目录 Git 仓库目前没有提交，绝大多数文件为未跟踪状态；独立站自身另有 Git 仓库。根目录 Git 的职责尚未定义。

## 三、主要结构问题

1. `output/` 与 `outputs/` 含义相近，却分别承担历史媒体产物和当前业务交付物。
2. 根目录堆放 Alibaba 审计报告、站点发布包、截图和临时脚本，入口不清晰。
3. 视频生成“方法、源片、过程文件、成片、评审”和非业务实验混在一个目录。
4. 获客存在多批名单和多轮邮件，但缺少唯一的当前客户主表与最新跟进状态。
5. Skills 位于工作区外，没有工作区内的版本清单或备份来源。
6. 多个预建业务目录为空，而真实资料仍留在旧位置。
7. 缺少一张连接 30 个 SKU、Alibaba、独立站、视频、外联和询盘结果的经营总表。

## 五、建议的进一步开发方向

下一阶段不宜继续同时扩展所有方向。优先建设一张“产品经营主表”，让每个 SKU 都能回答：

- 商品事实是否确认
- Alibaba 是否发布、最近优化日期、当前等级
- 独立站页面是否上线
- 是否有可用主图、详情页、产品册和视频
- 适合哪类买家与市场
- 是否进入外联素材
- 获得多少曝光、点击、询盘、样品和报价机会
- 下一步唯一动作是什么

推荐的经营闭环为：

`产品事实 → Alibaba/独立站内容 → 定向外联/视频引流 → 询盘与跟进 → 周数据复盘 → 决定下一款产品投入`

当前最需要补的是闭环后半段的数据，而不是继续增加更多工具或更多孤立内容。

## 六、建议的实际整理顺序

1. 先建立 `00_总控台` 和资产索引，不移动大文件。
2. 把根目录的 Alibaba 报告归到 `02_Alibaba运营`，仅做可逆移动并生成迁移清单。
3. 合并获客资料的索引，指定唯一客户主表；历史邮件包保留为记录。
4. 将贝强商品视频与非鞋类 AI 实验分开，保留原始任务 JSON 和评审记录。
5. 为全局 Skills 建立版本清单和工作区备份策略，不直接移动已安装 Skills。
6. 最后处理压缩包、空目录、拼写错误目录、缓存和临时数据；所有候选先进入 `90_归档/待确认_2026-08-10/`，不直接删除。

## 七、需要负责人确认的决策

1. 非贝强视频实验是否仍属于这个工作区，还是迁往独立的 AI 视频实验库。
2. 根目录 5 个独立站压缩包要全部长期保留，还是只保留带日期和版本说明的关键发布包。
3. Skills 是否采用“工作区保存源版本、全局目录作为安装副本”的方式管理。
4. 后续 30 天的主轴，是 Alibaba 商品转化、独立站询盘、主动邮件获客，还是商品视频测试。
