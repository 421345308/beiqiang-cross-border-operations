# 模板使用范围：由当前创意决定

适用于贝强鞋款视频借用工作区模板库的方法。模板提供镜头组织和描述方法，不替代当前项目受众、场景、风格、模型选择或单款证据。旧版针对海外采购证据短片的取舍，不适用于所有贝强品牌广告。

- [模板总索引](../../../../07_知识库与Skills/04_AI视频知识体系/awesome-seedance-模板索引.md)
- 正文：`08_工具链/02_视频工具/awesome-seedance/docs/templates/zh/<slug>.md`

| 当前需要 | 可参考的方法 | 采用条件 |
| --- | --- | --- |
| 镜头顺序与节奏 | timeline-shot-script、product-commercial-shotlist | 描述具体动作和摄影；时间控制按所选模型能力写，不强制逐秒 |
| 分镜控制 | storyboard-grid-to-video | 核对所选版本的宫格/关键帧建议；不把宫格数量当实际镜头数 |
| 人物/鞋型保持 | character-reference-lock | 将角色、鞋款和色款分别绑定，按镜头需要准备参考 |
| 生活感与使用情境 | handheld-ugc-vlog、travel-city-walk、fashion-lookbook | 人物行为、穿搭和场景与真实鞋匹配；质感不限手机拍摄或目录陈列 |
| 情节、对白与幽默 | cinematic-narrative-short、dialogue-performance-beats、meme-comedy | 服务当前品牌目标，先检查表演、节奏与可执行性 |
| 工艺或产品形成表达 | process-transformation-montage | 概念演绎不能冒充真实车间/生产证据；结构和制造声明有相应事实 |
| 动作与声音配合 | music-beat-sync-mv、pov-continuous-take、time-freeze-rewind | 由当前创意、模型和剪辑工具决定，不因旧失败一概禁止 |

其他模板按当前项目评估，不维护跨项目的题材黑名单。UGC广告表演与真实客户评价是不同表达：可以做明确的虚构使用情境，不能编造客户身份和真实使用背书。

产品、来源、商业承诺与授权按根及视频 `AGENTS.md`。历史生成问题只作为有范围的检查候选，参见 [prompt-framework.md](prompt-framework.md)，不把一次结果升级成模板禁令。
