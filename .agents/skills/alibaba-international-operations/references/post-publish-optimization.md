# Post-Publish Optimization

Use this after products are published or when the user asks what to do next.

## First 7 Days

- Check whether the product has exposure. If almost no exposure, review category, title relevance, keywords/selling points, attributes, and duplicate risk.
- Check whether the first main image is strong enough for search clicks.
- Confirm the page has no obvious quality issues: Chinese images, missing attributes, inconsistent materials, broken detail image text, wrong color labels, or empty size chart.

## 14 Days

- Compare exposure and clicks across products in the same product group.
- If exposure exists but click-through is weak, test the first main image and title opening words.
- If clicks exist but no inquiries, improve detail page clarity, specs, sample/MOQ policy, packaging, and FAQ.
- Record buyer questions and add repeated questions into detail page or FAQ.

## 30 Days

- Identify benchmark listings: products with better exposure/click/inquiry should receive more image and copy refinement.
- Merge or de-prioritize duplicate or weak variants that scatter traffic.
- Expand around winning keyword clusters, materials, closure types, or buyer scenarios.
- Decide whether to create sibling products or improve existing listings instead of adding more thin products.

## Optimization Triggers

- Low exposure: category/title/keywords/attributes/duplicate risk.
- Low click-through: first main image, title opening, price range, MOQ, product differentiation.
- Low inquiry rate: detail page, specs, MOQ/sample/lead time, trust modules, buyer objections.
- Poor inquiry quality: title too broad, image misleading, specs unclear, wrong category, price/MOQ mismatch.
- Repeated buyer question: add the answer to FAQ, specs, or detail image.

## Weekly Operator Notes

Maintain a simple sheet or note for each product:

- Product code/model
- Title version
- Main image version
- Exposure
- Clicks
- Inquiries
- Inquiry quality
- Buyer repeated questions
- Next action
