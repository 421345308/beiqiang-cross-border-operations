## 使用与接续

- [英文精选册](交付/Beiqiang-Selected-Casual-Footwear.pdf)：约1.9MB，含产品、工厂工序、比较和合作路径。供选款讨论；实际样品与订单条件按具体版本确认。与原69款完整目录分工，不覆盖旧资料。
- 选款理由、当前主推和商业缺口只维护在[产品矩阵与供货能力](../../../00_总控台/产品中心/产品矩阵与供货能力.md)。内部经济比较也由该入口进入，不混入买家PDF。
- [selection.json](selection.json)维护本册的编排、英文短文案和所选平台ID，是输出用的编辑清单，不是第二套产品或成本台账。规格、实图和供货身份从原产品中心、已核网站数据、逐款正式回读读取。
- 网站实施回[网站任务](../../../03_独立站/02_开发记录/独立站产品与架构设计.md)。本册已用正确的BQ003链接；网站BQ003/BQ005跳转串款问题已修复，正式域名中英文跳转及德法西内嵌产品ID回读通过。官网精选PDF与本地原件SHA256一致，验收回网站原任务。

## 内容与素材依据

产品照片保留原鞋体、配色和背景；仅为PDF嵌入按比例缩小，不用生成图替代实物。5款原厂图逐款追到原包哈希；合作来源按已采用身份与实际图库引用，BQ1009保留原有正式绑定核验。C2627使用已核来源配色合照局部，未称为新增独立拍摄。

公司成立年份、制造面积、年产量沿[负责人已确认公司资料](../../../02_Alibaba运营/01_店铺与全店诊断/店铺首页优化方案_2026-09-14.md)；工序使用既有真实视频帧。匿名品牌生产支持按[外发素材SOP](../../03_邮件与多渠道模板/潜在客户多渠道开发与外发素材SOP_2026-08-26.md)范围表达。没有把视频工序包装为已验收研发案例，也没有新增固定打样天数、认证、库存或价格承诺。

联系人沿既有工厂参观资料的本地联系人源读取，本册不新增公开个人信息。本经营仓库的输出、联系人源和QA记录留本地，只公开编辑清单、制作方法和业务结论；网站独立仓库按既有网站发布授权发布同一份买家PDF，不含内部成本或客户资料。

运行方式见[制作工具](../../../08_工具链/01_业务脚本/产品资料/README.md)。PDF生成读取当前原源与本次正式回读；来源/规格改变后重生成，再检查对应图片、文字和链接。原证据不覆盖，下一版更新其读取批次。

本次验收：6页渲染逐页目视检查；8个款号、8个产品目标链接和3个联系入口核对；无页面外文字或段落溢出；工厂原图哈希与原包映射检查通过。QA清单见 `qa/build-manifest.local.json` 和 `qa/validation.local.json`。链接核对指PDF链接目标与正式回读对应，不冒充已逐一打开全部国际站买家页面。
