# 客户开发总入口

本目录管理从目标买家发现到询盘、报价、样品、跟进和客户项目的完整记录。客户状态以CRM、发送记录和客户项目为准，邮件模板本身不代表已发送或已获得回复。

## 当前接续顺序

目标是把匹配的买家与可采购的产品方案连起来，推进报价、样品、订单利润和再订。2026-10-28起按[国际经营主线](../00_总控台/全渠道增长总控.md)验证区域渠道买家与已有销售的自有品牌两类客群；有时限的已触达对象继续原流程；具体研究与下一交付集中在[获客研究与送达率治理](获客研究与送达率治理.md)，RFQ按[专岗当前记录](07_RFQ专岗/README.md)独立接续。

实际主办在领取具体任务时写入原条目，按[共用工作流](../00_总控台/AGENTS.md)交付。客户状态和外发结果直接回原CRM，默认协作分工见[协作入口](../08_工具链/04_MCP与Workctl/Muse-Codex协作.md)。

## 经营与证据边界

RFQ按专岗SOP及其当前配置继续；主动开发按账户、联系人与实际触达动作分别维护。现行流水线接受需求邻近、系列缺口及备用供应等合理机会，不要求买家已经卖同款，也不把大名单当采购意向。

优先回收已触达对象的真实回复和采购推进，再按机会与承接能力扩量。早期暂停某批群发、10/20人实验或90天方案是当时假设，不是当前全渠道禁令；原始复盘与发送回执仍可按客户/批次追溯。实际外发继续按对应授权、对象和停止联系状态执行，本次整理不发送客户消息。

社媒账号与内容回原运营入口，产品身份回产品中心；客户身份、联系方式、原始回复及订单不进入公开同步。发送、送达、真人回复与采购推进分开，不能因旧记录写着“已发送”推断今天仍可联系。

| 主动获客流程与客户状态 | [流水线SOP](01_线索与CRM/规模化主动获客流水线SOP_2026-09-17.md)；本机CRM为 `01_线索与CRM/outputs/01a0a569-4d14-7a43-b384-bdd1bb8d08a2/主动获客_规模化流水线_2026-09-17.xlsx`，客户原件不公开同步 |
| 已发送、回复及停止联系 | [发送与跟进](04_发送与跟进记录/)；以真实发送和客户回复为准 |
| 一对一询盘、报价与样品 | [客户项目](05_客户项目/)、[报价材料](06_报价与产品册/) |
| 首次选款与工厂介绍 | [国际B2B精选册](06_报价与产品册/国际B2B精选册/README.md)：8款/6页英文资料已完成；按买家需求选择系列，实际外发和回复仍回原CRM |
| 外发规则和模板 | [邮件及多渠道模板](03_邮件与多渠道模板/)；技术型项目先读专项SOP |

客户状态只更新对应CRM/项目；同一客户不为每轮修改重建“当前状态”或工作簿。历史研究保留证据日期，发送、报价和样品分别留正式回执。

## 目录路由

| 目录 | 放什么 | 不放什么 |

## 最小记录

每次触达至少记录：买家公司、具名联系人或公共入口、触发信号、匹配SKU、渠道、发送时间、送达/退信、回复、下一动作、拒绝/退订状态。公共邮箱自动回复不算正面采购回复。
