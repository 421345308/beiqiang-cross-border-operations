# 客户开发总入口

本目录管理从目标买家发现到询盘、报价、样品、跟进和客户项目的完整记录。客户状态以CRM、发送记录和客户项目为准，邮件模板本身不代表已发送或已获得回复。

## 当前状态

- 2026-10-09设立[阿里巴巴国际站RFQ专岗](07_RFQ专岗/README.md)，由当前聊天定时持续负责；每天两次查询，对符合现行RFQ SOP和商品证据的需求已获持续提交报价授权。配置状态、运行故障与实际回执在专岗记录，其他获客渠道仍按各自授权执行。
- 2026-09-17起按“广泛发现、公司级去重、需求邻近评分、多渠道分流、动作级回写”的规模化流水线运行；不再要求买家已经销售与贝强完全相同的鞋款。
- 扩量优先发生在线索发现、资格核验、联系人研究和跨渠道队列；外部发送仍须核验目标、文案、产品证据和停止联系状态，不做无差别群发。
- 2026-08-27已完成Freet、The Mercer Brand、Shoesy和Footwear Cebo四封一对一邮件；当前证据仅能确认Gmail界面显示已发送，不能写成已送达、已打开或获得采购兴趣。
- LinkedIn及其他社媒渠道需要用户完成现有账号登录；企业邮箱认证和产品商业事实未齐前，不扩大冷邮件和正式报价。

## 目录路由

| 目录 | 放什么 | 不放什么 |

## 最小记录

每次触达至少记录：买家公司、具名联系人或公共入口、触发信号、匹配SKU、渠道、发送时间、送达/退信、回复、下一动作、拒绝/退订状态。公共邮箱自动回复不算正面采购回复。
