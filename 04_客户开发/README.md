## 目录路由

| 目录 | 放什么 | 不放什么 |
| --- | --- | --- |
| `01_线索与CRM/` | 买家研究、分层、联系人、触发信号和跟进状态 | 产品原图、通用模板 |
| `02_目标名单/` | 尚未进入正式CRM流程的渠道名单 | 已发送结果 |
| `03_邮件与多渠道模板/` | 经审阅的邮件、LinkedIn、WhatsApp和外发SOP | 客户真实回复 |
| `04_发送与跟进记录/` | 发送、退信、回复、下一触点和停止状态 | 仅供参考的草稿 |
| `05_客户项目/` | 一对一询盘、样品、报价和项目证据 | 泛化经验 |
| `06_报价与产品册/` | 报价材料、产品册和客户可见附件 | 未确认的固定商务承诺 |
