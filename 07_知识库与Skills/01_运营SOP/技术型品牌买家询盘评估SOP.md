# 技术型品牌买家询盘评估 SOP

版本：2026-08-14
来源案例：VORLEN × BQ-009（项目未成交，但形成有效经营规则）

## 适用范围

当买家提出下列任一要求时，不再按普通目录款询盘处理：

- 指定鞋底配方、工艺、硬度、密度、回弹或压缩永久变形。
- 指定鞋楦、堆叠高度、前后掌落差、平台宽度或重量。
- 要求两个或多个受控变量样品。
- 要求新模具、改变鞋底结构或特定橡胶接地区域。
- 要求耐磨、湿滑、材料或其他实验室测试。
- 要求 NDA、tech pack、矢量品牌文件或正式验收规格。

此类买家标记为：`Technical Development Buyer`。

## 第一步：区分两条业务路径

### A. Existing Style Adaptation

买家接受现有鞋楦、现有鞋底和基本结构，只讨论已经确认可行的颜色、Logo、鞋垫、标签或包装。

可以进入常规样品与报价流程，但每一项定制仍须逐项确认。

### B. Technical Product Development

买家要求改变鞋楦、模具、材料体系、硬度、结构、性能或测试标准。

必须先完成技术可行性审查，不能直接用常规样品价和大货价推进。

## 第二步：标记产品准备度

| 等级 | 状态 | 可以对客户说什么 |
| --- | --- | --- |
| R0 | 参考图/概念方向 | 仅用于讨论，不能提供成鞋数据或承诺生产结果 |
| R1 | 鞋底、鞋面或部件存在 | 可以说明部件现状，但不等于完整成鞋已验证 |
| R2 | 完整实物样品存在 | 可以拍摄和测量该样品，数据仅对应具体尺码/批次 |
| R3 | 内部实测资料完整 | 可以提供记录过的尺寸、重量、硬度和视频，注明方法 |
| R4 | 有正式测试或量产记录 | 只按真实报告和实际量产条件陈述，不扩大适用范围 |

任何产品从 R0/R1 直接写成 R3/R4，均属于高风险承诺。

## 第三步：把所有信息放入四个栏目

| 栏目 | 定义 | 对外用法 |
| --- | --- | --- |
| Confirmed | 已有实物、文件或供应链确认 | 可以明确回答，并保留证据 |
| Fixed / Not Adjustable | 现有模具或结构固定 | 直接说明不能调整，不用模糊措辞 |
| Available After Sampling | 只有生产完整样品后才能实测 | 说明会提供实际结果，但不保证命中买家目标 |
| Unavailable / Separate Test | 无法提供、属于专有信息或需另付费测试 | 说明范围、费用与周期需单独确认 |

特别规则：买家给出的规格一律先进入 `Buyer Target`，只有工厂和供应链书面确认后才能转入 `Confirmed Capability`。

## 第五步：样品单必须写清楚

### 评估样

适用于固定结构、尚无完整成鞋数据的方案。

```text
Purpose: Produce a physical evaluation sample using the existing fixed construction.
Data: Actual measurements will be recorded after production.
Boundary: The measured results are evaluation data and are not guaranteed to match the buyer's target values unless separately confirmed in writing.
```

### 受控开发样

只有工厂已确认可以按不同参数生产时才使用。

```text
Purpose: Compare two confirmed constructions with one controlled variable.
Specification: Each target and tolerance must be listed in the order.
Acceptance: Measurement method, sample condition and pass/fail rule must be agreed before payment.
```

不能把固定结构评估样命名为 Plush / Balanced 等受控版本。

## 第六步：鞋类技术数据规则

- Asker C 常用于软质泡棉硬度；Shore A 常用于较硬橡胶或弹性体。不能用一个值代替另一个值。
- 硬度必须写清测量部位、样品状态、仪器和方法；没有实测时不要给范围。
- 堆叠高度和落差要约定是否包含鞋垫、外底及测量点。
- 重量必须注明尺码、单只/一双和是否含鞋垫鞋带。
- 鞋码对应只能作为参考；品牌开发应同时确认脚长、脚宽/围度、鞋楦尺寸和试穿结果。
- 配方、密度、压缩永久变形、回弹、耐磨和湿滑不是同一指标；有数据就逐项提供，没有就逐项标明。
- 正式测试需确认测试标准、机构、样本数量、费用、周期和报告归属。

## 第七步：NDA 与公司尽调

1. 先用非机密信息判断产品方向和大致可行性。
2. 买家发送 NDA 后，由公司负责人审阅主体、保密范围、期限、适用法律、违约责任和签字权限。
3. 双方签署后再接收机密 tech pack、矢量图和未发布设计。
4. 营业执照等文件按需提供水印版本，标注接收方和用途。
5. Trade Assurance 卖家名、合同主体、收款主体与营业执照主体必须一致或有书面解释。

## 第八步：停止条件

出现以下情况时应停止催付，转为“不匹配说明”：

- 买家的关键验收标准是固定鞋底无法达到或无法控制的参数。
- 买家要求付款前取得只有生产后才存在的数据，又不接受评估样逻辑。
- 买家要求完整专有配方或未包含在费用中的正式测试。
- 工厂、鞋底方或材料方没有给出明确可行性。
- 样品订单无法清楚区分目标值与实际测量值。

停止不是销售失败，而是在避免样品争议、退款和信任损失。

## 回复质量检查

- 是否准确区分了客户目标、工厂能力和样品后实测结果？
- 是否说明产品处于 R0-R4 的哪一级？
- 是否把固定项写成固定项，而不是“可以试试”？
- 是否避免承诺未知材料、硬度、测试、MOQ、价格或交期？
- 是否只要求一个清晰下一步：接受固定评估样，或进入独立技术开发评估？
- 英文回复是否附有中文审阅稿？
