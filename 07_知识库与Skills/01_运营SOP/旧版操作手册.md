# 贝强外贸运营系统日常操作手册

## 1. 新产品上架流程

1. 将原始资料放入 `01_产品资产/01_原始数据包/`，保留产品图、详情图、颜色图和供应商事实。
2. 使用 `beiqiang-positioning` 判断产品是否符合贝强宽鞋头舒适慢走鞋、休闲慢走鞋或相关工厂供货定位。
3. 使用 `competitor-research-firecrawl` 调研同类公开竞品，记录到 `research/competitors/`。
4. 使用 `alibaba-product-optimizer` 和 `alibaba-international-operations` 生成标题、关键词、属性、卖点、主图方案和详情页结构。
5. 图片 Brief 存入 `alibaba/image-prompts/`，成品上架资料存入 `alibaba/product-listings/` 和 `alibaba/detail-pages/`。
6. 将需要确认的信息列出：材料、鞋底、内里、尺码、MOQ、样品时间、交期、包装、证书、价格。

## 2. 竞品调研流程

1. 明确调研目标：标题关键词、价格/MOQ、卖点、详情页、图片结构或内容选题。
2. 使用 `competitor-research-firecrawl`，只抓取公开网页，不抓登录、验证码、付费墙页面。
3. 将结果保存到 `research/competitors/`，使用 `templates/competitor-research-template.md`。
4. 将关键词拆分到 `research/keywords/`：核心词、差异化词、B2B 转化词。
5. 将可执行结论转给 `alibaba-product-optimizer`、`rfq-quote-assistant` 或 `tiktok-b2b-content`。

## 3. RFQ 报价流程

1. 收集客户信息：产品、数量、市场、尺码、颜色、Logo/包装、交期、贸易条款。
2. 使用 `rfq-quote-assistant` 生成首次报价或补充询问。
3. FOB `8-12 USD/双` 只作为目标区间，不作为无条件固定报价。
4. 将常用话术保存到 `customers/rfq-templates/`。
5. 未确认材料、包装、证书、DDP 费用、FBA 费用前，不给最终承诺。

## 4. 询盘跟进流程

1. 将阿里询盘或 WhatsApp 沟通摘要保存到 `customers/inquiry-replies/`。
2. 使用 `inquiry-follow-up` 生成二次跟进、样品单推进、沉默客户唤醒、WhatsApp 简短消息。
3. 跟进重点：样品、MOQ、尺码颜色、目标市场、包装、交期、下一步确认。
4. 将高频问题反向补充到产品详情页、FAQ、RFQ 模板和 TikTok 选题。

## 5. TikTok 内容生成流程

1. 从产品卖点、竞品缺口和客户高频问题中选题。
2. 使用 `tiktok-b2b-content` 生成 15-30 秒视频脚本。
3. 使用 `image-brief-generator` 生成需要的画面 Brief 或封面 Prompt。
4. 视频脚本保存到 `tiktok/scripts/`，排期保存到 `tiktok/content-calendar/`。
5. 每条内容必须引导 B2B 行动：询价、样品、MOQ、OEM/ODM、混色混码。

## 6. 每周数据复盘流程

1. 收集阿里数据：曝光、点击、点击率、访客、询盘、询盘率、P4P 花费、关键词、产品表现。
2. 收集客户数据：RFQ 数、回复率、样品推进、未回复客户、优质客户画像。
3. 收集 TikTok 数据：发布数、播放、互动、询盘线索。
4. 使用 `weekly-data-review` 生成复盘，保存到 `alibaba/weekly-reports/`。
5. 下周动作必须落到具体任务：优化哪个产品、补哪个关键词、改哪张主图、跟进哪个客户、拍哪类视频。

## Firecrawl 使用边界

- 只做公开网页调研。
- 不抓取登录后页面、验证码页面、付费墙页面和个人隐私内容。
- 不高频抓取；优先 5-12 个高相关页面，分批处理。
- 不把竞品文案直接复制到贝强页面。
- API Key 只放在本机环境变量或 Codex 用户级配置，不写入项目文件。
