# 证据优先决策框架

先区分四类信息：

1. `Buyer Target`：买家想要什么，不代表贝强已经能做到。
2. `Confirmed Capability`：有实物、文件、后台回读或供应商确认支持的能力。
3. `Fixed / Not Adjustable`：现有模具、结构、配方或硬度中不能调整的部分。
4. `Actual Result After Sampling`：成品样品完成后才存在的数据，不提前保证。

一般任务同样遵循：直接事实高于推断；最新对象证据高于旧总档案；一次观察先进入经验，不直接升级为原则；高影响字段缺证据时先确认。
