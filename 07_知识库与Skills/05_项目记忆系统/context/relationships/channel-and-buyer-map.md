# 渠道与买家关系图

| 对象/渠道 | 主要角色 | 需要对齐的事实 |
| --- | --- | --- |
| Alibaba.com | 正规 B2B 商品、询盘、RFQ 与交易信任入口 | 商品事实、价格/MOQ/交期、图片与公开页一致性 |
| 独立站 | 工厂定位、产品证据、落地页和询盘归因 | SKU 事实、有效 CTA、表单与通知链路 |
| 邮件/LinkedIn | 主动找到具名采购、产品或品牌负责人 | 采购触发信号、单 SKU 匹配、停止/退订状态 |
| TikTok/视频 | 展示产品、工厂和质量证据并引导询盘 | 不用消费级夸张承诺；与实际 SKU 和工艺一致 |
| importers/wholesalers | 批量采购和区域分销 | 商务条件、稳定供给、合规与包装 |
| Amazon/TikTok sellers | 单品机会、视觉内容与测试速度 | 英雄 SKU、内容素材、小规模测试路径 |
| brand/private-label buyers | 产品开发、定制和技术验证 | Buyer Target 与 Confirmed Capability 分离 |

具体联系人和互动状态仍以 `04_客户开发/` 的 CRM/客户项目为准。
