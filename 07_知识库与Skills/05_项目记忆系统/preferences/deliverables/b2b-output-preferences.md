# B2B 输出偏好

- 先给结论和下一步，再给必要证据。
- 使用清晰、直接、可执行的语言，减少空泛宣传和零售信息。
- 对不确定内容显式标注“待确认”“推断”或适用条件。
- Alibaba、RFQ 和周报沿用 `AGENTS.md` 规定的输出字段。
- 文件应进入对应业务目录，不在根目录堆放临时交付物。
