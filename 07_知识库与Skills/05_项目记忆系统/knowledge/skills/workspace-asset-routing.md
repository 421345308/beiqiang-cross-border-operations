# 工作区资产路由方法

## 路由顺序

1. 先判断内容是否是业务事实、执行记录、提炼记忆、历史材料或可再生成的中间产物。
2. 业务事实和执行结果放在所属经营环节，项目记忆只保存调用线索、判断框架和简要状态。
3. 已被新入口替代但需要追溯的材料进入`90_归档/`，并在正文顶部标明历史状态。
4. 可再生成、尚未验收或仅服务一次运行的文件进入`99_临时区/`或受忽略的运行目录。
5. 移动正式资产前扫描活动引用；移动后同步入口、索引、脚本配置和执行记录。

## 默认归属

| 内容 | 权威位置 | 不能放在哪里 |
| --- | --- | --- |
| 产品图片、材料、尺码和结构证据 | `01_产品资产/`对应单款目录 | 记忆正文、根目录 |
| Alibaba SOP、审计、批量发品和回执 | `02_Alibaba运营/`对应环节 | 根`outputs/`、个人记忆 |
| 客户互动、报价和发送结果 | `04_客户开发/`对应客户或CRM | 通用经验文件、公开目录 |
| 当前主轴、长期原则和复用方法 | 五层项目记忆库 | 复制整份业务台账 |
| 已失效但需追溯的入口和报告 | `90_归档/` | 当前总控入口 |
| 上传暂存、缓存和可重建结果 | `99_临时区/`或受忽略的运行目录 | 根目录、正式业务目录 |

## 约束

- 单一事实源优先：索引只链接权威文件，不复制容易过期的逐款状态。
- 目录数量、文件数量和素材包数量不能替代业务状态核验。
- 未确认用途或仍承担恢复证据的临时文件只分类，不删除。
- Junction、运行时、依赖和嵌套仓库须先确认调用关系，不按名称相似直接移动。
- 涉及客户数据、账号或内部经营结果时保持`privacy: internal`并留在私有工作区。
