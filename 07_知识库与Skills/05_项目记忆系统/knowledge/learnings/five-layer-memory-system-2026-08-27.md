# 五层个人记忆系统方法

来源：[微信文章](https://mp.weixin.qq.com/s/2Kz2JQK1r606S3quiCFUYg)，正文由用户于 2026-08-27 提供。

- 五类记忆：identity、principles、preferences、context、knowledge。
- 目录最多两级；二级目录下只放文件，用文件名前缀代替更深嵌套。
- 权重与目录绑定；高等级优先，但用户保留最终决策权。
- 每条记忆使用 type、title、description、status、privacy、tags、timestamp 七字段元数据。
- 两层索引：根 `INDEX.md` 是地图，各级 `README.md` 说明收纳边界。
- recall 负责按任务加载；curator 负责提取候选、解释归类、等待确认、写入并同步索引。
- 经验可升级为技能，外部学习可内化为技能，但升级依赖用户判断和实践证据。
- 不全自动沉淀；写入前确认，避免临时或质量不高的判断污染长期记忆。

本文件保存外部方法输入；贝强实际路由规则以本记忆库根 `README.md` 为准。
