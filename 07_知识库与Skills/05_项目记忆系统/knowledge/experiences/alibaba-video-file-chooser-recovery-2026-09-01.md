# Alibaba 视频上传文件选择超时

2026-09-01 观察：Chrome 文件网址权限已开启；素材列表的“上传视频”只打开上传页。上传页语义点击文件输入框仍约 3 秒超时；同会话先监听文件选择、再点击可见上传方块成功。5 页并行提交触发控制超时，改为每批最多 3 个完成。

遇到同类故障时，先确认在真实上传页，再依据当前浏览器工具文档重建操作；不照搬旧坐标、监听 API 或权限假设。提交后从视频银行按名称、VID 与审核状态回读；历史成功不证明今天审核状态。

证据：通用工厂视频 VID `6000342456358`；完整映射见 `02_Alibaba运营/05_扩品工程/批量发品/历史批次执行产物_2026-08-28至09-02/20260831_full_excel_title_video/53款商品主图视频映射_2026-08-31.csv`。

这是特定旧控制链路的 L5 经验。常规任务优先授权 OpenAPI，仅在 API 不支持时进入浏览器；不可推广为所有上传都必须坐标点击。
