# 报价成本与交付核验模板

用途：内部核价与供应交付准备；不是固定报价或无条件承诺。按SKU与报价/订单参考号填写，并链接现有台账，不另建客户主表。商品事实和已确认商业基线取[唯一商品SOP](../../02_Alibaba运营/00_运营SOP/国际站商品全生命周期SOP.md)及单款证据，已确认内容直接复用，只有本单缺口才核实。

## 成本与报价计算

| 成本项 | 金额/币种/单位 | 来源与有效期 | 分摊方式 | 确认/估算/未知 |
| --- | --- | --- | --- | --- |
| 工厂/供应商货价 |  |  | 双/批次 |  |
| 定制、配件、包装与标签 |  |  | 按双或分摊；避免货价已含部分重复计 |  |
| 本次约定由卖方承担的国内运输、检验、出口等费用 |  |  | 按实际约定费用范围 |  |
| 运费、保险、税费、目的地交付等适用项目 |  |  | 仅计卖方承担且核实的项目 |  |
| 平台/支付/汇兑等交易费用 |  |  | 固定或销售额比例分开 |  |
| 一次性打样、模具、测试等 |  |  | 买家另付或本单分摊，明确不重复收 |  |
| 质量处理、返工及其他已知支出 |  |  | 列依据，不用无依据百分比伪装已核成本 |  |

统一币种及费用范围后：

- 本单成本 = 按双成本×数量 + 本单固定成本 + 卖方承担的其他核实费用。
- 订单贡献 = 本单销售收入 − 上述成本 − 尚未计入的销售额比例费用；未计公司固定费用、税费等时不能称净利润。
- 单位成本C为确定金额、目标贡献率m为售价比例，且无其他比例费用时，单位售价 = C / (1−m)。存在售价比例费用r且尚未计入C时，售价 = C / (1−m−r)，分母必须大于0。
- 加价率 = (售价−成本)/成本；利润或贡献率 = (售价−成本)/售价。拿货价加30%不等于售价利润率30%。以上只是条件计算，未知成本不能填0，不能替代市场竞争与供应核实。

## 样品、批量与交付准备

| 核查 | 所需内容及完成标准 | 证据/状态 |
| --- | --- | --- |
| 样品 | 实样/版本、目的、交付物、成本及运费、时间；技术样读[技术询盘SOP](../01_运营SOP/技术型品牌买家询盘评估SOP.md) |  |
| 实物质量 | 对应色码/批次、做工与结构、代表尺码测量、已知问题；图片不能当测试结果 |  |
| 大货验收 | 以批准样和书面规格确定材料/尺码/色差/包装、检查方法与缺陷处理；未约定的验收阈值不编造 |  |
| 供方与备选 | 当前报价、数量与色码条件、交期起算、款式/结构是否允许替代；未经买家确认不换款 |  |
| 市场与单证 | 具体目的国、进口责任及需要的材料/标签/主体/文件，逐项核真实证据；平台可见不证明准入 |  |
| 运输 | 收货地、箱规、毛重、运输方式、有效运价、卖方责任范围；DDP/FBA未知税运不报价为包干已确认 |  |
| 异常与售后 | 短装、缺陷、延期的通知、证据与处理约定；不先承诺无限退款或补货 |  |

## 对外报价与回写

对外只保留款式/版本、数量与色码、单价/总价/币种、贸易条件及费用包含/不包含、样品或大货时间的起算、付款与有效期、关键确认项。内部采购成本与客户隐私不随报价公开。

状态用“可讨论 / 条件报价 / 已核实正式报价 / 待买家确认”分清。确认后回现有CRM、报价或订单记录；供给缺口回单款任务包，不把制作模板当作已取得供方答复或交付能力。
