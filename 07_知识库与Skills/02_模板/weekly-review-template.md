# 经营数据复盘模板

适用于定期复盘及一次动作完成后的即时复核。无需等到下周再实施已明确的必要工作；只在相应观察窗口足够时判断经营效果。

## 数据范围

- 开始/结束时间、时区、提取时间：
- 渠道、账户、商品ID/产品家族/活动ID与币种：
- 来源文件、后台证据或正式回执：
- 去重单位（买家/公司/动作/商品行），同款链接归并方法：
- 缺失、不可见、未追踪、确认零分别标记；对比窗口是否一致：

| 阶段 | 本期 | 可比前期 | 口径与证据 | 主要问题 |

| 点击/产品承接 |  |  | 同一搜索口径CTR；表单开始另计 |  |

分渠道、市场和产品家族观察，主表以原始台账为准，不在复盘表复制客户联系方式。漏斗计算复用[口径校验工具](../../08_工具链/01_业务脚本/funnel_metrics.py)。没有关联分母、不同时区/币种/渠道或不同观察窗口，不计算混合转化率和环比。

## 商品与买家反馈

- 搜索词/买家问题及需求来源：
- 已有曝光低点击、点击后低采购推进的具体SKU与证据：
