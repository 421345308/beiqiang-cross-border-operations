编辑建议（不是平台强制像素规则）：首图优先正侧面完整鞋型、真实颜色和清楚的加绒版本，主体约占画面七至八成；使用干净背景，去掉大火焰、悬浮燃烧鞋底和多余宣传圈，保留真实阴影与鞋口细节。先1:1清晰图，不为非必填3:4自动拉伸原图。首图不塞价格、平台标记、二维码或未经验证口号。

后续图片按可用证据排列：颜色版本 → 实际绒里/鞋口 → 已有真实鞋底或穿脱结构 → 核准尺码选择。不同颜色不是同一张鞋涂色；普通版外观不能变成加绒里料证据。R1811有真实鞋内视角，731有上脚/鞋底视角，可优先利用；H7116/H7212只有俯视主图，补侧面仍是缺口。没有脚长或内长表，不生成换算表或“偏大一码”建议。
