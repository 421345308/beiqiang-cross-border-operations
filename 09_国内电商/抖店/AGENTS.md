# 抖店执行入口

先读本目录[经营入口](README.md)和所属店铺当前档案；内容方法读[商品内容SOP](商品内容SOP.md)。本入口只维护渠道执行边界，单款材料、尺码、价格、服务及历史例外回对应业务记录。

- 共用产品身份与供应来源回[产品中心](../../00_总控台/产品中心/README.md)；[渠道对应](数据/渠道产品对应.json)分别记录店铺、商品、版本和SKU。未匹配项保留待绑定，不凭外观或相似货号合款，不继承国际站批发基线。
- 国内零售按消费者选款、版本、穿着场景及选码表达；主图、详情、材料与尺码只用本款证据。图片估值、标准脚长、实测鞋内长分开；普通版与加绒版不互相证明。已确认的材料判断范围和单款例外见经营入口，不反复询问。
- 价格、券、活动、库存和履约取所属店铺当前已确认档案。平台数量不等于实物盘点；新授权覆盖其范围内的旧基线，早期单批限制不成为全店永久禁令。
- 已授权国内妙手直接HTTP及本机会话持久化，优先复用[调用入口](../../08_工具链/01_业务脚本/抖店妙手/README.md)。新旧店会话、主体、商品与活动隔离，写前核实际目标店和当前字段，不把默认会话当目标店。
- 写前保存基线与拟改范围；核价格单位、类目、素材及SKU身份，每对象提交一次。结果未知先回读，现存规格改名可能重分配编号，须查业务记录中的实际机制与映射，不能顺带批改。
- 提交、审核、正式字段、媒体顺序/颜色绑定、H5、App选码及实际核销分别验收。接口成功或评分不代替买家体验；发布与成交、退款、广告归因和利润分别评价。
- 品牌资质、账号绑定和物流共享按本店真实状态处理；登录不证明可改绑，迁店意向不授权解绑、关店或改认证。外发、促销及投流按实际授权范围执行。
- 账户、商品/SKU/券精确ID、原始经营数据、请求回读及凭证仅留既有受忽略位置；公开Git只同步允许公开的规范、代码、产品准备内容和核验摘要。当前结论回原档案，必要取舍留对应问题旁，不在本页按会话累加规则。
