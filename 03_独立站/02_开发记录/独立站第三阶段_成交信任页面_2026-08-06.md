# 独立站第三阶段：成交信任页面

更新：2026-08-06（中国时区）

## 目标

这一阶段不是增加普通的“公司介绍”，而是解决买家从看完产品到愿意提交询盘之间的四个问题：

1. 贝强是否有真实的工作环境和产品处理证据。
2. 检查、分拣、包装前需要确认哪些订单细节。
3. OEM/ODM 如何开始，哪些内容不能在可行性检查前承诺。
4. 从选款、样品到大货、包装和出货协调的下一步是什么。

## 已完成的网页

- `/factory/`：真实车间图、产品方向到样品验证的工厂侧路径。
- `/quality-packing/`：手工检查、批次分拣、纸箱准备证据和逐单确认清单。
- `/oem-odm/`：现有基础款调整和新方向开发简报两条路径。
- `/sample-order-process/`：选款、规格确认、样品、大货确认、检查包装与出货协调。

四个页面已接入全站导航、首页信任入口、所有产品详情页和网站地图，最终导向已有询盘表单、WhatsApp、邮箱和 Alibaba.com。

## 内容边界

- 只使用 `00_精选可用照片` 中已筛选的真实素材。
- 不公开未确认的产能、年限、证书、客户品牌、价格、MOQ 或交期。
- OEM/ODM 统一表达为“可讨论并需根据款式、数量和样品确认可行性”，不做无条件承诺。
- 检查页展示实际处理场景，不写成未经证实的认证质量体系。

## 发布前验收

- 使用 Node.js 22 以上运行 `npm test`、`npm run edgeone:build` 和 `npm run lint`。
- 确认四个静态页面全部导出，图片路径无缺失，sitemap 包含四个 URL。
- 检查业务邮箱固定为 `421345308@qq.com`，并检查 WhatsApp 与询盘路径。
- 检查页面不含医疗、矫形、假证书、假产能或无条件定制承诺。

## 下一阶段建议

1. 制作可下载的英文 Line Sheet，按买家意图展示主推款，下载前采集公司、市场、数量和联系方式。
2. 为每个重点产品绑定对应 Alibaba.com 商品链接，而不是统一跳店铺首页。
3. 建立询盘到样品、报价和订单的跟进状态，形成每周转化数据复盘。
