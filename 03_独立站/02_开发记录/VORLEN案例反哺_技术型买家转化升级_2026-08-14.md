# VORLEN 案例反哺：独立站技术型买家转化升级

日期：2026-08-14
性质：开发需求与验收标准，暂未修改独立站源码

## 问题

当前独立站已经强调“样品前确认规格”和“OEM/ODM 先确认可行性”，方向正确。但 VORLEN 案例说明，品牌技术买家仍需要网站更明确地区分：

- 现有基础款调整。
- 固定结构评估样。
- 新材料/新模具/性能参数开发。

如果三类项目都使用同一个 `Request this sample` 入口，买家可能把网站上的基础款图片理解为已经具备完整技术数据和任意参数定制能力。

## P0：先修正 BQ009 信息模型

当前 BQ009 页面使用 `Athletic-footwear importers`，并把鞋底写为报价前确认。后续源码实施时应：

1. 将买家方向收窄为 `athletic-casual / walking footwear buyers`，避免无证据地靠近高性能跑鞋。
2. 在产品数据中增加准备度字段，例如：

```ts
readiness: "physical-sample" | "component-reference" | "measured" | "tested";
customization: {
  confirmed: string[];
  fixed: string[];
  afterSample: string[];
  separateReview: string[];
};
```

3. BQ009 只使用原款真实图片；组合橡胶参考鞋底不得出现在同一产品页面。
4. 在材料确认前不新增性能、橡胶或双密度字段。

## P1：改造 OEM/ODM 页面

新增清晰的路径选择：

### Existing Style Adaptation

- 选择产品编号。
- 讨论已经确认可行的颜色、Logo、鞋垫、标签和包装。
- 样品用于确认 fit、外观、材料和工艺。

### Technical Product Development

- 说明鞋楦、鞋底模具、材料体系、硬度、结构和测试目标。
- 先做内部和供应链可行性审查，再报价。
- 不保证每个目标在每个数量下都可实现。

在页面中增加一句核心边界：

```text
Buyer target values are reviewed as development requirements. They become confirmed production specifications only after factory and component-supplier approval.
```

## P1：改造询盘表单

增加字段：

- Project path: Existing style / Technical development
- Product code or reference
- Existing sole acceptable: Yes / No / Unsure
- Changes required: upper / last / sole / hardness / material / branding / packing
- Required test standards or target values
- Sample quantity
- Estimated bulk quantity
- Target market and sales channel
- NDA or tech pack required: Yes / No

表单提交后，后台标签至少包含：

- `base_style_adaptation`
- `technical_development`
- `fixed_sole_acceptable`
- `custom_tooling_required`
- `test_data_required`
- `nda_required`

## P1：改造样品流程页

增加两种样品定义：

1. `Evaluation Sample`：使用固定现有结构，生产后提供实际观察和实测；不保证命中尚未确认的目标值。
2. `Controlled Development Sample`：只有目标参数、容差、测量方法和可行性已书面确认后才能下单。

订单页面应展示：样品目的、交付物、验收标准、排除项。

## P2：建立技术资料与尽调入口

- 产品技术资料卡下载：只展示已确认字段，未知项不填假值。
- 公司尽调页：中英文法定公司名、注册地址、Trade Assurance 主体一致性说明。
- 营业执照：不直接公开高清原件；买家提交公司信息和用途后，提供带接收方水印的版本。
- NDA/tech pack：先完成非机密可行性问卷，再进入 NDA 审阅和签署。

## 验收标准

- 买家能在 30 秒内判断自己属于基础款调整还是技术开发。
- BQ009 页面不暗示双硬度、橡胶底或高性能跑鞋能力。
- 表单可以提前识别新模具、目标硬度、测试和 NDA 需求。
- 自动回复不直接承诺样品价、量产价、交期或技术目标。
- 技术目标、现有能力、样品后实测值在后台记录中属于不同字段。
- 修改源码后单独执行独立站的 `npm test`、构建和 lint，再在独立站仓库提交。
