# 独立站产品事实补齐第三批：R1811

日期：2026-09-03
范围：独立站 BQ015 / 源款号 R1811 / Alibaba Product ID `1601839073314`

## 一、为什么处理这一款

网站 BQ 编号与历史 Alibaba 运营记录存在过编号漂移：网站中的 BQ015 对应 R1811 和 Product ID `1601839073314`，而旧国际站记录曾把同一商品写为 BQ-020。仅按 BQ 标签迁移事实可能把 R1811 的属性误写到网站 BQ020/A218，或与 BQ006/M8811 混淆。因此本批始终用“网站款号 + 源款号 + Product ID”三键核对。

## 二、证据与结论

权威本地回读记录为`02_Alibaba运营/02_单品优化记录/R1811全面只读审计_2026-08-04.md`。该记录的 Alibaba trunk 明确包含：

- Upper Material：Stretch Fabric；
- Midsole Material：EVA；
- Outsole Material：EVA；
- Lining Material：Mesh；
- Style：Walking Shoes；
- 页面身份：R1811 / `1601839073314`。

用户此前在对应公开商品页确认“鞋面是弹力织物”。网站数据包同时保留 regular / selected fleece-lined 的颜色方向，所以本批不把 Mesh 扩大为所有颜色和所有订单的固定里料，而写成“Alibaba 在售配置已记录 Mesh 里料”；加绒版本继续按所选颜色确认。

## 三、网站改动

1. BQ015 鞋面由`Textile upper`改为`Stretch fabric upper`。
2. 鞋底由待确认改为`EVA sole`。
3. 短描述改为弹力织物系带方向。
4. 英文页新增`Mesh lining recorded in Alibaba trunk for the listed configuration`。
5. 保留`Fleece availability by color`和具体订单准确材料执行确认。
6. 中文产品页新增通用“已记录配置证据”字段，只展示明确标记来自 Alibaba trunk、产品资料包或来源资料包的事实。
7. 修复第二批遗漏：BQ009 中文品名由错误的“透气网布厚底运动步行鞋”改为“透气针织弹力织物系带步行鞋”。

## 四、防错门禁

- 产品对象测试同时锁定 BQ015、R1811、`1601839073314`；
- 验证 Stretch Fabric、EVA、在售 Mesh 配置与按颜色确认加绒同时存在；
- 中文渲染测试要求“已记录配置证据”在可见 HTML 中出现，不能只存在于 RSC 数据载荷；
- BQ009 中文品名纳入回归测试；
- 不根据旧 BQ 编号、相似标题或鞋图外观迁移事实。

## 五、Accio Work只读查询失败复盘

本轮先按当前 Workctl schema 流程尝试只读发现命令。`workctl auth status`显示 Alibaba 凭证存在，但`workctl schema`被平台拒绝，原因为`desktop_not_attached`：当前命令进程没有由 Accio Desktop 启动，也没有`ACCIO_GATEWAY_TOKEN`。这不是商品字段为空，也不是 R1811 无详情；不能据此重复创建内容或改用旧接口。恢复方法是在 Accio Desktop 附着的进程中重新读取 schema，再做平台二次回读。
