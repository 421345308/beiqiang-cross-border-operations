## 2. 买家从了解产品到正式下单

```text
进入英文/中文站
  → 浏览30款产品、集合、采购方案、工厂与采购指南
  → 查看单款证据，选择2–4款比较或最多12款加入询价单
  → 分享/打印内部选款材料
  → 填写逐款数量、颜色、尺码、样品、市场、目的地和贸易条件
  → 通过提交前完整度提示补足关键资料
  → 获得询盘编号和20位私密查询码
  → 在私密项目中消息、传文件、审核样品、查看/回复报价
  → 接受报价后申请建立正式订单
  → 贝强核对八项订单就绪资料
  → 转入Alibaba Trade Assurance或双方签署合同
  → 网站继续同步买家安全的履约、文件、异常和收货/复购记录
```

重要边界：网站中的比较、PDF、询盘、shortlist、样品记录、报价接受和建单申请都不是自动生产订单。只有正式Trade Assurance订单或经双方签署的合同及相关付款证据才是外部正式交易依据。

## 5. 业务员后台入口与日常使用

后台地址：`https://www.beiqiang.online/admin/inquiries/`

访问凭据：EdgeOne生产环境中的`INQUIRY_ADMIN_TOKEN`。它不是买家查询码、QQ邮箱密码或GitHub密码。

每天建议顺序：

1. 打开“今日成交工作台”，先处理买家新消息、待签发/待审核动作和逾期事项。
2. 对新询盘核对公司、市场、款号、数量、联系方式和采购简报完整度；不要只看分数。
3. 资料不足时一次追问最关键的1至3项；资料明确时进入shortlist、样品或报价路径。
4. 每个活跃项目设置负责人、一个明确下一动作和日期。
5. 报价先保存不可覆盖草稿，人工复核后再签发；条款变化必须新建版本。
6. 样品必须记录实物样编号、交付物、标准和排除项；买家批准只能来自私密买家动作。
7. 接受报价后检查建单申请和八项订单就绪摘要，再建立Trade Assurance订单或合同承接。
8. 已确认订单的关键变更必须建立买家批准提案；普通履约更新不覆盖订单商业版本。
9. 文件先看隔离状态；网站没有内置病毒扫描，必须按线下检查流程记录后再开放普通下载。
10. 每周保存经营快照并导出中文Markdown周报，将网站订单数字与真实Trade Assurance/合同记录核对。

## 8. 新增或修改产品时怎么维护

1. 产品事实先回到`app/data/products.ts`及对应SKU证据核对，不从图片外观推断宽楦、材料或性能。
2. 同步中文名称、图片目录、网页缩略图/详情衍生图、集合关系和Alibaba商品ID。
3. 运行目录一致性、图片预算、完整测试、EdgeOne导出和代码检查。
4. 推送GitHub `main`后核对EdgeOne生产部署，不以本地构建代替线上成功。
5. 更新本能力地图、功能总盘点和增长SOP；记录提交、部署、测试和未完成边界。
