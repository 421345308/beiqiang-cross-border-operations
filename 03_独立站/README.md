# 贝强独立站项目

独立站代码已经单独纳入 GitHub 版本管理，并持续用于后续开发。

- 本地源码：`03_独立站/03_网站源码/`
- GitHub：`https://github.com/421345308/beiqiang-footwear-site`
- 生产分支：`main`
- 当前本地开发分支：`codex/edgeone-github-deploy`
- 部署：GitHub `main` 推送后由 EdgeOne 自动构建和发布
- 正式域名：`https://www.beiqiang.online/`

## 为什么不放进经营仓库的 Git 历史

网站源码本身已经是一个独立 Git 仓库，拥有自己的提交、分支、测试、发布和回滚历史。根经营仓库只记录网站的运营计划、开发记录和仓库入口；如果再次直接收录源码，会形成嵌套仓库，父仓库通常只能记录一个 Git 指针，不能正确管理内部改动。

## 后续开发流程

1. 在 `03_独立站/03_网站源码/` 中创建或继续 `codex/*` 开发分支。
2. 修改后运行该项目自己的测试和 EdgeOne 构建。
3. 在独立站仓库提交、推送并合并到 `main`。
4. 验证正式域名、产品页、询盘表单、通知和后台台账。
5. 把商业结论、上线记录和指标结果更新回根经营仓库。

当前源码目录存在尚未提交的页面与信任模块改动。它们属于独立站仓库，不能由根经营仓库代替提交。
