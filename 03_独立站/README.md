## 开发与落盘

1. 在源码独立仓库的 `codex/*` 分支继续开发，保护已有未提交内容。
2. 按改动运行网站自身的必要测试与构建，再在该仓库独立提交、推送和合并。
3. 发布后核验正式域名及受影响页面、询盘、通知或后台链路，记录实际通过范围。
4. 将开发结论、发布回执和运营结果写回 `02_开发记录/`；日常流程更新 `01_运营SOP/`。根经营仓库不收录网站源码、依赖或构建产物。
