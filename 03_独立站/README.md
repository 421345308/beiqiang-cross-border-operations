## 为什么不放进经营仓库的 Git 历史

网站源码本身已经是一个独立 Git 仓库，拥有自己的提交、分支、测试、发布和回滚历史。根经营仓库只记录网站的运营计划、开发记录和仓库入口；如果再次直接收录源码，会形成嵌套仓库，父仓库通常只能记录一个 Git 指针，不能正确管理内部改动。

## 后续开发流程

1. 在 `03_独立站/03_网站源码/` 中创建或继续 `codex/*` 开发分支。
2. 修改后运行该项目自己的测试和 EdgeOne 构建。
3. 在独立站仓库提交、推送并合并到 `main`。
4. 验证正式域名、产品页、询盘表单、通知和后台台账。
5. 把商业结论、上线记录和指标结果更新回根经营仓库。
