# 独立站任务路由

先读本目录 [README](README.md)。渠道角色、Google当前数据和接入依赖只在 [全渠道增长总控](../00_总控台/全渠道增长总控.md)维护，不复制历史快照为当前状态。

| 任务 | 必读 / 执行位置 |
| --- | --- |
| 收录、SEO、GEO、AI来源与搜索内容 | [搜索运营SOP](01_运营SOP/搜索与AI可发现性运营.md)，随后查当前公开页面与Search Console |
| 源码、渠道归因、表单、后台、部署 | `03_网站源码/` 当前分支及改动；必要测试、构建、部署回执，保护其他任务工作区 |
| 商品声明与网站选款 | 对应SKU原件及根商品边界；旧网站产品数不代替当前来源核验 |
| 询盘通知与采购推进 | 网站真实提交/通知证据，客户只回 `04_客户开发/` 原CRM或客户项目 |
| 接入数据或社媒接口 | [接口与插件](../08_工具链/04_MCP与Workctl/渠道接口与插件.md)，仅复用已验证接入能力 |

网站源码是独立Git仓库。开发结论和部署回执回 `02_开发记录/`，搜索原始证据回 `03_搜索与渠道数据/`，日常方法原地更新SOP。根仓库不收录源码、依赖、客户提交或凭证。

先核最新远端与正式域名；旧分支与旧报告不是生产现状。API成功、构建成功、Git推送、平台部署成功和正式域名验收分别判断。公开页面HTTP200只证明该次访问，不代替Googlebot/CDN抓取及Google索引状态。对索引/结构化数据错误先读具体错误和受影响URL，再修改对应实现。
