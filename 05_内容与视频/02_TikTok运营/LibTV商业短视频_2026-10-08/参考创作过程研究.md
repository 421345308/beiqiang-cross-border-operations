# 参考作品怎样从场景走到产品

2026-10-08。本轮研究回应用户对静态陈列方案、跳过参考创作过程的批评。旧制作方案、对应制作节点及“鞋的试镜”试写已实际删除，没有另存备份；真实产品原件和参考作品保留。

## 指定运动画布：可见的创作链路

[源画布](https://www.liblib.tv/canvas?projectId=78e7999de82844b5a370d4f2cd957a02&spaceId=10758443)包含六段约15秒原视频及对应分镜、人物和产品参考、剧本文本、风格指令和放大结果。本轮读取了全部31个内容节点、分组与连线，核对全部六张分镜与六段视频。没有找到可确认的90秒剪辑成片，不能把六个生成片段当成已经完成的整片。

| 可见环节 | 作者实际准备的内容 | 对制作的作用 |
| --- | --- | --- |
| 场景与情绪 | 热感、运动负荷、风感释放、日常延展 | 先给观众感受，再让鞋进入表达 |
| 剧本细化 | 动作、景别、机位、时长、声音提示 | 把抽象感受变成可生成、可核查的镜头 |
| 风格提取 | 从参考中抽取色彩、光线、质感与节奏 | 统一画面语言，不照搬参考产品和情节 |
| 人物与产品探索 | 带环境的人物图、产品氛围图，再提取干净人物/产品图 | 分开解决场景感觉与人物、鞋的外形一致性 |
| 分镜图 | 六段各自的多格画面 | 提供构图、景别和动作顺序的视觉依据 |
| 动态生成 | 分镜＋人物＋产品混合参考；产品CG段只用分镜＋产品 | 参考按用途分工，不给每个镜头塞同样的资料 |
| 后处理 | 已有片段再放大 | 改变技术规格，不能补救叙事缺失 |

值得特别纠正的细节：画布中的作者指令明确要求保留既有场景叙事，不强套“开场—出现—细节—高潮—扩展—结尾”结构；Marshall耳机文本是镜头描述格式参考，不是这支鞋片的内容。此前把它变成产品目录模板，偏离了可见创作要求。

两份细化脚本均可见，但较晚脚本的时间在首段生成之后，不能推断它就是首段实际使用版本。画布没有完整试错对话，不能编造作者返工次数、隐藏提示或全部迭代顺序。

## 六段实际画面与叙事关系

下面按叙事顺序排列，不按素材抓取顺序。画面由实际视频帧序列与逐段视频理解交叉核对；“作用”一栏是创意解释。

| 段落／视频节点 | 观察到的画面 | 在这个参考里的作用 |
| --- | --- | --- |
| 场景启动 `v-gfA1Gl84Ts` | 城市场地、地面、鞋进入、系带、人物面部、跑动和球类动作 | 人和行动先建立产品出现的理由 |
| 身体负荷 `v-OTO4ladWTo` | 汗水、衣料、握拍、脚步、球靠近鞋、鞋面网眼、呼吸与屈伸 | 身体感受把观看注意力带到鞋的细节 |
| 产品转译 `v-boCeBWxVyJ` | 悬浮鞋、鞋底与网眼、蓝色气流、半透明结构、产品落幅 | 用广告CG回应前面的感受；不构成实物性能证明 |
| 回到运动 `v-fdaGEec535` | 同一组人物回到球场，脚部风感、球类动作、跳起、人物近景、同行 | 产品表达回到原场景，形成前后关系 |
| 日常延展 `v-vOhBeE2MpP` | 湖边开阔空间、系带、步行、错身、回头、远去与鞋部特写 | 光线、空间和人物状态共同延展情绪 |
| 产品收束 `v-RQFGSFW9Fx` | 鞋盒与包装纸、鞋部特写、穿鞋腿部、产品陈列 | 陈列在体验之后承担记忆，而非撑满整片 |

动态不只来自镜头推近。系带、触地、屈伸、握拍、球与鞋的相对位置、人物返回等动作，让镜头之间有关系。空间、景别和画面密度的变化也参与表达。漂亮背景本身不足以建立这些关系。

六张原分镜已逐张看过：虽然文字常要求4×3／12镜，实际五张是4×4／16格，一张为4×3／12格。视频也有合并、取舍和重新组织，不能拿提示词中的镜头数当作实际完成数。本轮尚未逐帧确认鞋型一致性、接触物理与全部动作瑕疵，不把参考自动评为生成质量合格。

## 补充案例：使用过程与剧情如何组织动态

**饮料UGC演示，约14.86秒。** [来源帖](https://x.com/AIwithkhan/status/2076893397256695952)。视频上方是动态，下方保留十镜分镜；逐镜写ACTION、ANGLE、LIGHTING、PACING。能对照看到人物展示、产品特写、开罐、柠檬与液体、倒入杯中、饮用、人物反应、户外使用和产品收束。人物使用与商业特写围绕同一过程组织。它说明分镜可以先把产品怎样参与人的行为写具体，随后逐项检查动态结果。实际画面有MINIMAX／Hailuo水印，不能凭案例库名称就认定它由Seedance生成；也不能把AI表演当成真实用户评价。

**跑鞋剧情案例，约30.14秒。** [来源帖](https://x.com/SyntheSarah/status/2096099021152498159)。约前7秒建立工作室任务压力，中段转入水面、城市和山地跑鞋动作，随后回到人物、客户消息和反应，最后收束产品。产品动态被放进一个事件，返回人物的镜头让它不只是运动素材拼接。这是第三方AI创意案例，不能称为Nike官方广告。

这两条是从现有案例库补充研究的案例，不冒称用户此前指定的另外两条作品。已检查实际视频帧序列；自动语音转写只取得少量句子候选，尚未实际试听配乐、音效与混音，不能给声画节奏作完整评价。

## 这次真正改正的制作判断

贝强可以多款，但“几双鞋各占几秒”应当晚于场景选择。先有具体的人、正在发生的事、动作和感受，才判断哪一款鞋应该出现、该看到哪个细节，以及换款是否帮助叙事。多款若只增加陈列数量，会继续重犯旧方案的问题。

贝强工厂IP需要与前面的产品选择建立联系：观众先理解某种穿着情境与需求，再理解贝强怎样理解、开发和制造对应产品。工厂表达可以贯穿产品选择和设计语言，具体呈现仍需创意讨论；本轮不预设必须拍车间，也不把最后加一个厂名当成IP已经建立。用户不提供真实工厂素材，仍可做人物演绎和概念视觉；实际制造能力必须有真实依据，不能用生成车间和性能CG代替。

这不是把运动参考的六段压成30秒。参考给出的可复用方法，是先建立场景与行动、分开整理风格和内容、明确参考图各自职责，再用真实动态验证分镜意图。贝强的新创意尚未定稿，本轮不再抢先命名或搭建另一套固定方案。
