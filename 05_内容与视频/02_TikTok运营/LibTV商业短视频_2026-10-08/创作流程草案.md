# 贝强国内抖音产品品牌片｜创作流程草案

日期：2026-10-08。状态：讨论稿，尚未确定脚本、SKU、模型及预算。关联事实、参考范围与授权见 [PROJECT.md](PROJECT.md)。本文件是项目方案，不是长期偏好或公司能力证明。

## 已确认的任务

面向国内抖音上的贸易商、品牌方及采购客户，制作30秒以内的商业短视频。允许多款鞋共同出现，突出贝强企业品牌及产品/制造专业性；本次不要求提供真实工厂内容，不走真人出镜或工厂纪实路线。先搭建创作和审片过程，再准备制作。

## 推荐的商业任务

首片让买家记住贝强、理解展示的产品方向，并愿意进一步看款或沟通采购需求。它承担认识入口，不把所有产品、工艺和交易条件塞进30秒。

“工厂 IP”在本片中按企业品牌识别理解：反复出现的贝强名称、产品方向、视觉与声音。单条形象片建立第一印象；持续内容才逐渐形成稳定识别和信任。

建议先做产品主导的品牌片。运动参考的镜头质感、产品锚点和音乐组织可借鉴；其运动强度、冷感特效、90秒结构不直接迁移。

## 产品与生产能力的表达分工

| 要表达的内容 | 可用画面/信息 | 制作前核查 |
|---|---|---|
| 产品方向与系列感 | 有共同主题的多款陈列、相同机位转场、关键外观细节 | 对应真实SKU和原始包；不能将配色变化当品类扩展 |
| 产品观感与日常用途 | 真实产品锚定的品牌空间、适度上脚与生活场景 | 鞋型、织纹、鞋底和穿法一致；用途不越过单款证据 |
| 制造专业性 | 经确认的工艺说明、细节对应关系、明确的示意动画 | 工艺确为贝强相关能力；示意不得冒充实际生产记录 |
| 自有工厂产品身份 | 贝强身份与具有原始包映射的入选款 | 外采款不归入自产展示；有鞋不等于有当前库存 |
| 产能、质控结果及交付 | 可核实的资料及后续采购沟通 | 当前数据和适用范围；无依据则不进入脚本 |

AI画面可以表达制造理念，不能独立证明生产规模。没有结构依据时，不能用自动生成的爆炸图虚构内部部件；改用可见鞋面、缝线、鞋底纹路等外观细节。无需为本片另拍车间。

## 创建流程与阶段产物

| 阶段 | 本阶段要完成的工作 | 可检查的产物与完成条件 |
|---|---|---|
| 1. 定商业任务 | 确认买家、一个记忆点和一个下一步 | 一页简报；“贝强是谁、展现什么、让买家做什么”可各用一句话说明 |
| 2. 核对并选款 | 按原始包和实拍筛组合，梳理每款允许表达的细节 | SKU/图片/来源/可用主张对照表；每款有明确镜头角色 |
| 3. 分析参考音画 | 逐段识别镜头、动作、声音及二者关系，标注借鉴与舍弃 | 带时间戳的参考分析；先完成小样音画理解实测，未接通不能称已完整审片 |
| 4. 定创意与视觉 | 比较少量有差异的方向，确定品牌空间、灯光、颜色和声音基调 | 中心创意、参考板、关键构图草案；看图能认出同一系列 |
| 5. 写脚本和镜头表 | 先确定全片节奏，再安排多款与制造信息 | 秒数/画面/产品/声音/字幕/证据/素材来源逐镜对应，总长不超过30秒 |
| 6. 准备LibTV任务 | 独立新项目，按官方CLI和当前模型规格整理参考、提示词和连接关系 | 每个镜头可追溯至SKU、输入图和脚本；明确模型、报价、用量及需测试的难点 |
| 7. 小样后再制作 | 先验证最可能失败的产品或动作镜头，通过后补齐全片 | 用户当次明确确认付费生成范围后执行；保留任务及版本，不以生成成功代替可用 |
| 8. 剪辑和声音 | 统一音乐节奏，准确制作中文品牌/字幕/采购引导 | 完整候选成片；不用各段独立配乐硬拼；素材和音乐使用范围明确 |
| 9. 全片验收 | 分别检查商业表达、产品一致性、动态和声音 | 时间戳问题单、修订版本与验收记录；生成、导出、验收分别记状态 |
| 10. 发布与复盘 | 按明确发布授权执行，观察采购沟通质量 | 发布记录；看款/需求/报价或样品讨论等反馈，不以播放量替代商业结果 |

当前在阶段1—3之间；阶段6以后尚未开始。新建LibTV画布时保留原参考项目不动；本轮不做远端生产操作。

## 多款选择原则

起步建议约3款，数量为提案而非已锁定标准。设置一个视觉主款，其他款有不同的形态、场景或产品方向；整片仍围绕一个主题。避免每款平均分时、快速翻目录，或把不相干的人群/用途强拼。

BQ001与BQ002已有原始包和实拍核查，但外观接近；选款阶段需继续比较其他可追溯自产款，不因现成素材较多就默认选它们。最终名单附核查理由。

## 约27秒的节奏示例

这是用于检查信息密度的框架，不是定稿脚本。

| 时间 | 画面任务 | 希望买家得到的信息 |
|---|---|---|
| 0—3秒 | 主款在统一品牌空间出现，贝强识别自然进入 | 这是贝强的鞋类产品内容 |
| 3—11秒 | 不同款以共同构图与节奏接续，保留清楚的整体鞋型 | 有明确产品方向和可看的系列 |
| 11—20秒 | 少量准确细节及经核实的工艺表达 | 理解产品的具体特点与制造专业性 |
| 20—24秒 | 多款回到同一场景，形成系列画面 | 将产品组合与贝强绑定 |
| 24—27秒 | 企业名称与一个采购行动 | 进入看款或需求沟通 |

开头不做长Logo动画；贝强不只在片尾露出。未证实工艺信息时，11—20秒改用产品外观与场景，不用虚构制造画面补位。片尾“贸易商/品牌采购，私信看款”可作为待讨论文字，不附未经核实的产量、时效或服务承诺。

## 音画理解与验收安排

LibTV继续负责指定的画布/生成流程；音画联合理解另行核实入口。候选Gemini支持视频与音频语义分析，但当前没有完成连接及样片调用，不能写成已具备完整审片能力。Hypit现有配置也未接通转录服务。

接入后先用已下载的参考片段测试：能否正确按时间描述动作、切镜、音乐/音效/语音及它们的对应关系；再和实际关键帧、音轨及连续动作检查核对。快速鞋部动作不能只靠低频采样判断。语音转录不等于听懂配乐和音效。

成片验收须覆盖：鞋型与款式一致；动作接地和变形；镜头衔接与节奏；音乐、音效和字幕的对应；声音突变、削波及静音；中文文字准确；制造表达的事实来源；品牌记忆和采购引导。无法由当前工具判断的部分明确记为未验收，不伪称已原速看完或听完。
