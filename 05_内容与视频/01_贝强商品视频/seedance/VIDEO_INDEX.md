- Keep the `.mp4`, `.json`, and `_frames` directory on the same base name.
- Keep the original Seedance task ID inside the JSON metadata and review record rather than in the public-facing filename.

## video-use Post-Production

The installed `video-use` Skill handles editing after Seedance generation. It does not replace Seedance.

Prepare or refresh a SKU project:

```powershell
python .\08_工具链\02_视频工具\video_use\prepare_product_edit.py `
  --sku BQ001 `
  --seedance-dir .\05_内容与视频\01_贝强商品视频\seedance
```

Project outputs:

- `05_内容与视频/01_贝强商品视频/seedance/edit/BQ001/`
- `05_内容与视频/01_贝强商品视频/seedance/edit/BQ017_A008/`

Use product-only mode for generated clips with music but no speech:

1. Read this index and the SKU review.
2. Inspect source clips with `timeline_view.py`.
3. Propose the cut, caption, music, and CTA strategy before rendering.
4. Add real English overlays in post-production instead of generated text.
5. Render a preview and inspect the first two seconds, every cut, and the final two seconds.
6. Record remaining product-identity defects in the SKU review.

ElevenLabs is optional for product-only edits. Configure `ELEVENLABS_API_KEY` later only when word-level transcription, voice-over editing, or speaker diarization is required.
