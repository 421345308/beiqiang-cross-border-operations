# 抖音 AI 鞋类带货制作方法研究

更新时间：2026-10-16。当前阶段：参考研究完成；贝强实鞋试拍尚未执行。

## 当前结论

这条教程展示的是“人物、产品、场景分别准备 → 从参考片整理脚本 → 绑定参考素材 → 生成竖版鞋类展示片”的流程。最有用的部分是素材分工、去掉冲突提示词，以及围绕鞋子安排持鞋、上脚和走动镜头。它可以作为贝强下一次产品试拍的候选方法；没有本店生成结果或成交数据，不能据此承诺复刻效果或带货收益。

唯一研究入口是本文件。原片、抽帧和检查证据在同项目 `edit/`，不晋级为跨项目强制规则或长期偏好。

## 教程实际怎么做

时间范围是教程章节/操作区间；不是每个带货成片镜头的精确切点。

| 原片时间 | 画面及字幕支持的步骤 | 可迁移的做法与限制 |
| --- | --- | --- |
| 00:00–00:55 | 先放竖版鞋子展示效果，再说明需要人物、鞋子、场景、脚本。展示中鞋子和腿部占主要篇幅，也有全身画面。 | 先看成片需要什么，再准备必要素材。出镜人物服务产品展示。不能由展示效果推断实际销量。 |
| 00:55–03:02 | 即梦网页搜索男性人物，选择适合账号风格的示例，复制提示词重新生成；界面出现3:4比例。比较候选时指出脸部过曝和个性化角度的问题，删除侧光/复杂环境/角度等相关词，再挑清楚的人物图；随后演示智能超清。 | 学习提示词结构并生成自己的角色，重视曝光、清晰度和可用角度。多张候选不等于同一人物多视图资产。超清只改善可读性，不保证视频一致性。 |
| 03:02–03:43 | 从要带货的鞋子链接取较完整图，上传豆包，生成白底商品图并去除文字。画面显示白底鞋图，字幕同时强调单一视角不够，最好有正面等完整图片。 | 商品需要完整、无遮挡、多角度资料。贝强直接优先使用真实原始商品图；去背景不应改款，AI补出的遮挡部位需要回原件核对。 |
| 03:43–04:32 | 区分两种场景：只拍脚和鞋、背景信息少时，不一定要固定背景；做系列账号、出现全身时，建议统一场景。截取参考室内画面，在即梦图片生成中去人和文案，示例输出空房间，界面出现9:16。 | 场景参考是按连续性需求增加的条件，不是所有鞋片都必须准备。贝强可建立自己的空景，避免把竞品鞋或原人物混入。 |
| 04:32–04:46 | 字幕说明：保存对标视频，反推出脚本，再稍作调整优化，带到Seedance2.0生成。 | 教程这一段没有完整展示反推工具的实际界面、完整脚本及验证过程，不能认定某个反推入口或“一键反推”已经验证。借鉴节奏与镜头功能，重新写本品内容。 |
| 04:46–05:30 | 即梦切换视频生成、全能参考，上传参考并放入优化脚本；选择9:16，示例时长15秒。讲解指出已有场景图时删除重复背景描述；用@绑定人物、核心道具（鞋）等参考。 | 关键是明确“哪个参考控制什么”，并减少相互矛盾的约束。录屏中可确认鞋图上传和@绑定的讲解，但没有完整任务清单，不能反推最终实际提交的全部参考与参数。 |
| 05:30–06:08 | 介绍当时界面的Seedance2.0 VIP、2.0、Fast选项、积分和排队经验。 | 这是作者当时的选择和判断；不是模型质量对照实验，也不是当前价格、排队时间或版本建议。未来生成另核当前官方入口并按用户选定版本执行。 |

## 对咱们产品的应用判断

1. **可以先试生活化鞋片。** 对套脚、针织、休闲步行方向，可试“拿在手里看完整鞋 → 上脚近景 → 走几步 → 一处真实结构细节 → 全鞋收尾”。这是待验证的镜头结构，不指定某个SKU已具备特定卖点。
2. **产品身份比人物脸部更关键。** 顶视、左右侧、后跟、外底、鞋口等真实资料按镜头需要准备。鞋头轮廓、鞋底纹路、分割线、配色、标识逐镜对照；手拿、转鞋、脚鞋接触处单独检查。
3. **人物与空景按需要复用。** 以腿部为主的片子可先降低面部设计投入；有露脸或系列账号才固定角色。需要多视图时按现有参考资产协议制作，不能把随机生成的几个相似脸当成同一人物。
4. **把参考写成职责。** 人物图管身份/穿搭，实鞋图管产品，空景管空间，参考视频管镜头与动作节奏，脚本管表达顺序。实际执行时采用所选入口支持的绑定方式，不能假定任何API都接受网页里的@写法。
5. **文案回到真实证据。** 教程的穿搭夸赞不自动适配所有鞋。普通套脚不写成Hands Free；宽楦、材料、轻量、回弹等按单款证据。生成动作不能证明耐折、止滑、防水或舒适度测试结果。
6. **按渠道改结尾。** 国内零售围绕选款、尺码和真实上脚信息；国际B2B另组织样品、款式或合作沟通，不直接沿用零售催单。研究阶段不改任何商品字段或发布状态。

## 下次可直接使用的试拍准备单

先选一款来源、外观与销售渠道已确认的鞋。交付物是一条约15秒、9:16的生活化展示候选；具体模型、版本、执行平台和预算在生成前按当次决定填写。

| 位置 | 镜头作用 | 候选画面 | 需要的依据 |
| --- | --- | --- | --- |
| 0–3秒 | 让观众立即看清鞋款 | 室内自然光完整持鞋或全鞋近景 | 真实鞋子正侧面、标识；手部动作单独审查 |
| 3–6秒 | 给出穿搭与比例 | 已穿好的双脚，低机位轻转身 | 实鞋图、固定裤装；核鞋长、左右脚与鞋底 |
| 6–9秒 | 展示使用情境 | 同一室内走两三步 | 只表达走动，不用生成动作证明性能 |
| 9–12秒 | 解释一处购买信息 | 鞋口/针织纹理/外底之一，按本品证据选 | 近距离真实原图；没有证据不写材料或性能名 |
| 12–15秒 | 留下清楚的商品印象 | 稳定全鞋收尾，后期加入短字幕 | 文案匹配渠道；保持产品无遮挡 |

这是贝强试拍提案，不是原作者逐字脚本，也没有生成或获用户验收。优先让原图/可靠实拍承载结构证据，生成片段承载人物和生活化动作；若一个长片候选出现局部漂移，可保留合格段，再改局部，不预设所有视频必须拆段或一次生成。

参考整理提示词（用于后续分析，不是本次运行记录）：

> 请按源视频顺序列出镜头作用、景别、鞋子与人物动作、背景、字幕表达和可确认的时间；无法看清的写未知。随后只保留可迁移的镜头结构，使用提供的真实鞋款证据重写商品内容，不复制原人物、商标、销量或体验陈述。把人物、实鞋、空景和节奏参考的职责分别列明；若参考之间冲突，指出冲突，不能擅自改鞋。

## 候选经验与最小验证

- 候选A：素材分工清楚，可能减少身份与场景冲突；证据是本教程的操作及字幕，贝强新片尚未验证。
- 候选B：以鞋和腿部为主，可能更直接展示鞋型且降低面部连续性的制作负担；不意味着无需检查脚、手和鞋的接触。
- 候选C：系列账号统一空景可能有助于辨识；脚部特写是否值得增加空景约束需要比较，不能一律强制。

下一步：选定真实SKU后，先锁定产品图、人物/裤装、脚本和模型；若要验证场景条件，做“同样输入，仅有/无空景参考”的小比较。以鞋款保真、可用秒数和制作代价记录结果；实际转化效果须在后续授权发布与数据积累后单独评价。生成前保留完整提示词、参考角色、参数与预计成本，按项目既有规定取得当次付费生成确认。

本轮不把这些候选写入长期记忆或共享硬规则。
