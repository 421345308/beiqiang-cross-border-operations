# 沙县熟客与加绒鞋短剧

更新：2026-10-15。国内抖音消费者短剧，9:16，暂按60秒安排。当前完成台词、分镜和AI制作设计；人物、空景、声音和动态素材尚未制作，没有付费生成或发布。本稿时长是未读演的表演预算，先完成自然读演再锁剪辑点。

负责人已认可的基线：小吃店老板与熟客闹别扭，嘴上划清关系，却记得他夜班脚冷及鞋码；鞋把在意暴露出来，结尾以“下次”和咸菜留白。负责人本轮要求台词更自然、减少广告感，拆分镜并设计AI制作。当前稿尚待负责人评价，不冒称已接受台词或成片。

## 当前剧情与对白

片名候选：《下回来再说》。关系不明确写成恋人或前任。成年男女、夜间小吃店、同一餐饭，无旁白和商品总结。借用负责人提供的“老样子、店客赌气、咸菜”的叙事机制，不认定热点最早作者、传播量或唯一原版。

门帘一响，男生进店。

男：老样子。

女，低头擦台面：菜单在那儿。

男：还用看啊？

女：隔壁不用看？

男停一下，拉开常坐的椅子：行，鸡腿饭。

省略备餐。她端来饭，又把一个装着鞋盒的纸袋放到旁边空凳上。

女：吃完，这个拿走。

男：什么？

女：自己看。

省略复杂拆袋开盖，切到已打开、稳定放在他膝上的鞋盒。他看着鞋，手指轻触鞋口；同款内里素材未补齐前，不生成绒毛微距。

女，画外：夜里穿，别老穿那双薄的。

男抬眼：给我买的？

女，转身整理筷筒：买错了。

男看一眼盒子，再看她：四十一，还挺巧。

女：不穿拿回来。

他把盒子安置到旁边，准备换鞋。切到新鞋已上脚，他手扶鞋口，把后跟扶正。

女，画外：后跟提起来，别踩着。

男，低头笑一下：知道了。

他收好旧鞋，拿起手机。

男：饭跟鞋，一起转你？

女：饭钱就行。

男：那鞋呢？

她擦台面的手停一下，没有抬头。

女：下回来再说。

他放下手机，把原来朝向门口的双脚收回桌下。

男，画外：还有咸菜吗？

她不回答，把一小碟咸菜推到他手边。停一拍，结束。

## 台词与表演取舍

- 撤掉“不是说只是顾客吗”“这双不用系啊”和任何总结关系的独白。让观众从她记得鞋码、管他后跟和推咸菜自行判断。
- “夜里穿”是她说漏嘴的关心；“买错了”是临时找补。前者随口，后者短而快，不使用对镜讲解语气。
- 男生不嬉皮笑脸地追问。开头照常，听到隔壁后收一下；发现鞋后才有试探和很浅的笑。
- 女生不一直板脸，也不大幅翻白眼。手上继续干活，用不看他掩饰在意；最后只停手半拍。
- 产品信息由镜头承担：黑杏鞋型、加绒版对应素材、没有鞋带及需手扶鞋口的普通套脚动作。取消舒适、防滑、轻量、温标和无需用手穿脱等未证主张。

## AI制作路线

### 先建立一场连续的戏

1. 先用两条稳定声线录或合成整场自然读演，包含呼吸、停顿和反应；先做约60秒的低成本声音加静帧样片。当前未产生录音、未测实际语速。演员现场语气，不朗诵广告。
2. 锁店面空间、两人站位与视线。需要连续表演驱动时，优先准备同一场低精度表演母版，再按同一声音时间线生成覆盖镜头。这是待本片验证的制作路线，不保证生成结果。
3. 如所选工具支持带声音的视频/动作参考，使用共享母版的重叠时间窗；如入口不支持，按同一读演设计完整对话段，分别获取画面与可对口型的人像，再在统一声音下剪辑。若口型无法可靠修复，保留合格主镜头并用有叙事理由的听者反应、手部和道具画面接句，不把所有讲话都藏成画外声。
4. 按剧情分四段组织素材：进店赌气S01—S03；鞋露馅S04—S08；换鞋S09—S10；留人S11—S15。它们是连续性分组，不是强制四次生成；实际片段长度、参考数量和声音方式按最终所选模型与Provider规格落实。
5. 先做S06—S08相邻的短试段：验证鞋型、她说漏嘴后找补、他抬眼和同一空间的视线。试段通过再扩展其他段；不能只用一个好看的静帧批准全片。

### 拍法与声音

- 竖屏、正常人眼尺度、小幅靠近或固定机位。店内暖白顶灯，门外略冷；不过度磨皮、不做豪华餐厅、不每句推拉镜头。餐馆标识和菜单若需可读文字，在后期统一排，不依赖视频模型生成文字。
- 男生主要在画面左侧朝右，她在右侧朝左；相机在同一侧覆盖两人。下机位仍保留同一门、桌腿和灯光方向。
- 用一条连续店内环境声连接画面：冰柜低鸣、远处碗筷、门帘声。对白前段略生分，后段松一点；先不铺伤感音乐，若加入配乐只用已授权/原创轻器乐，并让位于“下次”和推碟。
- 字幕后期逐句加，贴近自然口语分行，不用“加绒保暖”“轻便舒适”等大字卖点。按实际AI生成部分添加适用标识；商品挂载、发布与当前平台设置在发布阶段单独核查。
- S06的清楚鞋口近景若无实物内里参考，先换成已知鞋面/侧面角度，不放大或补画未知绒毛；加绒内里特写是待补素材，不让整段人物对白因此停工。
- 换鞋用动作省略，不能让旧鞋在同一连续画面直接变成新鞋。可以拍/生成手扶正已穿好鞋的后跟；如实际接触不稳定，仅局部改该镜或用对应实物插镜。
