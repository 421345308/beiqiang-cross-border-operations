# 参考片画面拆解

来源：MRUQIQUI千特，https://www.douyin.com/video/7581072106546565523 。单条互动证据与原片哈希见 ../../reference/REFERENCE.json 。不以互动推断销量。

0—约2.7秒：俯拍膝下，棕色高帮套脚鞋已穿好，前景另有两色鞋；脚小幅调整，出现作者品牌文字。
约2.7—6.4秒：手摸裤脚/鞋口，坐姿与轻微转脚，展示鞋侧。多余色鞋仍在地上。
约6.4—10.2秒：起身/短步上脚展示，手持俯拍有轻晃，后段出现另一双鞋和裤脚。
约10.3—13.5秒：黑底品牌与“左下角同款”尾卡，无商品展示。

本次仅借鉴前10秒快速看鞋、转脚、短步的镜头功能；不复制穿入、多人多款、黑底尾卡、水印、音乐和身份。场景换成明亮住宅玄关，牛仔裤单一黑杏配色，增加清楚的外侧稳定近景。原片单镜头为主，本片按商品需要改为四个清晰机位；不声称逐镜复刻。采用已查看的16帧全时段概览，原始帧与时钟见 sampling_manifest.json 。
