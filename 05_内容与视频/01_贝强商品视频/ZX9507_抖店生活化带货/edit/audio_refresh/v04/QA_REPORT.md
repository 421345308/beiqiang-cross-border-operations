# V04 年轻男声音色候选

负责人实际反馈V03“声音太老了”；V03未获音色验收。本版保留75字文案、V03独立BGM和V01全部361帧，只改变人声音色与必要的节奏适配。

- 改用LibTV Minimax-speech-2.8-hd并显式设置`male-qn-daxuesheng`（青年大学生）系统音色。官方MiniMax音色目录将其归为青年男声；这是预设身份，不等于负责人已经认可实际年轻感。来源见plan.json。
- 节点创建起初因缺少Text-to-Speech场景被CLI拒绝，未提交生成；按错误要求补足场景后，节点参数回读确认音色ID与语速1.12。实际仅生成1条音频、0条视频。
- 原干声20.97475秒，较长静音会重现上轮问题。仅移除低于-42dB连续0.35秒以上的静音中段，内部每段保留共160ms；未删有声字。压紧后15.64697秒，用保音高变速1.15903适配约13.5秒口播，0.08秒进入。未通过升调假装年轻。
- BGM复用V03源轨、混音目标-31LUFS；人声目标-16LUFS。最终实测约-16.84LUFS、峰值-4.43dBTP。完整解码无错误，视频压缩流与V01完全相同。
- 最终完整混合音轨经过云端原生回读，恢复75字文案主体，仅标点不同。模型未回答所问年龄/音色细节，不能冒称已验证年轻或吸引力。待负责人实际试听。
- 初次回传LibTV发生fetch failed，正常重试前查询未发现同名资源节点；原始故障与重试证据均留.local。本地成片独立有效。

当前结论：技术检查通过的可试听候选；音色审美、发布和转化未验收。
