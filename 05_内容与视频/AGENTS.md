# 内容与视频执行入口

先从[内容入口](README.md)进入对应 `PROJECT.md`。商品视频、渠道运营与通用创作各有目标；缺项目档案时先查现有来源，再补最小入口，不从目录名或渲染文件推断验收。

- 渠道、受众、语言、工具、模型版本及创意形式取本次要求与项目记录。通用创作不默认加载鞋类营销或客户资料，历史实例和经验不成为新项目硬规则。
- 项目状态、素材、生成、剪辑、观看修订和验收在原项目维护；发布及经营结果回实际渠道，原始参考与正式产物保持关联。失败素材有复盘/恢复用途才保留，可重建缓存退出长期资料。
- 需要恢复既有创作偏好时才查相关记忆；启动、继续、复盘或维护AI视频知识时用 `ai-video-learning-system`。工作区方法源见[学习体系](../07_知识库与Skills/04_AI视频知识体系/ai-video-learning-system/SKILL.md)，个人安装为调用副本，不擅自覆盖。
- 制作人物、动物、商品、道具、空景或镜头参考时使用 [video-reference-assets](../.agents/skills/video-reference-assets/SKILL.md)；参考职责与连续性按该能力处理，不把文件检查当像素或完整音视频审查。
- 付费生成沿根AGENTS的当次授权边界；商品事实回真实SKU。文件生成、像素/音视频验收、用户认可、发布和转化分别取证；不因参数达标或生成成功宣称作品/经营完成。
