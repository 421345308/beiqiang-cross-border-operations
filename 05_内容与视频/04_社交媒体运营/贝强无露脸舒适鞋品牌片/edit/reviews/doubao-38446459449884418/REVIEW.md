# 豆包协作实测结论

2026-10-11，对话ID `38446459449884418`。前两轮图像输入含同源拼图，第三轮含密集边界拼图及原尺寸图，第四轮上传同源完整音轨；Chrome网页当前入口显示“豆包 快速”。实际能力是局部图像分析与音轨系统转写分析，不是原生视频/完整声音审片或模型全面评测。

| 测试 | 实际结果 | 决策 |
| --- | --- | --- |
| 仅给抖音链接 | 明说无法读取视听，只取文字；随后又作无画面支撑舒适的判断 | 使用构思建议，拒绝无证据的视觉结论；其口播文本未独立听核 |
| 4张时间戳拼图 | 看出白背景、腿鞋主体及手脚活动；误称连续完整穿入，将拼图黑边当视频内容 | 广义构图建议可参考，关键事件不直接采用 |
| 密集边界+两张原尺寸 | 撤回完整穿入与黑边；后跟侧部、鞋头网孔指触读对；2.8/2.9秒空鞋/赤脚状态仍错 | 局部清晰图较有用，时序需独立核验；提示纠正后的同意不算独立判断通过 |
| 同源19.71秒WAV音轨 | 附件被接受；明确仅获取系统文本转写，不能确认音乐、声线、脚步或声轨配比；从文本识别增高推销主题 | 可辅助理解口播意图；不作为听感验收。其约数分段、说话人标签及送礼受众细节未独立听核，不采为事实 |

制作方也曾从小拼图误写“手压前掌”，5.286秒原尺寸核对后改为手指指向/接触后跟侧部、脚前掌靠地而脚跟抬起；不把模型错误掩盖自身误读。

合作建议：先让豆包对已准备的画面提出独立可替代方案，再由制作方核动作、产品身份、声明和剪辑意义；不将旧方案当标准答案投喂后索取认可。高接触动作需更清楚、更密集的局部证据，不能只给整片拼图。保留它有用的“具体部位作为记忆锚点”“鞋随脚动作表达”的思路，拒绝未证实的久走不压脚、自主回弹、慢穿入高成功率判断。
