# 后续集中实拍候选

此表供负责人以后统一拍摄；当前17秒商品介绍采用整条AI生成，不依赖此表补片。原24秒混合制作安排已撤销。

手机竖屏1080P/30fps，窗边柔光、干净背景、保留完整鞋与身体连接；正常速度，每个动作前后留约2秒，交原视频，不先加字幕、配乐或加速。下面各项是可复用素材，不要求制作六条视频。

| 素材 | 具体动作 | 用途 |
| --- | --- | --- |
| 上脚角度 | 双鞋穿好，低机位自然换重心、抬跟落回、小幅转向 | 看清鞋口、侧线、后跟与脚的关系 |
| 日常步态 | 正常走3–4步，最后落脚与停稳完整 | 真实动作参考或后续直接剪辑 |
| 穿脱 | 坐姿侧拍，按平常方式穿入并按需整理，另拍脱下 | 判断实际穿脱方式，不演成Hands Free |
| 织纹与鞋口 | 柔和斜侧光近拍前侧波纹、鞋口、后侧 | 补商品身份视角；不无目的擦鞋 |
| 自然前掌支撑 | 平地自然抬跟一次并落回，正常受力 | 记录实际可见弯曲；看不出就不宣传“极软” |
| 手持外观 | 托起、转向前侧/侧面/后侧、放回 | 完整商品介绍；手只执行展示任务 |

实物有怎样的表现就记录怎样的表现，不强折鞋，不用道具制造夸张性能，不将画面联想当材料测试结论。
