## Transferable Pattern

- 约0–3.5秒：袜脚靠近鞋口，手扶鞋口整理后跟，最终穿好。鞋脚占主体，另一只鞋/腿保留关系。2.6秒原尺寸可见手、后跟与鞋口接触；不能从抽样推定连续完整穿入或Hands Free。
- 约3.5–5.5秒：穿好后的抬跟与鞋侧近景，前掌支撑让脚与鞋的形态关系可读。
- 约5.8–8.2秒：木台面建立接触参照，落平、前掌支撑抬跟、落平。6.1秒原尺寸可见鞋随脚弯曲的姿态；不据此认证实物缓震/回弹参数。
- 约8.7–12.8秒：回到地面，双鞋重心转换、转脚和抬跟。9.8秒原尺寸可见鞋/地面接触；多个姿态展示上脚轮廓与贴合。13.38秒样本鞋已离场，单帧不足以判尾部拖沓。
