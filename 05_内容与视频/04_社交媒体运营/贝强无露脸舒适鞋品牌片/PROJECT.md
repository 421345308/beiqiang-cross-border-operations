# 贝强 · 日常舒适鞋剧情带货审核

当前状态（2026-10-13）：负责人已大致认可剧情，授权生成人物与小狗资产，指定年轻女生、可爱机灵的小狗、写实日常世界；并确认舒适一脚蹬男女都可穿，按颜值选择亮色鞋。当前已用内置图片生成完成三张选定角色资产，待负责人审核。未调用LibTV或腾讯云付费视频生成。原26秒方案报价与平台草稿不适用，不得执行。

## 当前故事：《我家狗开始养我了》

一位二十多岁的年轻女生、一只每天盼着散步的赤白柯基。旧鞋走久让主人不舒服，主人第二天不想出门，狗发现阻碍来自鞋，于是偷偷给主人买了一双日常鞋。主人试穿后真正走出去，散步途中觉得穿着舒服，主动问“再走一圈？”；狗开心继续走，最后吐槽“养个主人，真费钱”。

主人原来不是单纯懒，不以狗责备主人的口吻制造矛盾。狗买鞋有具体用途；舒适在出门后的步行中表达，不只在玄关试穿时靠一句话宣布。前后各一次散步服务于不同状态，不循环复用同一画面。

| 11—15秒 | 次日主人在玄关打开快递盒，看见白色休闲鞋，再看向守在盒边的狗；狗轻轻抬头回应。不设置快递员人物，不用旋转、揉鞋或长时间拆包装 | 主人：“你给我买的？” 狗叫一声。将下单和到货接起来，商品身份第一次清楚出现，但没有性能说明 |
| 15—18秒 | 以盒里鞋切到同款已穿好的双脚，随后回到主人拿起牵引绳、狗站起来的中景。穿入过程不安排 | 主人：“走，试试你的眼光。” 这句话提出待验证的结果，不在原地直接宣布走路舒服 |

| 25—30秒 | 狗先看主人，再开心转向前方，两者继续正常走。保留反应停顿和最后的同行动作；约末1.5秒品牌随画面出现 | 狗内心：“养个主人，真费钱。” 最后落“贝强｜把日常走舒服”。狗的愿望实现，结尾回收谁照顾谁的反差，不让狗累趴 |

全部时间是剧本预算，尚未录制声音测时。对白约50余个汉字，需在声音制作时核对自然语速、换人说话与反应停顿；未测时不能把时段当精确配音长度。七个叙事段不等于必须七次生成或每段只有一镜。后期画面切换和配音设计先写入整条提示，不要求每两秒硬切。购买、开箱、穿鞋是过桥，前后遛弯与狗的反应才是主体。

## 叙事判断与声音设计

- **因果比上一稿清楚**：以前只交代“主人说改天”，鞋和不遛狗的关系不充分。现在先让观众看到旧鞋不适如何影响出行，再让狗针对这个阻碍行动。
- **开场直接发生冲突**：狗朝前、主人想回，没有日常背景介绍。观众的期待是“狗会怎么解决”，约7秒出现拟人行动。倒叙快递开场不再占用时间。
- **中段持续改变状态**：第一次走不舒服 → 次日取消 → 狗决定下单 → 送鞋 → 主人尝试。不能长时间拍看平板、盒盖或脚穿鞋；这些信息各交代一次。
- **结尾同时给结果和笑点**：主人愿意再走一圈，狗开心接上；“养个主人，真费钱”回收拟人购买。舒适主题与宠物喜剧不分别做两个结尾。
- **普通观众是否觉得有趣尚待验证**：逻辑改善不等于完播率、转化已改善。前三秒表演与声音要迅速让人理解差异，狗不能静态配音，角色对白也不能像主播念卖点。
- 声音靠主人自然讲话、狗少量内心独白、脚步、绳落地与下单轻点声推动；轻巧配乐在狗决定行动时进入。不要每个动作都加夸张音效，不要求狗张嘴说人话。
- 已参考[TikTok官方Creative Codes](https://ads.tiktok.com/business/en-US/creative-codes)关于开头吸引、中段发展、结尾收束与声音的建议。此处是创作启发，不是国内抖音算法、固定黄金秒数或效果保证。

## 自审与生成前核对

1. **情节是否能读懂**：主人第一次停下要明确是鞋脚不适；第二天看旧鞋再拒绝是因果接续；狗的下单是为解决散步阻碍。各段不靠长旁白补解释。
2. **狗旺盛欲望与主人状态**：狗每次主动拿绳或向前，不暴力拉人，不让它后段疲惫，以免剧情自己否定其持续散步欲望。
3. **前后散步都是真动作**：第一次走后停，第二次自然继续；不能换鞋后只做一秒原地踏步或用一个走路循环撑舒适段。
4. **生成难点提前设计**：主人双腿、狗四足、绳的一致性，狗叼绳放绳，开盒露鞋，跨场景白色套脚款一致。平板屏幕朝向狗，前爪完成一次轻点后收回，动作起止需验收；无人的手、无复杂支付、无口型任务。
5. **动作的剪辑用途**：可以正常剪辑，但每个付费动作要按完整用途规划；不事先安排生成长片后只留下两秒。若生成中有错误，记录实际可用性再决定修复，不能通过短取样冒充动作通过。
6. **付费视频范围仍空**：本轮已生成上述角色图片，未录制配音、未上传LibTV/腾讯云、未查询新实际视频报价。旧1196积分报价作废。角色与制作包通过后，按当时LibTV模型、参考输入、声音、总时长与720P查实际报价，再取得本批付费视频确认。整条30秒为执行候选，实际入口限制提交前再核。
