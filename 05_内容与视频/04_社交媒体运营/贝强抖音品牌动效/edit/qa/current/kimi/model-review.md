## 4）C 的完整动作评估（0–5.042s）

- **起点（0.000s）**：人物坐姿，米白阔腿裤+米白毛衣，双脚已穿着黑色针织袜式鞋；右手握住右脚鞋跟提拉带，鞋口呈自然堆叠褶皱。
- **过程（约 0.6–1.9s）**：手持续捏住提带做小幅提拉/整理鞋口动作，幅度很小，接近"微调"而非"提拉穿入"。
- **终点（约 2.6–5.0s）**：手松开后回落至腿侧，鞋口保持整理后状态，画面静止收尾约 2s。

- **有价值的秒段**：0.000–1.9s（手与提带接触、展示鞋口针织弹性与提带细节，作为"鞋口整理/触感示意"可用）；约 2.6–3.9s（松手后鞋口服帖的静态结果，可作"就位后状态"的短插入）。

- **结论**：C 可作为 1–2 个短插入保留（总计约 2–2.5s 可用），**不能为省成本把它拉成主镜头，更不能用它替代"穿入"镜头**。

## 5）B 比 A 有效之处 / 不适用之处 / 可迁移方法

由于 A 无画面，以下为 B 自身的有效做法（可见帧）：

**B 的有效事件与视觉组织：**
1. **每帧都有产品锚点**：8 个采样帧中鞋出现在几乎全部画面里，或实物、或插画巨型化（11.467s 鞋化作山路，人物在鞋面上奔跑）。品牌曝光不依赖结尾 logo。
2. **色块章节化**：桃橙（0–1.9s）→ 青/橙分屏（3.8s）→ 橙（5.7s）→ 紫（7.6–9.6s）→ 橙（11.5s）→ 紫收尾（13.4s）。每个章节一个主色，观众即使静音也能感知段落推进。
3. **分屏漫画格组织**（3.822s、7.645s、9.556s、13.379s）：用格子边界做多信息并置（人物特写/系带特写/跑步全身+勾选框），信息密度高但秩序感强。
4. **尺度游戏**：鞋从实物大小变为地形（11.467s），把"产品"转译为"世界"，是情绪表达而非性能声明。
5. **固定版式 footer**：每帧底部统一的 logo+品名锁排，15 秒内品牌结构零漂移。
6. **首尾呼应**：0s 与 13.4s 都是斜置悬浮鞋的英雄产品图，中间是场景叙事，结构闭合。

**不适用于本片（贝强）的：**
- B 的跑步/竞技语境（START、跑者、马拉松勾选清单）与贝强"日常舒适"定位不符，照搬会错位成运动性能暗示。
- 高饱和多色章节（桃橙/紫/青）与贝强素材（米白+黑）的克制家居气质冲突。
- 插画化巨型鞋的超现实尺度游戏，对强调"真实针织触感"的产品反而削弱可信度。

**3 条可迁移方法：**
1. **产品常驻**：每个场景都让黑鞋以实物或近景细节出现，不做无产品的纯氛围段。
2. **统一版式锁排**：全片固定位置放"贝强+款名"小锁排（学 B 的 footer 纪律），31.5s 内建立品牌印象主要靠重复一致，而非片尾一次亮相。
3. **单事件分屏并置**：如"提拉鞋口特写｜行走全身"两格并置，用格子边界同时给细节与整体，适合在小成本素材下提高信息密度。

## 6）图生视频最小有效替换方案（4 个镜头，每个仅一个可观察事件）

**镜头 1｜一脚蹬穿入（核心证据镜头）**
- 起始状态：黑鞋平放于浅色地面，一只脚（米白裤脚）悬于鞋口上方。
- 动作过程：脚尖探入鞋口→针织鞋口被撑开→脚跟下滑坐实→鞋口回弹贴合脚踝。
- 终态：脚跟完全就位，鞋口褶皱自然，手不参与。
- 建议时长 4–5s，预计可用约 3s（取穿入到就位的中后段）。
- 必须保留：黑色针织鞋面+堆叠鞋口+厚黑底；米白裤装；亮调室内。
- 主要失败风险：脚跟与鞋口穿插错位、织物形变出现非物理拉伸、穿入瞬间脚与鞋分离。生成后须逐帧核查穿入接触段。

**镜头 2｜鞋口提拉整理+松手（替代并修正 C 的歧义）**
- 起始状态：脚已穿好鞋，手捏住后跟提带。
- 动作过程：一次明确上提→鞋口收紧贴合→松手。
- 终态：手离开画面，鞋口保持服帖。
- 建议 3s，预计可用 2s。属性同镜头 1。
- 风险：手指数量/关节异常、提带与手的粘连穿模（C 在采样帧内未见，但生成素材此风险高）。

**镜头 3｜行走（必须双腿连续关联双鞋）**
- 起始状态：人物站立，双脚双鞋同框。
- 动作过程：连续 3–4 步自然行走，双腿交替、双鞋轮流承重与离地。
- 终态：走出画面或停步站稳。
- 建议 4–5s，预计可用约 3s。
- 风险：腿与鞋脱关联（鞋滞空/滑步）、左右鞋形不一致、地面接触阴影漂移。行走段任一帧鞋脚分离即整段作废，不剪碎救场。

**镜头 4｜针织触感特写（舒适表达，禁止无目的转鞋）**
- 起始状态：手指悬于鞋面针织上方。
- 动作过程：指腹按压鞋面→针织下陷→抬手回弹。
- 终态：鞋面恢复原状，纹理清晰。
- 建议 3s，预计可用约 2s。
- 风险：按压形变不真实、织纹在形变中崩坏、手指与鞋面接触帧穿模。

四个镜头合计可用约 10s，配合 C 的有效段（约 2–2.5s）与统一锁排，足以支撑 31.5s 片的骨架；其余时长若需填充，用产品的稳定近景（静止或单一缓慢推近），不用空转鞋。
