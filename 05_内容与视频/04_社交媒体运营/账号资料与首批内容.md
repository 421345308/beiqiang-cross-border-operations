## 首批主题一：怎样发一份能报价的鞋类RFQ

LinkedIn正文：

> A reference photo is a useful start for a footwear enquiry. A comparable quotation also needs the target market, intended quantity, size mix, materials or construction requirements, packaging and delivery expectations.
>
> If a detail is still open, mark it as a question rather than an agreed specification. It helps both sides identify what can be quoted now and what needs a sample discussion.
>
> We have put these points into a footwear RFQ checklist: https://www.beiqiang.online/resources/footwear-rfq-checklist/

## 首批主题二：样品批准不是只看一张图片

LinkedIn正文：

> When reviewing a shoe sample, record which version was checked and what was agreed: appearance, sizing or fit requirements, construction, materials, packaging and any requested tests.
>
> A reference image, a physical sample and a test report answer different questions. Keeping them separate makes the approval more useful for the next discussion.
>
> Sample approval checklist: https://www.beiqiang.online/resources/shoe-sample-approval-checklist/

Facebook正文：

> Keep a clear record of the shoe sample version and the points approved. Photos, physical checks and formal test results should each be identified, so the next step is based on the same requirements.
