## 平台分工

- LinkedIn：个人专业身份、采购知识、供应协作讨论；核官方公司页后补企业证明。按买家角色/采购触发研究目标，优先有内容可回应的具体互动与匹配建联，不用加好友数量验收。
- Facebook：公司Page资料、采购内容与相关行业社区讨论；先区分个人账户与Page管理身份，遵守社区规则，不直接向所有成员群发。
- TikTok：用真实产品/流程与清晰画面建立认知，也可用采购讲解回答具体问题。避免把其他创作实验直接当作贝强实拍证明。首批素材先检查来源、画面和音乐使用，再走已验证发布渠道。
- Instagram：目前不投入独立内容、接入和每日互动。保留账号与可复用素材；出现目标买家证据或复用成本足够低再重新评估。

同一采购主题可复用，形式分别适配：LinkedIn解释判断，Facebook用简洁正文与图，TikTok用可视动作与字幕。不要四个平台机械复制一篇长文。

## 一个主题到采购机会

明确买家问题→核真实产品或公开采购知识→选择平台格式→准备落地页/活动来源→实际发布/互动→回收真人问题→关联CRM→补款式、报价或样品资料。公开贴文、私信和客户报价是不同动作；准备好的文案不当成已发送。

内容记录至少关联：平台内容ID/URL、主题、真实素材、目标页面、活动码、实际发布时间、平台接受/处理状态、访问、采购动作和相关CRM记录。涉及客户身份的部分只留受控台账。发布次数、粉丝数与播放量仅作过程指标；经营验收看有效采购讨论。

优先已连接插件/官方接口，浏览器处理必要登录、授权与终验。平台接口只暴露发帖不能推断也可批量私信、拉好友或读取任意用户数据。
