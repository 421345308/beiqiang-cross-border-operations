# 贝强文件夹目录说明

## 00_运营SOP

存放阿里巴巴国际站上新 SOP、运营规则和后续沉淀文档。

## 01_原始数据包

存放供应商/厂家给的原始图片数据包。不要直接改这里，后续需要回溯原始素材时从这里找。

## 02_可上传素材

日常发布商品主要看这个文件夹。

- `数据包1/英文主图`：数据包1主图英文版
- `数据包1/推荐上传-英文详情图`：数据包1详情页图集上传版
- `数据包2/英文主图`：数据包2主图英文版
- `数据包2/推荐上传-英文详情图`：数据包2详情页图集上传版
- `原整理详情图-中文参考`：早期整理图，可作为信息参考，不建议直接上传国际站

## 03_厂家资料

存放工厂照片、厂家介绍相关素材。

## 90_工具脚本

存放图片生成脚本。后续如果要重新生成英文主图或详情图，从这里运行。
