# Alibaba运营入口

本目录管理国际站商品、店铺经营和发布验收。共用产品及供应商关系回[产品中心](../00_总控台/产品中心/README.md)；本渠道以商品ID在[国际站商品数据](05_扩品工程/数据/国际站商品.json)维护关联和已记录状态，执行时还要核对该商品的原任务及最新回执。

| 工作 | 入口 |
| --- | --- |
| 当前方向和任务 | [总控当前任务](../00_总控台/当前状态.md#工作台任务)；具体工作回对应原任务 |
| 逐商品执行与证据 | [商品档案](02_单品优化记录/商品档案/)、[单品记录](02_单品优化记录/)、[执行记录](05_扩品工程/执行记录/)、[发布回执](03_发布记录/)、[图片检查](06_图片与检查记录/)；按商品ID核对时间、范围和更近回执 |
| 全量身份、来源与链接查询 | [扩品全量视图](05_扩品工程/国际站合规扩品工程总控.md)、[本渠道查询页](05_扩品工程/供应商产品总表/供应商产品查询.html) |
| 发布、修复、图片与验收规则 | [商品全生命周期SOP](00_运营SOP/国际站商品全生命周期SOP.md) |
| 全店诊断与指标 | [店铺经营诊断](01_店铺与全店诊断/店铺经营诊断.md)持续更新当前结论，采集证据保留实际时间；不替代产品台账 |
| BQ持续优化 | [BQ执行入口](02_单品优化记录/BQ系列持续优化_2026-09-14/README.md) |
| 共享工厂图制作、成品与迭代 | [共享工厂详情](06_图片与检查记录/共享工厂详情/README.md) |
| 执行工具 | [Skills路由](../07_知识库与Skills/03_Skills清单.md) |

扩品全量视图及查询页由产品、来源与国际站商品数据生成，用于查询已登记的身份、关联和历史记录，并非实时平台状态或当期任务清单。视图中的“当前任务与下一步”汇集源记录，“本轮”等词来自生成模板或记录本身；是否仍有效须核对原任务与最新证据，时间不明的先待核。视图内目录对应明确是 **2026-10-10 06:28:16 UTC** 的完整列表分页观察，未覆盖全店正式字段或公开正文，不代表当前线上状态。

生成视图可能滞后于源数据：2026-11-11 的生成器 `--check` 发现不一致，相关源数据和查询页有在制修改；先与原任务对照，勿直接刷新覆盖。共用事实更新产品中心，渠道关联和状态更新国际站商品数据，再由相关任务核对并生成视图。

同款A/B/C共用产品身份与货源；各商品ID分别保留审核、展示、关键词和适用公开验收。正式请求与回读按原商品留证，不再每次修改新建进度报告。
