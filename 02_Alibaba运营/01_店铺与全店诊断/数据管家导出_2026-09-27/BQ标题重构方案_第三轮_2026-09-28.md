## 二、标题结构模板（从热榜 128 条归纳）

```
[性别] + [风格] + [闭合方式] + [品类主词] + [2 个特色维度] + [价格信号]
                                          ↑ 材质 / 功能 / 场景 / 价格，按款轮换
```

热榜实例对照：

```
Men's Casual Flat Walking Shoes Breathable Lightweight Summer Thick Soles Fashion Design
High Quality New Design Casual Shoe Running Jogging Sneakers Women Walking Style Shoes
2026 new fashion trend mens casual sneakers versatile soft sole comfy white shoes daily
```

### 结构要素覆盖 vs 热榜

| 要素 | 热榜 | 本轮方案 | 说明 |
|---|---:|---:|---|
| 性别 | 86% | **96%** | 热榜第一大开头词是 `men's`(12%) |
| 价格信号 | 38% | **46%** | 原来仅 3%，本轮补上 |
| 场景 | 66% | 51% | |
| 材质 | 51% | **54%** | 原来 99%（严重过剩） |
| 功能 | 42% | **61%** | 原来 81% |
| 季节 | 33% | 52% | 属性事实，174 款为 All Seasons |
| 定制/批发 | 24% | **0%** | 原来 75% —— 本轮全部移出标题 |

**核心修正**：旧标题把字符大量投在「材质 + 功能 + 场景 + 批发」，热榜把位置留给「性别 + 款式 + 价格」。

### 关于两处大幅下降的解释

- **`casual shoes`（1519）从 140 降到 56**：旧标题 77% 含此词，而热榜仅 34% 含 casual。这是**有意的去同质化**——181 款抢同一个词，平台只能展示少数。
- **`shoes`（1034）从 178 降到 129**：同上，从 98% 降到 71%，接近热榜水平。

**判断依据**：热榜的做法是**每款突出不同维度**，而不是所有款堆同一批词。

## 八、本轮**故意未做**的事

1. **不写跑鞋/网球/登山词** —— 属性不支持（见第三节）
2. **不往标题塞外语词** —— 25 个非英文词的高曝光来自**平台对英文标题的自动翻译**，不是缺口

## 九、方法论局限（用之前请先读）

1. **关键词覆盖用词元近似匹配**（不要求相邻），**非真实搜索匹配** → 只能作相对比较
2. 词表来自「**引流关键词**」（有偏：只含已带来流量的词），全行业词库需另导「关键词指数」页
3. 热榜为**混合品类**（鞋靴及配饰），且**完整标题样本仅 20 条**
4. 热榜排序规则未公开，**不可反推因果**
5. 单周快照（09-13~09-19），未排除季节性

## 十、下一步建议

1. **先改 P0 的 84 款**（有流量基础，边际收益最高）
2. **BQ-009 单独处理**：它是唯一有成交的款，建议保留其已验证的卖点词
