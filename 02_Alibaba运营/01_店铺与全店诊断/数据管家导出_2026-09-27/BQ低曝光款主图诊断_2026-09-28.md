## 一、先复述我从项目里读到的原有指导思想

在动手之前，我读了项目里关于主图的全部沉淀。**原有逻辑本身是成熟的**，核心是三层：

### 1. 六图决策漏斗（M1–M6）

```
找到我 → 看懂我 → 相信产品 → 知道怎么采购 → 判断SKU空间 → 相信供应商
  M1       M2        M3          M4              M5            M6
```

- **M1 白底搜索首图**：回答"这是不是买家在找的产品"。真实鞋体、白底、完整、大主体、易识别 3/4 角度。**不承担** OEM、参数、工厂、功能、认证
- **M2–M6**：不是同一鞋面/同一颜色/同一卖点的重复展示，整组要帮进口商完成**不同**采购判断

### 2. AI 的定位（这条最硬）

> **AI 只能是 `Visual Enhancement Tool`，不能成为 `Evidence Creation Tool`。**

允许：抠图、白底、去污、曝光/白平衡、清晰度、自然接触阴影、轻微透视与构图。
禁止补造：鞋底纹路、鞋垫、内部结构、针织纹理、缝线、标签；设备、工人、厂房面积；MOQ、产能、认证。

### 3. 三证据等级

`VERIFIED`（可发布）/ `CONDITIONAL`（只能条件化表达）/ `UNKNOWN`（不得进入正式视觉）

> 每张正式图必须回答：图中每个事实可以回溯到哪一张原图、哪份资料或哪次确认？回答不了就不发布。

**这套逻辑没有问题。问题出在执行层。**

我把项目的沉淀按位置列出来，问题就清楚了 —— **同一主题的知识分散在三处，彼此没有交叉引用**：

| `07_知识库与Skills/05_项目记忆系统/knowledge/experiences/` | `alibaba-multilink-visual-failure-2026-08-28.md` | 失败经验 |
| **`02_Alibaba运营/02_单品优化记录/BQ系列持续优化_2026-09-14/`** | **`鞋类B2B商品视觉方法论_网页版GPT讨论结论_2026-09-16.md`** | **通用方法论** ← 位置异常 |

**最后一个尤其说明问题**：一份**通用**视觉方法论，被放在**某个单品的优化记录目录**里。后来的人要找视觉规范，不会想到去 `02_单品优化记录/BQ系列持续优化_2026-09-14/` 下面翻。

### 更关键的是：规则与校验脱节

`批次01-08主图质量阻断审计（2026-08-30）` 自己写明了根因：

> 旧 Excel 校验**只验证六张 URL 唯一、详情图不重复以及 URL 属于阿里图片银行**。
> **校验没有识别中文文案、国内促销图、颜色拼图、电子秤、场景道具、第三方标识和首图职责。**

而项目里**早就有**规则：「原始数据包只是证据源，不等于可发布素材」。

**结论：规则在文档层存在，但执行层（脚本 + Excel 校验）只检查"结构性唯一"，不检查"内容质量"。** 于是：

- 105 条链接里 **100 条首图来自原始数据包**
- **96 条链接的六图全部来自原始数据包**
- 直到人工预览才发现问题

**这就是债务形成的机制：规则 → 无人执行的文档；校验 → 只查 URL 不查内容。** 后来者看到的是"绿灯通过的 Excel"，而不是"规则"。

## 三、实测：这 54 款的主图实际状况

我对 54 款全部下载了 M1 首图，做了量化 + 抽样目视。

### 3.1 好消息：底子比预期好

| 指标 | 结果 |
|---|---|
| 干净白底 | **48 / 54（89%）** ✅ |
| 首图被多款共用 | **0 款**（多链接首图确实做了区分，符合项目规则）✅ |
| M6 公司能力图共用 | 29 款共用 1 张，**位置均为第 6 位** ✅ 符合设计 |

**这修正了我原本的预判** —— 我以为低曝光款图很烂，实际不是。

### 3.2 真问题（按严重度）

**① 首图上的文字信息 —— 36 / 54 款（67%）** —— ⚠️ **本节判定已重写，见修订说明**

实测分布与重判：

| 标注类型 | 出现在 | 重判结论 |
|---|---|---|
| 底部 `WHOLESALE · OEM / ODM` | 若干款 | ✅ **不是问题** —— B2B 核心采购信号，热榜普遍使用，且我们有证据支撑 |
| 底部品类说明（如 `WIDE TOE BOX \| SLIP-ON`） | 若干款 | ✅ **不是问题** —— 这是产品事实（属性 Fit Type / Closure Type） |
| 顶部**内部型号码**（`BQ001` / `R1218` / `M8811` / `L0017`） | **36 款** | ⚠️ **待判断** —— 对买家无采购价值，但占用顶部视觉位 |

实例：

```
BQ001-S2  → 顶部「BQ001 | WHITE」   + 底部「WIDE TOE BOX | SLIP-ON」
BQ003-S1  → 顶部「R1218 · WHITE」   + 底部「WHOLESALE · OEM / ODM」
BQ006-S1  → 顶部「M8811 · ALL WHITE」+ 底部「WHOLESALE · OEM / ODM」
BQ007-S1  → 顶部「L0017 · WHITE」   + 底部「WHOLESALE · OEM / ODM」
```

> ~~**三重违规**（按项目自己的标准）：① M1 规定"不承担 OEM" ② skill 要求首图 minimal or no text ③ skill 明确"不做装饰性徽章"~~
> **↑ 上述"三重违规"判定已全部撤回**（理由见修订说明）。

**真正需要判断的只有顶部型号码一项。** 判断依据不是"规则有没有写"，而是：**买家在搜索缩略图上看到 `R1218`，能得到什么采购信息？** —— 得不到，而它占了顶部黄金位。

**但这里有一个需要你确认的问题**：型号码放在主图上，是否服务于**老客户复购识别**或**内部核对**？如果是，那就不该删，而应评估"有没有干扰更小的呈现方式"（例如只在 M2 之后的图出现，把 M1 让给产品本身）。

**② 场景图 —— 不是问题** —— ⚠️ **原判定已撤回**

负责人明确：「**做场景图是没问题的**，因为很多时候不仅要白底也需要一点场景让客户感知」。

实测中出现的 `BQ023-O1`（手持 + 咖啡店橱窗）、`BQ022-O1`（台阶）、`BQ036`（水泥地）—— 这些是**场景图，不是违规**。热榜前排同样有手持图和灰底场景图。

> ~~门禁第 3 条"首图必须为单鞋或一双鞋的完整产品主体、干净浅色背景"~~
> **↑ 用这条判场景图违规是我的过度执行。** 门禁第 3 条针对的是 2026-08-30 那批"中文信息图、颜色拼图、电子秤、国内促销图"，**不是禁止场景摄影**。

**唯一值得看的判断**：场景是否喧宾夺主、鞋在缩略图尺寸下是否仍清晰可辨。按这个标准，上述几款都合格。

**③ 首图风格三套并存**（这一条**保留**，是真实的观感问题）

- 卡片式（浅色渐变 + 圆角白卡 + 上下角标）— BQ001/BQ003/BQ006/BQ007 家族
- 纯白双鞋（无角标）— BQ032-O1 等
- 场景式（手持/台阶/水泥地）— BQ023-O1/BQ022-O1/BQ036

同一店铺、同一品类，首图风格不统一，会影响买家对"这是不是一个稳定的供应商"的判断。
**注意：风格统一 ≠ 必须全部白底。** 可以有场景，但要有一套一致的规范（同一类场景类型、同一套标注体系、同一视觉重心）。

### 3.3 关于"同款多链接"的结构性发现

31 款零曝光**全部**是同款多链接的变体：

| 家族 | 链接数 | 家族六图唯一数（满分=链接数×6） |
|---|---:|---:|
| BQ006 | **7** | 36 / 42 |
| BQ007 | 6 | 34 / 36 |
| BQ005 | 6 | 33 / 36 |
| BQ002 | 5 | 28 / 36 |
| BQ003 | 5 | 26 / 36 |
| BQ004 | 4 | 21 / 36 |
| BQ001 | 3 | 16 / 36 ← **最低** |
| BQ032 | 3 | **12 / 36** ← **最低** |

**表面看：首图各自独立（合规）。但鞋型完全相同、标题品类词相同、M6 共用。**

按项目自己的 `image-conversion-review` 判定标准：

> Classify `5/6 shared main images + all product-detail images shared` as high-confidence duplicate-presentation risk.

我们的重合度**未达到 5/6 全部共用**，所以不构成项目定义的高置信度重复。但**同款 5–7 条链接同时零曝光**，这个组合本身值得警惕。

**我的判断（标注为推断）**：零曝光的**根因可能不在主图质量，而在"同款多链接"策略本身** —— 平台面对 5–7 条外观近乎相同的链接，只可能给少数分配曝光。**先把主图改好是必要的，但不一定充分。**

这个我不下定论，需要下一批数据验证（见第六节）。

## 六、下一步：从内在逻辑出发，而不是黑盒观察

**先撤回我原来的建议**（"挑 8–10 款改造，观察 7–14 天"）—— 那是黑盒做法：冻结变量等结果，却不解释机制。你已多次指出这一点。

**从已掌握的事实出发，能直接推出三件事**：

1. **零曝光 ≠ 图片差。** 31 款零曝光全部是同款多链接变体，而 48/54 首图是干净白底。**图片不是它们的瓶颈。**
2. **平台给曝光是有条件的。** 同款 7 条链接（BQ006）**全部零曝光**；而 BQ-009（有成交、曝光 4,378）是**独立款**。这指向「**同款多链接被平台判定为重复**」这个机制。
3. **曝光主要来自付费推广。** 全店 54,082 曝光中纯自然曝光仅 **2,951（5.5%）**。所以"改图 → 自然曝光上涨"这条链本身就不成立 —— **零曝光款很可能根本没进过推广池**。

**由此推出的下一步不是"改完等结果"，而是先回答一个问题**：

> **这 31 款同款多链接，是继续维持（把差异做在颜色 + 买家意图上），还是收敛为 1–2 条主链接？**

这个问题不回答，改图、改标题都可能是无效劳动 —— 因为**瓶颈不在图，在结构**。

**我可以先做、且不依赖上面决策的事**：

- 把 54 款的**顶部型号码清单**逐条列出，你判断是否保留（含是否有复购识别用途）
- 把**同款家族的链接清单 + 六图重合矩阵**整理出来，供你做收敛决策
- 用同一套方法核对**高曝光款**的首图（看它们做对了什么）——**只读不改**，避免你担心的副作用
