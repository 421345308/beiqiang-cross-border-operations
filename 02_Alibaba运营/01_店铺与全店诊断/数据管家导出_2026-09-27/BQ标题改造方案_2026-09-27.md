## 〇、两条纪律（本方案的事实边界）

### 1. 事实只有两个来源，绝不新增

| 来源 | 内容 | 用途 |
|---|---|---|
| **A. 系统属性**（`product.get` 的 `attributes`） | Upper/Lining/Outsole/Midsole Material、Closure Type、Toe Style、Feature、Season、Fit Type | 写进标题的材质与功能描述 |
| **B. 作者已断言的事实**（旧标题里你写过的） | Thick Sole、Chunky、Anti-Slip、Mesh、Knit、Retro、Platform… | **保留，不丢弃** |

**任何新事实都不添加** —— 不编材质、不编认证、不编功效。`Wide Toe Box` 只在系统属性真的标注了才写（本批 5 款）。

> 中途我发现并修掉了一个违反这条纪律的 bug：`Outsole Material = "Rubber / Plastic"` 被清洗函数截断成了 `Rubber`，等于篡改了产品事实。已修正为保留 `Rubber Plastic Sole`。

### 2. 品牌词硬性排除

已校验：**46 条新标题品牌词命中 0**（`nike/adidas/jordan/puma/skechers/vans/converse/reebok` 全部排除）。旧标题本身也是干净的。

## 一、先纠正一个前提：BQ 的标题并不缺关键词

| 检查项 | 结果 |
|---|---|
| BQ 系列**占位标题**（`Wholesale Shoes Model XX`） | **0 款** |
| 标题长度 | 78–128 字符，中位 104，**无一条超 128 上限** |
| 品牌词命中 | **0 款**，干净 |

**所以 BQ 的问题不是"标题没有关键词"** —— 那 103 款零关键词标题全在 HR。BQ 的真实问题是另外两个：

| 问题 | 款数 | 说明 |
|---|---:|---|
| **零曝光** | **18** | 搜索里完全不存在 |
| **零询盘** | **13** | 有曝光、有人看、没人问 |
| **零询盘 + 低CTR** | **12** | 曝光不少但点击率显著低于全店 1.16% |
| **低CTR** | **3** | |
| 覆盖搜索曝光合计 | **21,295** | 其中零询盘款占 **16,791**（79%） |

### 覆盖缺口（机会词在 46 款标题里的命中情况）

| 机会词 | 词指数 | 卖家规模指数 | 当前标题精确命中 |
|---|---:|---:|---:|
| **mens casual sneakers** | **491** | **5** | **0 款** 🔥 |
| mens breathable running shoes | 235 | 1 | 0 款 |
| loafers | 287 | 8 | 0 款 |

**关于小语种**：没有任何标题含法语词，但你却拿到了 **1,325 次法语曝光**（`chaussures pour hommes`，比 `shoes` 的 1,089 还高）。

→ **说明小语种流量来自平台对英文标题的自动翻译**，不是靠手写外语词得来。所以正确做法是**把英文核心品类词写扎实、让翻译映射准确**，而不是往标题里塞法语词（塞了反而像关键词堆砌）。

## 二、改造原则

1. **填满 128 字符上限** —— 旧标题平均 104，新标题平均 **122**（+17 字符），在不堆砌的前提下扩大覆盖
2. **保留作者事实** —— 旧标题里的 Thick Sole / Chunky / Anti-Slip / Mesh 等原样保留
3. **词族去重** —— 同一词根（含单复数）不重复出现，避免堆砌感
4. **主攻词轮换** —— 同组内不重复同一个主攻词，防止 46 条互相蚕食
5. **丢弃无价值属性** —— `Other` 这类值不写进标题；不堆颜色、不堆尺码

## 三、逐组策略与对照示例

### ① 曝光最高但 CTR 最低的（优先改）

**BQ049 / A230** ｜曝光 3,550（全店第 2）｜CTR **0.56%**（全店均值 1.16%）

```
旧(120): Wholesale Model A230 Knit Lace-Up Breathable Walking Shoes Lightweight
         Plastic Outsole Casual Sneakers for Men and Women
新(124): Mens Casual Sneakers Men Women Lace Up Light Weight Breathable
         Rubber Plastic Sole Knit All Seasons Walking Shoes BQ049 A230
```
**改动逻辑**：`Wholesale Model A230` 开头浪费了 22 个字符的黄金位 → 换成主攻词 `Mens Casual Sneakers`（词指数 491、卖家规模仅 5，当前 0 覆盖）。旧标题的 `Model A230` 信息移到尾部，不丢。

### ② 零询盘 + 极低 CTR

**BQ027-R1 / K6116** ｜曝光 1,211｜CTR **0.41%**（只有全店均值 1/3）

```
旧(78):  Grey Knit Lace Up Casual Walking Shoes Lightweight Breathable Sneakers for Men Women K6116
新(116): Mens Casual Sneakers Men's Lace Up Light Weight Breathable Mesh All Seasons
         Casual Walking Shoes OEM ODM BQ027-R1 K6116
```
**改动逻辑**：旧标题只有 78 字符 —— **上限有 128，白白浪费 50 个字符**。同时开头 `Grey Knit` 是颜色+材质，搜索价值低 → 换成主攻词。

### ③ 零曝光款（18 款，需要建立可发现性）

集中在 `BQ001–BQ004` 的 S1/S2/S3 变体（Wide Toe Box 系列）。这类没有历史排名可保，**可以更激进地铺机会词**。

### ④ 儿童款

**BQ016 系列** → 主攻 `Kids Casual Sneakers` / `Children Walking Shoes`。注意：系统属性里 **没有 Gender 字段**，性别是从你旧标题（`Girls School Shoes` / `Kids Knit Slip-On School Shoes`）保留的，不是我推断的。

### ⑤ 宽头款（属性真实标注 `Fit Type = Wide Toe Box`）

这 5 款的 `Wide Toe Box` 写进标题是**有属性依据**的。其余 41 款我**没有**写这个词 —— 符合你项目里「`Wide Toe Box` 不从外观推断」的规则。

## 四、附带发现：属性缺口本身就是提分点

数据拉出来才看到的——**你的商品属性有大面积空缺**：

| 缺失字段 | 款数 | 影响 |
|---|---:|---|
| `Upper Material` | **19 款** | 无法在标题声明鞋面材质；也是质量分的评分项 |
| `Closure Type` + `Fit Type` | **16 款** | 无法声明系带/套脚、无法声明版型 |
| `Upper Material` + `Fit Type` | 8 款 | |
| `Fit Type` | 3 款 | |

**补全这些属性可能比改标题更立竿见影** —— 属性是平台质量分与筛选器的输入，填了才能被"按材质/版型筛选"的买家找到。建议与标题改造**同批进行**。

### ⚠️ 我建议你这样做（风险控制）

1. **不要 46 条一起改。** 这些商品已有排名历史，批量重写会让平台重新评估、短期可能掉排名。
2. **先改 6 条灰度** —— 建议挑 `BQ049/A230`（CTR 0.56% 最该救）、`BQ027-R1/K6116`（CTR 0.41%）+ 4 款零曝光的，观察 7–14 天。
3. **改完不要动主图/价格** —— 否则无法归因是标题起了作用。
4. **同时补属性缺口**（第四节）。

### 需要你确认的 3 件事

1. **`loafers`（词指数 287、卖家规模 8）我故意没写进任何标题** —— 你的套脚针织鞋严格说是 Slip-On Sneaker，称 "Loafers" 可能失准。要不要用？
2. **`tennis`（词指数 321）也没用** —— 网球鞋是特定品类，你的产品不是。要用吗？
3. **型号写法**：新标题里型号我统一成 `BQ049 A230`（去掉斜杠）。你希望保留 `BQ049 / A230` 还是保持现在这样？

## 六、诚实说明：这套方案能做什么、不能做什么

**能做的**：把 46 款标题的**关键词覆盖面从"缺 20 个机会词中的 18 个"补到尽量完整**，且每条都有属性或作者原文依据。

**不能做的**：
- **不能保证曝光或 CTR 上升** —— 标题只是影响因素之一，主图、价格、MOQ、销量、店铺信任度同样决定结果。
- **CTR 低的根因我无法单独确认** —— 1,211 次曝光只 5 次点击，可能是标题吸引力不够，**也可能是主图在搜索结果里不够突出**。这个必须用同样的曝光量做 A/B 才能归因。
- **小语种曝光来自平台翻译**是目前证据支持度较高的**推论**，不是平台文档的明文结论。如果你有后台关于多语言发布的说明，可以推翻或确认它。
