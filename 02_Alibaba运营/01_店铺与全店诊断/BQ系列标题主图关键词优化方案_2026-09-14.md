# BQ 系列标题、主图与关键词优化方案

> 日期：2026-09-14（Asia/Shanghai）  
> 范围：BQ 系列现有链接；本方案不涉及 HR 商品，不主张删除或合并同款兄弟链接。  
> 任务性质：市场与店铺诊断、优化方法和执行批次设计；尚未修改线上商品。

## 一、结论先行

目前 BQ 的主要问题不是链接数量不够，而是大量链接虽然使用了不同图片 URL 和不同标题文本，买家在搜索页看到的仍是近似的商品卡：相近的侧视角、小鞋体、米白或浅蓝背景，以及高度重复的 `Walking Shoes + Knit + Wholesale/OEM` 表达。

下一轮不采用“只改一个字段、等待七天”的低效率做法，也不继续机械复制三套标题。应当以**单条链接的独立搜索意图**为单位，同时重构标题、关键词字段、M1 首图和前 3 图，使一条链接形成一个完整、统一的买家入口；再用同款兄弟链接承接不同入口。原始链接可以作为稳定基线保留，扩展链接优先改造。

最优先的四个方向是：

1. `Men's Casual Sneakers`：当前规模最大，适合真实属于男士休闲运动鞋的 BQ 款。
2. `Breathable Mesh / Sports Shoes`：适合网面、透气、系带和运动外观明确的款。
3. `Men's Casual Slip-On Shoes`：适合真实一脚蹬、弹力带或无传统系带结构的款。
4. `Wide Toe Box Shoes`：只用于已有单款宽鞋头证据的 BQ001、BQ002、BQ031 等，不向普通楦型扩散。

`Knit Shoes` 不应继续作为全店通用主词。实时结果量小且混入鞋面、针织设备和材料采购词，更适合作为属性词，和 `casual sneakers`、`slip-on shoes`、`breathable shoes` 组合使用。

## 三、对现有 BQ 多链接策略的诊断

### 1. 做对的部分

- 同一真实鞋款保留多条链接是可行的，不需要因为详情图接近就删除或合并。
- 工厂、生产、包装等详情模块可以复用，但必须保持事实一致。
- 颜色、图片和标题可以针对同一商品形成不同表达。
- 多数扩展链接已经拥有不同图片 URL，说明素材生产能力不是当前瓶颈。

### 2. 没做到位的部分

- 32 个多链接款号族大多仍沿用 `W1=Wholesale`、`R1=Daily Wear`、`O1=Custom Logo` 的固定三分法，导致不同鞋款之间的关键词结构高度重复。
- 148 条可读取 BQ 链接的关键词字段为空，标题承担了全部搜索覆盖任务。
- `Walking Shoes` 和 `Knit` 被写进几乎所有标题，使搜索入口过度拥挤；买家无法在首屏快速区分弹力带、条纹针织、厚底、低帮、透气网面和宽鞋头。
- 许多首图虽然文件不同，但仍是相近颜色、相近侧视、相近背景和偏小主体。机器判定“不同图”不等于买家感知“不同商品卡”。
- 标题平均 107.2 字符，73 条超过 110 字符。问题不只是长度，而是重要核心词经常被 `2026 New`、`Wholesale`、`Spring Autumn` 等弱区分词挤到后面。

## 四、新的多链接方法：一款四个入口，而不是三套固定文案

原始链接保留为稳定链接，三条扩展链接重新分工。每个款号不机械套用完全相同的四类，而是从下列入口中选最符合实物的三个：

| 入口 | 标题核心 | 关键词字段 | 首图任务 |
| --- | --- | --- | --- |
| 大类需求 | Men's Casual Sneakers / Casual Walking Shoes | 大类词 + 一个真实属性长尾 | 最容易识别鞋型的真实颜色，3/4 角度，主体最大 |
| 结构差异 | Slip-On / Elastic Band / Lace-Up / Thick Sole / Low Cut | 闭合结构词 + 鞋型词 | 让结构在缩略图中一眼可见 |
| 材质与季节 | Breathable Mesh / Textile / Summer Casual | 材质词 + 使用场景 | 使用辨识度最高的浅色或撞色，展示鞋面纹理 |
| B2B 采购 | Wholesale / Custom Logo / Private Label | 采购词 + 精准鞋型词 | 干净双鞋或成对展示；不在首图堆字 |
| 宽鞋头专项 | Wide Toe Box / Wide Fit | 仅证据款使用 | 俯视或 3/4 前视，真实展示前掌形态 |

标题建议控制在约 75–105 个英文字符，前 60–75 个字符必须完成“买家对象 + 核心鞋型 + 真实差异”。型号放末尾；`OEM ODM` 只保留在采购入口，不在所有链接重复；颜色通常交给首图和 SKU，不占标题核心位置。

关键词字段每条填写 3–5 个相关短语，标题中已出现的主词不需要机械重复。关键词之间应覆盖同一意图的变体，而不是跨品类塞热词。示例：

- 标题：`Men's Breathable Mesh Casual Sneakers Lightweight Thick Sole Walking Shoes Model L1026`
- 关键词：`men's casual sneaker; men's breathable mesh shoes; athletic walking shoes; lightweight casual sneakers`

## 六、主图与前 3 图执行规范

### M1 首图

- 真实产品照片或真实产品抠图作为不可替换的鞋型锚点；AI 只允许清洁背景、校正光影和优化构图。
- 不改变鞋型、鞋底纹路与厚度、闭合结构、真实颜色、材质纹理和货号身份。
- 单只或一双完整鞋，不做多角度拼图；背景纯白或非常浅的中性色。
- 鞋体完整可见，横向占画面建议约 82%–90%；不能为了占比切掉鞋头、鞋跟或鞋底。
- 同一款号四条链接的 M1 必须至少在“真实颜色、角度、单/双鞋构图、突出结构”中形成明确差异；只换米白/浅蓝背景不算差异。
- 首图不堆 `OEM/ODM`、MOQ、认证、促销或工厂文案。采购信息交给标题、属性和详情页。

### M2–M3

- M2 必须证明该链接的主搜索意图：例如条纹鞋面、弹力带、系带、厚底或宽鞋头。
- M3 展示另一真实颜色或鞋底/后跟结构，不能只是 M1 的轻微位移。
- M1–M3 在缩略图模式下也应能看懂，不能依赖小字。

### M4–M6 与详情图

- M4–M6 可承担鞋面细节、鞋底、后跟、颜色组合、上脚或使用场景。
- 同款详情页里的工厂、生产、包装与 OEM/ODM 图片可以复用；它们不是区分链接的主要区域。
- 详情图复用不构成删除链接的理由，但每条链接的前 3 图与标题必须兑现各自搜索意图。

### 上线前视觉验收

1. 原图与候选图并排核对鞋头、鞋面纹理、鞋带/弹力带、后跟和外底。
2. 以 160–240px 搜索缩略图查看主体辨识度。
3. 同款四条链接做 M1 联系表，确认不是同色、同角度、同模板。
4. 再做每条六图联系表，确认没有错款、变形、重复槽位或风格断裂。
5. 通过后才上传图片银行并提交；提交后回读 API，最后打开公开页复核。

## 八、评价方法：整套优化，而不是低效单变量等待

本轮采用“意图包”评价：标题、关键词、M1 和前 3 图共同服务同一个搜索意图，作为一个整体上线。上线前保存每条链接的基线数据和原图；上线后按款号族、链接和关键词三层复盘。

主要指标：

- 搜索曝光：新关键词是否带来覆盖。
- 搜索 CTR：商品卡是否与搜索意图匹配。
- 访问人数与停留/互动：点击后是否继续了解。
- TM、询盘人数与有效询盘内容：是否吸引到采购型买家。
- 关键词结构：曝光是否从泛词迁移到相关长尾词。

不是机械等待固定七天：达到足够曝光样本就复盘；明显错款、错词或视觉异常立即回滚；样本不足则按 14 天或两个完整周累计。对同款兄弟链接比较的是“哪个搜索入口更有效”，而不是假装能把标题、图片和关键词的贡献完全拆开。

严禁使用截图教程中提到的自买自卖、虚假订单、虚假评价或其他操纵数据手段。这类方法不能作为贝强运营方案。

## 九、网络经验转化为贝强规则

Alibaba 官方高质量发品指南强调：标题应由营销词、属性词、核心词和使用场景组成；关键词至少填写 3 个相关词，避免重复和无关词；主图要求产品完整、背景干净、主体占比高，附图再承担多角度和信息图。[GGS 商品力白皮书](https://activity.alibaba.com/supplier/1fb02307.html)

官方产品名称指南指出，应按用户搜索选择关键词，标题包含关键产品特征，为相似产品写不同名称，避免关键词重复和只写品牌/型号。[Product Name Guide](https://activity.alibaba.com/ggs/product_name.html)

官方图片指南要求图片与标题、关键词和描述一致，并从不同角度展示同一产品；图片需清晰且由供应商或其代理制作。[Product Photo Guide](https://activity.alibaba.com/ggs/Product_photo.html)

Alibaba 的 B2B 页面优化建议进一步说明，企业买家会进行更有针对性的搜索，页面应明确 MOQ、定制边界、规格和多角度高质量图片，而不是只提供泛化卖点。[How to Optimize B2B Product Pages that Convert](https://seller.alibaba.com/businessblogs/pxigj1o5-how-to-build-and-optimize-your-b2b-product-page-that-converts)

因此，贝强不照抄热销卖家的标题、价格或图片，也不把高销量当作因果结论；只提炼“精准搜索词、强鞋型识别、真实结构证明、清楚采购边界”四个可迁移原则。
