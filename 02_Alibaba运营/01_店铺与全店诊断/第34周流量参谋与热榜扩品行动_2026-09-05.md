# 第 34 周流量参谋与热榜扩品行动

## 结论

当前不是单纯的“商品数太少”，而是曝光覆盖、搜索点击和询盘承接三层同时偏弱。店铺已有 182 个商品，但第 34 周只有 53 个商品获得访问，搜索曝光 720、点击 5，CTR 仅 0.69%，询盘为 0。继续扩品是必要的，但新品必须用不同的需求方向、完整单鞋首图和采购型卖点去抢新词，不能再做机械排列组合。

## 真实数据

- 近 30 天全店流量 331，环比 -7.5%，比优秀同行低 7.8 个百分点。
- 搜索流量 76，环比 -10.6%；场景流量 147，环比 -9.3%；互动流量 21，环比 -27.6%。
- 流量转化率 4.2%，环比下降 9.4 个百分点。
- 商品分层：高曝光高点击 6，高曝光低点击 30，低曝光高点击 1，低曝光低点击 37。
- 近期最有明确询盘信号的单品是 L1026：103 访客、3 个询盘人数、1 个 TM，反映出“明确鞋型+完整信息+卖家信任”比单纯铺词更有效。

## 市场方向

- Men's Walking Style Shoes 买家规模最大，但供需比 574.01，竞争非常拥挤；不适合继续用泛化“walking shoes”铺量。
- Men's Chunky Shoes 买家规模 1060，同比 +29.81%，供需比 232.71，转化率 7.4%，是当前更值得测试的相邻方向。
- 热销榜可安全转化的方向：透气网面慢走、轻量白鞋、复古厚底、日常跑走、合成绒面办公休闲、一脚蹬/套袜、低帮杯底和无品牌旋钮闭合。
- 排除带设计师或受保护品牌识别的榜单款，不复制竞品图片、商标和无法证实的参数。

## 已执行的第一批

已将 8 个不同热榜需求方向转化为贝强自有 HR001–HR008 概念款 A 链接，通过 Alibaba Schema API 提交发布。每款均使用：

- 1 张完整单鞋首图，顶部仅保留 `FACTORY DIRECT / OEM/ODM / CUSTOM LOGO / MOQ 2 PAIRS / QC / EU 36-45` 采购信号。
- 6 张主图、3 个颜色、EU 36–45 共 10 个尺码、4 张产品详情图、5 张公司图。
- 独立型号、独立 SKU 编码、鞋型对应颜色图和买家导向亮点。
- MOQ 2 pairs，价格梯度保持店铺基线并按款式做 0.01 美元级别的合理差异；结构化交期保留 100 双/31 天，产品亮点则明确“确认要求后立即安排生产与发货，定制时间按材料、数量和要求确认”。

2026-09-05 发布回读：8 款全部为 `approved / display=Y`，且 8 款的型号、6 张主图、3 个颜色 SKU、EU 36–45、4 张产品详情、5 张公司图、MOQ 2 和 100 双/31 天结构化交期均通过 API 回读。发布 Schema 将 SKU 库存落成 0，已通过库存专用 API 将每款 30 个 SKU 同步为店铺现有基线 999 并逐款回读确认。

库存同步后的最终质量分回读：HR001–HR008 全部为 `5.00`。

公开页验收：8 个产品详情页均返回 HTTP 200，不存在发布成功但公开页不可访问的情况。

HR001 后续仅用增量更新接口补齐标题中的 `Model HR001`，保持库存 999 和质量分 5.00；当前状态为 `modified / display=N`，等待这次标题修改审核完成。HR002–HR008 仍为 `approved / display=Y`。

## 接下来的流量动作

1. 审核转在线后，逐款回读质量分、公开页、颜色 SKU 和视频；任何一款不通过就停在该款修复。
2. 用户确认执行颜色入口策略后，8 款 × 3 色共 24 条已提交。A/B/C 不是只换颜色文字：分别对应批发进口、Private Label、线上卖家三种采购意图，并使用不同首图构图、主推色、标题、关键词簇、型号和价格尾数。审核通过后按 7–14 天曝光、点击、CTR、访客、TM 和询盘选出赢家。
3. 高曝光低点击款优先改首图的主体占比、颜色和搜索意图表达；低曝光高点击款增加关联词方向和橱窗，而不是改掉有效主图。
4. 产品亮点固定回答五个 B2B 问题：批发价格怎么算、能定制什么、怎么验货、多久安排生产/发货、能否先做样。
5. 每周从流量参谋记录同一组口径，用“需求方向”而非“新上数量”决定下一批：强化赢家，暂停无曝光无点击方向。

## 买家搜索词结论

- 店铺引流词中，`walking style shoes` 获得 17 次曝光、`sneakers` 12 次、`shoes men` 10 次，但均为 0 点击；这些泛词竞争大，只能作为标题中的类目词，不能单独承担点击。
- 新链接采用“采购修饰词 + 核心鞋型 + 材料/功能 + 使用场景”的长尾结构。优先词簇包括：`OEM walking shoes`、`private label sneakers`、`custom logo casual shoes`、`breathable mesh walking shoes`、`lightweight walking sneakers`、`chunky walking shoes`、`platform sneakers`、`slip on walking shoes`、`dial closure walking shoes`、`synthetic suede platform sneakers`、`low top casual shoes`。
- 阿里公开供应页反复出现 `OEM/ODM`、`private label`、`custom logo`、`wholesale`、`breathable mesh`、`lightweight`、`walking style shoes`、`chunky/platform sneakers` 等组合，说明买家搜索通常不是只搜颜色，而是先搜鞋型/用途，再加材料、功能和采购方式。颜色用于首图和 SKU 选择，标题中只在能帮助区分时保留。
- `zapatillas` 和 `zapatillas informales` 各带来 8 次曝光但 0 点击，暂不把英文链接机械改成西语；如后续拉美访客增长，再建立独立西语词组与页面测试。

## 剩余商品调整原则

- 30 个高曝光低点击商品：优先改首图和标题前 60 字符，检查首图是否完整、是否与关键词鞋型一致、是否有克制的 B2B 采购信号；不先重做整套详情页。
- 37 个低曝光低点击商品：先检查类目、核心属性和关键词覆盖。若款式仍符合市场方向，再补高意图长尾词；若鞋型同质且无证据，不继续制作更多同类链接。
- 6 个高曝光高点击商品：保留有效首图和核心标题，只增强询盘承接、视频和详情页采购信息。
- 1 个低曝光高点击商品：优先进入橱窗/P4P 小预算测试或扩关联词，不改掉已有效的首图。

## 接口边界

当前应用的国际站数据管家 API 权限仍未开通，且官方说明为聚石塔限制能力；因此自然流量数据继续从已登录的流量参谋页面取得。商品、图片银行、发布、视频绑定和质量分回读继续使用 API。视频源文件上传是当前唯一仍需页面操作的环节；上传后的视频查询和商品绑定都可通过 API 完成。
