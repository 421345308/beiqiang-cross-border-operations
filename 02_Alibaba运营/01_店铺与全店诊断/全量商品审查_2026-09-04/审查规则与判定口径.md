# 全量商品只读审查规则与判定口径

日期：2026-09-04。范围：线上商品目录 151 款；本轮先机械评分前 50 款。只读读取线上目录、主图机器审计、次级图片复审摘要及本地最终上传资产，不修改商品、图片或发布状态。

## 1. 标题、关键词、货号

- 从 `model` 提取制造商货号：含 `/` 时取斜杠后 token；否则取完整 model。标题必须不区分大小写包含该 token；缺失即 `FAIL/MODEL_MISSING`。
- 另检标题是否误含其他目录商品的制造商货号；误含即 `FAIL/CROSS_MODEL`。标题中出现同一货号两次、重复短语（如 `Large Size for Large Size`）记机械质量警告。
- 核心词覆盖采用弱判定：产品类型（shoe/sneaker/walking/casual）、结构（knit/mesh/textile/lace-up/slip-on 等）、B2B 意图（wholesale/factory supply/OEM/ODM/private label 等）至少覆盖两类；缺失仅降分，不因模板标题单独阻断。
- 未有 SKU/资料证据的 `wide toe box`、医疗/矫形、认证、真皮、防水、免费运费、DDP、固定交期、产能等承诺均为阻断或需人工复核；BQ032 及以后不得仅凭外观写 wide toe box。

## 2. 重复与聚类

- `EXACT_TITLE`：规范化标题完全相同，阻断。
- `NEAR_TITLE`：小写、去标点、去角色模板词（wholesale/custom logo/factory supply/OEM ODM/private label/model/for daily walking 等）后，token Jaccard ≥0.80；需人工确认是否同鞋型误拆。
- `FAMILY-3`：同制造商货号的 W1/R1/O1 组合归为同鞋族。它们可分别服务批发、零售展示、定制买家，不能仅凭标题判定重复；必须继续核验首五图、详情角色和 SKU。
- `EXACT_FIRST_IMAGE`：首图 CDN URL 完全相同，阻断。感知近重复以机器审计的 reference distance 或人工图像复核为准；没有证据不宣称通过。

## 3. 详情四图语义角色清单

每款至少四张“信息完整、产品专属”的图，且角色互补：①产品总览/身份；②鞋面、材料或结构；③尺码/脚型/穿着适配；④鞋底/功能或耐用结构。颜色图、订单支持/OEM 图可作为额外角色，但不能用公司图替代产品证明。文件名只能作线索，最终应以画面和文字可读性确认。

## 4. 公司五图语义角色清单

五张公司图应分别覆盖：①供应商/工厂身份；②开发与 OEM/ODM；③生产流程；④质检/抽检；⑤包装、装箱或出货。不得出现第三方品牌或 Palison 包装、中文包装、与产品无关的宣传，也不得五张图表达同一空泛“factory”语义。公司图放详情页下游，不能替代产品详情图。

## 5. 买家价值与评分

机械评分仅判断证据是否存在：货号/标题 10、关键词 10、首图机器风险 15、首五图风险 15、详情角色 15、重复风险 10、公司图角色 10、买家决策信息 10、询盘入口 5。缺少公开或本地证据记 `PENDING`，不推断为通过。发布阻断沿用权威 SOP：标题/货号不匹配、首图/详情非本品、SKU/颜色不一致、详情少于四张完整产品图、公司图不合规、临时或嵌套 URL、未完成公共页核验。

证据文件：以 `API全量六图复审_2026-09-03_修复后/线上商品目录.json`、同目录 `主图机器审计.csv` 为主，辅以 `次级图片审计摘要.json` 及本地 SKU 文件夹。Alibaba 列表缩略图为 320px 预览，不能据此判原图低清；机器风险只作筛选，不能替代视觉判断。修复后首图仅保留审计仍存在的 `P0_LOW_HERO_OCCUPANCY`。
