# 151 款六主图视觉复核结论

日期：2026-09-04

范围：人工查看 `API全量六图复审_2026-09-03_修复后` 的 16 张联系表，覆盖目录序号 1–151。该联系表用于内容分流；带 `DOWNLOAD_ERROR`、`NON_SQUARE`、`LOW_HERO_OCCUPANCY` 的旧机器标签必须用当前 API URL 重新验证，不能直接当成线上故障。

## 全店共性结论

1. 目录前约 111 款大多是白底/浅底的单鞋、双鞋、颜色与鞋底视图，商品身份通常清楚，但不少链接的六图只是颜色和角度轮换，缺少鞋面、穿着方式、鞋底、颜色选择、应用场景等互补信息。
2. 同货号 W/R/O 家族中，有多组主要通过图片顺序变化区分；这不等于已确认重复铺货，但从买家视角差异不足，应按不同采购意图重做首图与前五图，而不是继续排列组合。
3. 目录约 112–151 的新模板整体更接近正确方向：首图先识别商品，后续图分别解释鞋面、穿着、鞋底、颜色和场景。这个角色结构应作为后续优化基准，但每张图中的材料、重量、宽楦和性能词仍必须有 SKU 证据。
4. 部分旧款使用国内电商风格的实拍拼图、不同背景和近似角度；信息虽然真实，但页面观感不统一。优先把首图整理为干净国际站白底/浅中性背景，后续保留真实细节和穿着证明。
5. 主图主体偏小的机器提示大量来自细长侧视图。人工复核后不能一律判废；只有鞋体明显小、留白过多、缩略图辨识度差时才进入重做队列。

## 优先视觉队列

### P0：当前 URL 复核后决定是否立即替换

旧联系表序号 `56、71、107、115、119、122、135、137、145、147` 存在下载失败、非方图或不可用预览标签。已单独建立当前线上 URL 验证任务；只有当前链接复现问题才写入线上。

### P1：确认存在买家信息不足

- BQ029 / A025 的多链接六图高度重复，尤其高帮袜套款多为同一侧面视图反复出现；应补鞋底、后跟、鞋口/织面、上脚或弯折信息，并让各链接首图承担不同采购意图。
- BQ025 / A1689、BQ022 / A2208、BQ019 / A206 等多个 W/R/O 家族存在同图重排倾向；保留真实颜色与尺码不变，重做首图构图和前五图角色。
- BQ013 / T55836 等商品的产品图本身尚可，但标准材料字段使用描述性词，视觉优化不能替代属性证据核实。

### P2：统一提升

- 将后续六图结构统一为：识别型首图、结构/鞋面、穿着/闭合、鞋底/弯折、真实颜色、使用场景或采购信息。
- 颜色图只承担颜色选择，不伪装成另一张主图；SKU 颜色缩略图必须与名称精确对应。
- 工厂/OEM/质检/包装内容放在详情页公司图，不占据前排产品识别图；主图视频使用对应鞋视频，无法对应时才使用明确的通用工厂证明视频。

## 写入门槛

任何图片替换前必须同时通过：真实 SKU 身份、无第三方标识、无中文促销、正式图片银行 URL、主图与详情不重复、SKU 颜色绑定正确、更新后 API 回读、审核后公开页终验。
