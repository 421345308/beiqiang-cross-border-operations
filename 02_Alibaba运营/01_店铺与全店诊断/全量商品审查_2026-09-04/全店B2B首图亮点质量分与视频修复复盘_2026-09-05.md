# 全店 B2B 首图、产品亮点、质量分与视频修复复盘

日期：2026-09-05

## 问题与根因

1. 产品亮点重复标题：旧生成逻辑在缺少产品亮点时错误地把商品标题当作兜底文本，导致标题进入 Product Highlights。
2. 六个 3.9 分：初始回读中 5 款为首图被判定“有边框或拼图”，1 款为童鞋标题与成人慢走鞋类目不一致。
3. 首图 B2B 信息不足：旧版只强调 Custom Logo，未完整表达工厂直供、OEM/ODM、小起订和出货前检查。
4. 通用工厂视频问题：旧视频中存在无完整开头/结尾，以及把 16:9 横屏素材裁成 9:16 竖屏的问题。

## 已完成的全店修复

- 商品范围：151 款。
- 151 款首图均加入两层 B2B 采购信息：
  - `FACTORY DIRECT | OEM/ODM`
  - `CUSTOM LOGO | MOQ 2 PAIRS | PRE-SHIPMENT QC`
- 151 款 Product Highlights 已改为采购决策信息，不再重复标题：工厂直供报价逻辑、Logo/颜色/包装定制、出货前检查、规格确认后及时安排生产与发货、样品沟通。
- API 首轮写入与逐款回读：151/151 生效；3 个严格保护字段比对异常经专项二次回读均通过。
- 对平台持续判定为“边框/拼图”的 8 张首图，采用同款真实图全画幅重构，移除四周白色卡片边框和独立信息面板，将 B2B 文案直接叠加在场景中。

## 质量分专项

- 修复前：133 款 5.0、12 款 4.9、6 款 3.9。
- 第一轮统一首图后：131 款 5.0、12 款 4.9、8 款 3.9。新增低分证明“顶部独立信息区 + 内嵌商品图”仍会被算法视为边框/拼图。
- 第二轮针对 8 款改为无框全画幅，均已通过 API 写入和图片读回；等待平台审核完成后记录最终质量分。
- 原童鞋类目错配商品在后续平台回读中已恢复 5.0；不擅自切换店铺一级经营类目。

## 新版通用工厂视频

- 文件：`E:/贝强大文件/05_内容与视频/01_贝强商品视频/通用工厂视频修复_2026-09-05/edit/final_beiqiang_factory_44s.mp4`
- 参数：44 秒、1280 × 720、30 fps、H.264 + AAC、16:9 横屏。
- 内容顺序：工厂外观 → 材料准备 → 针车 → 成型 → 包装 → 检查/生产线 → OEM/ODM 询盘引导。
- 修复点：保留原始横屏构图，不裁成竖屏；补完整工厂开场和 B2B 结尾；不再使用无头无尾片段。
- 阿里开放 API 能查询、绑定和回读视频，但没有本地 MP4 上传到视频银行的接口。新版视频只需人工选择上传一次，审核完成后 56 个通用视频商品可全部通过 API 批量换绑。

## 后续发布门槛

- 首图不能使用四周大白边、拼图、尺码卡、局部残缺鞋体或产品被裁断的图片。
- B2B 信息必须是覆盖层，不得把商品图缩小后放入独立卡片。
- Product Highlights 只写采购决策信息，绝不把标题当兜底。
- 通用视频必须 16:9、开头交代工厂、结尾有询盘动作；不允许横屏强裁竖屏。
- 所有写入以 API 回读和公开页检查为完成标准。
