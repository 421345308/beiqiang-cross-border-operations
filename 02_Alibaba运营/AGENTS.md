# Alibaba执行入口

[商品全生命周期SOP](00_运营SOP/国际站商品全生命周期SOP.md)是本渠道唯一规则源。单字段草稿只定位适用事实与字段章节；正式发布或修复再读取适用执行、保护和验收门，不为小任务遍读全部经营材料。

- 共用产品、来源与资产入口回[产品中心](../00_总控台/产品中心/README.md)；本渠道商品ID、字段及状态维护于 `05_扩品工程/数据/国际站商品.json`，执行索引由它与共用数据组合生成。供应商及旧HR编码不再形成独立当前项目。
- 发品/修复使用 `alibaba-openapi-operator` 和当前Schema成功证据；接口及规格入口见[工具说明](../08_工具链/01_业务脚本/国际站扩品/README.md)。历史Workctl/代理方案不能恢复为当前路线。
- 修改范围由本任务决定；写前基线、关联字段、正式回读和公开验收按SOP核。未知结果先核实，不重放已成功或结果未知的创建。来源、页面质量、评分和公开呈现分别判断。
- 商业基线、图片角色/数量、单款例外及评分完成条件只在SOP与单款证据维护。本入口不另存默认值、阶段目标或待办。
- 单字段任务只交付该字段及依据；完整发品任务按SOP覆盖选品、内容、素材、SKU、商业字段及验收。结果回原对象，不按会话新增影子台账。
