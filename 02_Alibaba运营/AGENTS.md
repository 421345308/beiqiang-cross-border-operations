# Alibaba 执行约束

先读 `00_运营SOP/国际站商品全生命周期SOP.md`，这是发布、修复、图片与验收的唯一业务规则源。根 `AGENTS.md` 的货源和证据边界仍适用。

- `HOLD_SOURCE` 与页面质量分开，API 成功不能解除货源缺证。局部修改、共享变更和店铺级风险的核验与阻断范围统一按 SOP §9 执行。
- 商业基线只从唯一 SOP 和单款证据读取，不在本入口复制价格、包装、MOQ 或交期数值；结构化字段不自动构成对买家的生产或发货承诺。
- GPSR 暂时接受部分欧盟国家屏蔽，不等于已合规；不得编造 EU Responsible Person。
- 已授权 API 操作用 `alibaba-openapi-operator`，能力判断先查 `08_工具链/01_业务脚本/国际站扩品/schema_publish_contract.py`；Workctl 旧路线只作历史追溯，不恢复执行。浏览器用于授权、未支持字段及公开页验证。凭证不进 Git 或报告。
- 图片必须用官方图片银行/CDN URL，禁止 Accio 临时或嵌套 URL。
- 发布/修复按 SOP §§6–9 核验适用字段、关联字段及买家公开结果。完整商品默认六主、至少四详、五公司；2627BSK 单款例外统一读 SOP §4，不降低全店默认，不重复凑图。
- 当前产品、来源和进度统一维护 `05_扩品工程/数据/产品与链接台账.json`，生成 `05_扩品工程/国际站合规扩品工程总控.md` 供负责人阅读；同款A/B/C只溯源一次。正式回执写商品ID、型号、时间、操作范围、回读与公开结果；不另建每次修改的进度报告，局部成功不当全生命周期完成。
- 完整发品交付包含采购意图、关键词、标题、属性卖点、主图角色、详情模块、询盘钩子和待确认项；单字段修改只交付该字段及必要依据。

- 本批“改造完成”须通过唯一 SOP 的发布后评分完成门及原有全内容验收；未知分数不得填猜值，评分不作首次发布前置条件。
