# Alibaba 执行约束

先读 `00_运营SOP/国际站商品全生命周期SOP.md`，这是发布、修复、图片与验收的唯一业务规则源。根 `AGENTS.md` 的货源和证据边界仍适用。

- `HOLD_SOURCE` 与页面内容质量分开。先核对原始包和实物来源，API 成功不能解除货源待核验；全店审计有阻断时不继续发新品。
- 商业基线在唯一 SOP 维护：2026-09-04 确认 MOQ 2 pairs、当前线上价格梯度、结构化商机品交期原值、单件 34 × 23 × 13 cm / 0.5 kg / 1 pair；单款证据覆盖基线。不得把结构化周期当生产承诺或承诺全店 3 天发货；定制交期按订单要求在下单前确认。
- GPSR 暂时接受部分欧盟国家屏蔽，不等于已合规；不得编造 EU Responsible Person。
- 已授权 API 操作用 `alibaba-openapi-operator`，Workctl 命令从当前 schema/help 发现。浏览器用于授权、未支持字段及公开页验证。凭证不进 Git 或报告。
- 图片必须用官方图片银行/CDN URL，禁止 Accio 临时或嵌套 URL。
- 发布/修复完成须核验：标题/型号、六张主图、SKU 绑定、至少四张信息完整的商品详情图、五张公司图、坏 URL、文案、trunk 与公开页。不要为凑六张详情图增加填充图。
- 回执写商品 ID、型号、时间、操作范围、回读与公开页结果；局部首图/质量分专项成功不能写成全生命周期验收完成。
- 完整发品交付包含采购意图、关键词、标题、属性卖点、主图角色、详情模块、询盘钩子和待确认项；单字段修改只交付该字段及必要依据。
