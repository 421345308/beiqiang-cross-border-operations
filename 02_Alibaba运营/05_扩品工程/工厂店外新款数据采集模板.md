# 工厂店外新款数据采集模板

用途：收集达到国际站100款目标仍缺的44个真实独立新款。每个货号建立一个文件夹，禁止把颜色、加绒或标题变化当成新款。

## 每款最低资料

1. 工厂货号与内部暂定名称。
2. 至少6张清晰实物图：左右侧、正面、后跟、俯视、完整鞋底；另附每个真实颜色一张单鞋或一双鞋图片。
3. 鞋面、里衬、中底和接地外底的实际材料口径；配方不确定时写通用材料，不猜化学名称。
4. 真实尺码范围，只记录EU/CN原始尺码；没有实测表时不提供US换算和脚长。
5. 所有真实颜色及特殊尺码限制。
6. 闭合方式、适用人群、常规楦/宽楦；宽楦必须有实物或负责人确认。
7. 是否可提供无标版本；若原图含第三方Logo，还需无标实物图并复核整体设计。
8. 是否沿用当前商业基线：MOQ 2双、三档价格、商机品结构化交期保持原值、34×23×13 cm / 0.5 kg / 1双；买家侧只写尽快安排生产或发货，定制交期按材料/数量/要求确认。不同则逐项写明。

## 独立款判定

至少有一项真实关键结构差异：鞋面结构、外底几何、闭合方式、后跟/鞋头结构、保暖内里、用途或独立尺码人群。仅颜色、标题、图片、型号、尺码组合或加绒变化不直接建立新链接。

## 推荐交付批次

每次提供10–15个货号。收到后统一执行：来源登记 → 货号/图像/结构去重 → IP与事实闸门 → 国际站图片加工 → 图片银行 → 官方Excel → 平台检测 → 整批导入 → 公开页验收。
