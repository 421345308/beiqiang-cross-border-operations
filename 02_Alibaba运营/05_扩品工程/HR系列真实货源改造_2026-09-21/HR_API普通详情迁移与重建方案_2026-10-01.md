## 已核实的 API 能力

官方发布及更新文档明确：普通详情使用 `productDescType=2` 和 `superText`，后者为转义的富文本 HTML。所有图片先进入官方图片银行，再把 URL 写进 HTML。可以在一次详情请求中包含完整商品图、公司图、规格表、价格说明和 FAQ，减少逐图界面操作。

HR020-A 当前详情类型为4，当前 render 提供 `superText`；当前类目发布 Schema 的详情选项也包含普通编辑2。以上证明有此类型和字段，**不证明现有结构化4直接改2一定成功**。原生 API 不支持结构化图集的通用删除替换，不能把普通 HTML 与结构化字段混作一条已验证路线。

官方来源：[发布文档](https://developer.alibaba.com/docs/doc.htm?articleId=119213&docType=1&treeId=456) §3.4.2；[更新文档](https://developer.alibaba.com/docs/doc.htm?articleId=119214&docType=1&treeId=456)“修改详情”。

## 建议顺序

1. 优先验证原有 HR020-A 链接能否直接迁移到普通详情，保留原 Product ID。完整候选同时保留六主图、真实12 SKU、三档价、准确标题和类别属性；不能只更换详情而留下旧款身份。
2. 若原链接迁移被拒或正式回读不生效，记录一次实际失败，不循环换空节点。评估 API 新建普通详情商品。
3. 采用重建时，先建并验收新页，再逐条下架已被替代的旧页；永久删除放在确认不再需要旧链接之后。先全量删除会失去链接连续性，并使新页未通过时无法回退。
4. 旧链接历史曝光、点击和询盘需要按已有流量分析区分；有价值的链接优先保留和修复。不能承诺重建后立即恢复流量或排名。
5. ABC 必须有真实采购意图和页面内容差异；单纯改标题、首图颜色、详情类型或 Product ID 都不能证明没有重复铺货。
