## 官方平台字段

- HR013 A/B/C 当前类目 `201334413`，官方 `alibaba.icbu.category.get.new` 回读为 `Men's Shoes > Casual Shoes > Walking Style Shoes` 叶子类目，当前款 777 网面套脚休闲步行方向与此路径相符。类目树回执 `request_id=213c934417901714539841295`；上级查询 `request_id=0b80d2d617901714966137534`。
- 当前 [`alibaba.icbu.product.schema.get`](https://developer.alibaba.com/docs/api.htm?apiId=50063) 对该类目回读 `biz_success=true`。属性 `p-191290426 Outsole Material` 为必填，可选 `Other=-1` 且支持自定义 `inputValue`，所以来源图写出的 `MD 大底` 可以按**自定义 MD**表达；不必错填 PHYLON、Rubber 或 EVA。
- `p-191290430 Lining Material` 必填，支持自定义文本；来源页“鞋面内里材质：布”可按广义 **Cloth** 表达，不细化为 Mesh 或 Cotton。
- `p-20700 Midsole Material` 必填，虽然选项包含小写 `md` 和 `Other`，但来源页未说明**独立中底**的材质、是否为一体底或分层结构。不能因为大底是 MD 就把中底也写 MD，更不能继承旧款 EVA。平台 `Other` 也不是“未知材料”的可证替代物。
- 官方 [`category.get.new`](https://developer.alibaba.com/docs/api.htm?apiId=50064) 显示相邻 `Boat Shoes / Canvas Trendy Shoes / Chunky Shoes / Skateboarding Shoes / Basketball Style Shoes` 等都不比 Walking Style 更符合 777；不能为了回避必填字段错分类目。

## 买家与运营结论

保持 `777` 作为同一 HR013 A/B/C 家族候选；已制作的同鞋 B2B 图稿无需因两个失效替代货号返工。下一步只对 **777 的中底分层**找可靠的同货号资料/实物信息；若无法取得，再选择另一个现行可接单、素材及材料完整的相似款整组替换。任何替换都要重新做图与 30% 价差，不混用 777 图。

本次市场页标题中的“透气 / 轻便 / 缓震 / 防滑”只是卖家用词，不转成贝强未经证实的性能承诺。B2B 关键词可用 `mesh slip-on casual shoes / walking style shoes / wholesale` 的品类与采购意图组合，但标题须以当前款结构和后台选词参谋复核，不从热词推断鞋底或宽楦属性。
