## 维护协议

新增或改造正式成功后，同步一行精确商品 ID/本店型号/原货号及来源；供应商原货号与买家可见本店型号分列。新款未取得ID时保持候选，UNKNOWN先对账，不重建。旧新版本/ABC同款是不同链接记录，按来源鞋款链接和原货号另做独立款去重，不用行数报鞋型数。

来源更新必须写原观察日、证据文件或URL、核价币种/单位/数量条件。发生换款覆盖对应映射并在冲突栏引用旧新证据，不把所有旧候选变成并列可用渠道。平台状态由对应最新回读更新，来源、评分和公开QA分开。空白来源不自动认定自产或外采不可供；是否自有工厂仍按原包证据。

CSV为维护真源，查询HTML只作同数据展示；更新CSV后同步重建HTML并核行数、ID唯一性、前导零、链接和敏感信息。不上传凭证、cookie、私钥、客户原始资料或配置。负责人2026-10-07明确允许本任务供应商产品资料同步现有公开仓库；授权不扩展为买家商品页披露内部采购信息。

选品与可比报价规则见[唯一商品SOP](../../00_运营SOP/国际站商品全生命周期SOP.md#11-供应商总表与本批选品比价2026-10-07)。研究与发布分阶段，本任务仅整理与同步，不发布或改价格。
