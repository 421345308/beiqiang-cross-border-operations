# 供应商查询入口

日常看[扩品总文件](../国际站合规扩品工程总控.md)，或打开[可搜索查询页](供应商产品查询.html)。按产品家族、链接型号、商品ID、供应商和原货号查原鞋款直链。A/B/C只展开关联链接，款式来源只维护一次。

[产品与链接台账](../数据/产品与链接台账.json)是唯一可编辑数据；[兼容CSV](供应商产品总表.csv)和查询页是生成结果，不独立改动。CSV保留逐商品ID的正式来源绑定，未正式绑定的兄弟链接不能靠继承标成已验收；共用款式来源在总文件/查询页查看。

已采用、候选未替换、原始包关联、来源冲突和缺证分别显示。价格保留原观察日期与条件，不把整理日期当重新核价；原四款、全分类和HR进度均回总文件查看。

[原始来源索引](来源证据索引.json)、[10-07来源观察](路崎来源核验_2026-10-07.json)、[10-07目录快照](平台目录快照_2026-10-07.json)是历史证据，不是第二份当前台账。发布规则见[唯一SOP](../../00_运营SOP/国际站商品全生命周期SOP.md)。内部执行文件继续留本地；已发生的公开推送审批拒绝不绕过。供应商资料的公开同步只按负责人明确的授权范围执行，不从整理授权推定可公开新增内部证据；凭证和客户原件遵守根Git边界。
