可重复执行：

```powershell
python 08_工具链/01_业务脚本/国际站扩品/build_sooxie_prelisting_batch.py --workspace C:\Users\spq\Desktop\贝强
```

配置正本：`08_工具链/01_业务脚本/国际站扩品/sooxie_prelisting_profiles_2026-08-14.json`。

处理规则：

1. 只对真实源图做选图、裁切、留白、尺寸归一和英文信息排版。
2. 不使用 AI 生成或改变鞋型、颜色、外底、Logo 和结构。
3. 国内中文详情图只用作材料/结构证据，不直接上传。
4. 主图 1000×1000，详情图 1200×1200，颜色图 1000×1000。
5. 每款自动验收6张主图、6张详情图、颜色名/颜色图数量一致和尺寸正确。
6. 视觉总览在 `02_可上传素材/00_最终上传/99_批次视觉验收_2026-08-14/`。

## 四、后台执行链路

Accio Desktop + Workctl 已在 BQ031 上证实可用，届时以当前动态 schema 为准，不照搬旧命令。

```text
用户登录国际站/Accio

→ 只读回查在线、草稿、拒审和违规列表
→ 批量上传本地图到图片银行

→ 按填写表建立唯一草稿
→ 回读标题/关键词/属性/图片/SKU/价格/MOQ/交期/包装/详情/物流
→ 通过后提交
→ copy/trunk/买家页核验
→ 7/14/30 天数据复盘
```

执行节奏：先用 BQ032 跑通一个完整草稿并回读；通过后每批 3-5 款顺序建立，不并发提交 20 款而失去错误定位能力。素材和字段已全部就绪，分批只是后台验收策略。

## 五、链接布局与规则

1. 上齐真实独立鞋型，用不同结构、人群、闭合和尺码段扩大搜索覆盖。
2. 不把同一鞋仅换标题、主图、详情页和关键词后重复发布。
3. 不用“违规后还有备用链接”作为账号安全策略。违规必须修复根因，IP 风险款不上架。
4. 同款不同颜色和加绒变体优先做同链接 SKU，不分散权重。
5. 发布后以曝光、点击、CTR、询盘数和询盘质量决定优化，不因零曝光继续制造重复链接。
