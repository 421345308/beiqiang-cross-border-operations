更新时间：2026-08-14

本文件是扩品工程的唯一续跑入口。每次继续任务时，先读本文件和 `数据/扩品批次台账.csv`，只执行“下一动作”，不要重新从头调研。

## 一、经营结论

国际站官方公开材料支持“把真实产品目录上齐”：真实产品越丰富，命中买家搜索的机会越多；高质量产品页的 Product Information Score（PIS）超过 4 时可获得更多搜索曝光。官方表述是上传 catalog 中的产品，不是复制同一商品制造多个 URL。

本工程采用以下原则：

1. 扩大真实鞋型、结构、季节和买家意图覆盖。
2. 不把同一商品仅换标题、主图、价格、关键词或详情模板后重复发布。
3. 不把“备份违规链接”当作账号安全策略。下架后应修复违规根因；重复或持续违规不会因为链接多而变安全。
4. 链接数量、页面质量和后续数据都要同时管理；不得用低质量页面换数量。

## 三、允许独立建链接的判定

一款候选只有满足“真实独立产品 + 独立商业角色”才能建新链接。至少应有一项强结构差异，并且页面证据完整。

强差异包括：

- 不同鞋楦或明显不同的鞋头空间。
- 不同鞋面结构或鞋型轮廓。
- 不同闭合方式，例如常规系带、一脚蹬、半拖、高帮套袜。
- 不同外底几何形状或明显不同的底部结构。
- 常规与加绒版本存在真实内里结构、季节和库存差异。
- 不同真实尺码段，例如成人大码与童鞋尺码线。
- 不同采购用途，例如低帮日常步行与高帮秋冬保暖。

以下内容不能单独证明是新产品：

- 颜色不同。
- 主图角度不同。
- 标题、关键词、价格或 MOQ 不同。
- 把美国、欧洲、Amazon、TikTok 等买家词换一遍。
- 详情页模块重新排版。
- 货号前面增加 A、AA 或后缀 `-1`，但实物结构没有变化。

边界案例统一处理：

- 仅颜色不同：作为同一链接 SKU。
- 同鞋型仅加绒：先判断能否作为同链接季节 SKU；只有内里、季节、交付和买家用途都独立时才考虑独立链接。
- 同鞋型不同标题：合并，不建新链接。
- 带第三方标识：隔离，取得合法无标实拍和权利确认前不得发布。

## 四、状态机

每个款只允许处于一个主状态：

`DISCOVERED → EXACT_CHECKED → VISUAL_DEDUPED → IP_CHECKED → FACTS_CONFIRMED → ASSETS_READY → DRAFT_READY → BACKEND_PRECHECKED → APPROVED → SUBMITTED → LIVE_VERIFIED → 7D/14D/30D_REVIEWED`

可转入暂停状态：

- `HOLD_DUPLICATE`：与现有商品实质重复。
- `HOLD_IP`：商标、图案或外观权利不清楚。
- `HOLD_FACTS`：材料、尺码、价格、MOQ、包装或交期未确认。
- `HOLD_ASSETS`：缺无中文、无第三方标识的国际站图片。
- `REJECTED`：不符合贝强定位或不值得投入。

状态推进规则：

1. 没有完成前一状态，不得跳到下一状态。
2. Workctl/后台写操作前必须输出字段差异、对象和影响范围。
3. 一款一草稿；审核失败时修复原草稿，不重建克隆草稿。
4. 发布后必须记录商品 ID、审核状态、公开页、关键词和图片版本。

## 五、批次节奏

每批建议 5-8 款候选，最多 3 款进入发品草稿：

1. 周一：同步搜鞋网增量和国际站在线/草稿/拒审列表。
2. 周二：完成货号、图片、结构、IP 三重去重。
3. 周三：向负责人集中确认产品事实和商业字段。
4. 周四：完成标题、关键词、属性、前六图和详情页预检。
5. 周五：逐款建立草稿、回读字段、人工确认后提交。
6. 上线后第 7/14/30 天：记录曝光、点击、CTR、询盘和买家质量。

数量目标以质量门槛约束：

- 每周新增真实候选：5-8 款。
- 每周进入草稿：1-3 款。
- 每款提交前：标题、属性、主图、详情、SKU、交易、物流和合规全部一致。
- 低质量或重复款不为完成数量目标而提交。
