# Alibaba 公司能力图复用模板 v4

状态：`LOCAL REVIEW ONLY`  
来源：BQ019-W1 整页视觉样板 v4 的已审阅公司图组。  
用途：作为各产品详情页和后续 B2B 图组中的公司能力模块基线；上传前仍需逐图确认文字、事实和当前联系方式。

## 五张角色

1. `C1_real_factory_identity.jpg`：真实工厂身份与供应商识别。
2. `C2_custom_project_flow.jpg`：定制项目输入和协作流程。
3. `C3_real_production_organization.jpg`：真实生产组织与订单执行。
4. `C4_real_quality_checkpoints.jpg`：真实质检节点。
5. `C5_packing_order_handoff.jpg`：包装选择、订单交接与出货协作。

## 复用边界

- 可以复用公司级真实能力和版式，不把公司图当成某双鞋的实物证据。
- 不得用 AI 虚构厂房、设备、产线规模、认证、检测结果或产能。
- 袋装、盒装等为可讨论选项；未单独报价时，不表示产品价已默认包含。
- 产品细节、颜色、尺码、材料、鞋型与 SKU 图必须按具体产品制作，不从本模板复用。
- 用到主图 M2-M6 时，应与本款的其他信息角色互补，不重复同一工厂信息。

## 正式使用门禁

1. 确认图片来自真实工厂/流程证据或中性流程图。
2. 确认英文、联系方式和公司名称仍准确。
3. 根据具体商品决定是否需要全部五张；只选能解决买家采购疑问的图片。
4. 上传 Alibaba 图片银行后记录 URL 和 file ID，再写入商品。
5. 回读商品并检查角色、顺序、清晰度及移动端可读性。
