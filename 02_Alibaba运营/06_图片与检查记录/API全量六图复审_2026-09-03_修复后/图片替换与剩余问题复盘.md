## 已沉淀的技术修正

- 透明 PNG 转 JPEG 时必须先在纯白底上进行 alpha 合成，不能直接 `convert("RGB")`。
- 图片审计请求明确使用 JPEG，避免阿里 CDN 自动返回 AVIF 引发假损坏告警。
- 网络下载错误至少独立重试三次；只有持续 404 才判定为坏链接。
- `productDescType=2` 必须检查 `superText` HTML；`productDescType=5` 必须按新版详情单独核验，不能套用结构化详情计数。
- 同一外观的常规/加绒 SKU 可复用真实颜色图，颜色图审计不得仅凭 URL 重复判错。
- 旧 `alibaba.icbu.product.update.field` 已返回下线错误；颜色 SKU 图片应通过 Schema 的 `saleProp / p-191288010 / value@img` 增量更新，并在更新后回读全部 SKU。
- 鞋类侧视首图不能仅用主体高度判断占比，应同时判断宽度、高度与主体框面积。
- 每次批量替换使用独立执行记录文件，禁止后续重试覆盖前一批记录。
