# 国际站商品身份与商详发布验收 SOP

适用范围：贝强国际站新发品、旧品改标题、主图替换、结构化商详补图和批量扩品。

## 一、不可跳过的八道门

1. **身份门**：唯一真源是 `02_可上传素材/00_最终上传/BQxxx_货号/00_上架填写表.md` 与原始数据包。先冻结 `BQ 编号、厂家货号、产品类别、材料、尺码、颜色`，再生成标题。
2. **标题门**：标题不得出现其他款货号；没有必要时不堆内部编号，但出现货号必须与数据包完全一致。发布前用目录名和 Model Number 双重比对。
3. **图片门**：逐图排查中文、国内平台促销词、水印、联系方式、第三方商标、错误尺码和与实物不符的 AI 改造。首图优先干净白底，后续图分别承担鞋面、结构、鞋底、颜色和场景证明。
4. **地址门**：商品接口只使用图片银行或 Alibaba 正式 CDN 地址。禁止把 `skill.accio.com` 临时 URL 直接写入主图、详情图或公司图；禁止出现 `alicdn.com/kf/https://...` 嵌套地址。
5. **草稿门**：线上商品先用浏览器 `pubAction=edit` 保存，确认 draft 存在后再调用 Workctl 分模块修改。不得为修复旧品重新建商品 ID。
6. **结构门**：标准结构化商详至少为 6 张产品图 + 5 张公司图；产品图顺序固定为概览、规格、尺码、颜色、批发支持、OEM/ODM 询盘。
7. **发布门**：提交前回读 draft，至少核验标题、Model Number、6 张主图、SKU 数量、详情图数、公司图数和坏地址扫描；任何一项不符不得发布。
8. **生效门**：发布成功不等于线上生效。依次记录 draft、copy、trunk；copy 正确而 trunk 仍旧表示审核切换中，只能写“已提交修复”，不能写“已生效”。

## 二、标准执行顺序

`数据包清单冻结 → 图片人工/视觉验收 → 图片银行正式地址 → 从正本保存草稿 → 分模块写入 → draft 精确回读 → 发布 → copy 回读 → trunk 回读 → 更新总控与交付记录`

每个 SKU 必须保存一个可复用载荷文件，字段只包含本次确认的事实和正式 CDN 地址。载荷不得混入临时测试 URL、过期删除操作或其他 SKU 的图片。

## 三、异常处理

- **详情为空**：从线上正本建立草稿，只补 `detailImage/companyImage/companyDesc`，不改价格、SKU、物流等无关模块。
- **错误临时地址已进入草稿**：先尝试正式替换；若 DELETE 回读不生效，在浏览器中按图集清空并保存，再写入正式图片。
- **审核中不可编辑**：记录 productId、copy 与 trunk 差异，等待可编辑后继续；不复制新链接规避审核。
- **标题货号冲突**：以本地数据包目录名和填写表为准，批量更新后逐款回读 Model Number 与标题。
- **图片已清理但未进图片银行**：状态标记为 `LOCAL_READY`，不得把本地路径或临时 OSS URL 当成已上线。

## 四、Sol / Luna 分工

- **Sol 负责判断**：数据包身份核对、标题策略、材料与属性冲突、图片是否国际站化、异常修复、发布前终审。
- **Luna 只做冻结后的机械执行**：按已批准 manifest 上传、填写、逐项计数和记录回执。输入必须包含 productId、正式图片 URL、目标计数和禁止修改字段。
- Luna 发现页面结构变化、URL 非 Alibaba CDN、计数不一致、货号冲突或必填项异常时立即停止，交回 Sol；不得自行猜材料、尺码、价格或替换图片。

## 五、单款验收回执模板

- SKU / 厂家货号：
- productId：
- 标题 / Model Number：
- 主图：`6/6`；中文/水印/第三方标识：`无`
- SKU：`颜色数 × 尺码数 = 总数`
- 产品详情图：`6/6`
- 公司图：`5/5`
- URL 扫描：`无 skill.accio.com；无嵌套 URL`
- draft：`通过`
- copy：`通过`
- trunk：`已生效 / 审核中`
- 本地载荷与交付记录：`已保存`
