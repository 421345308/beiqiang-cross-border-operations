## 1. 不变目标

1. 让正确的买家通过正确的搜索意图看到正确的 BQ 产品。
2. 让搜索卡中的标题、首图、价格/MOQ展示和产品事实彼此一致，提高点击意愿。
3. 让点击后的前 3 图、详情首屏、产品亮点和询盘钩子回答采购问题，提高有效询盘率。
4. 保留并强化已经有效的资产，不因为一次建议、一个热词或一周波动破坏已有流量。
5. 所有优化必须回到真实 SKU、真实颜色、真实结构和平台规则，不能靠虚假订单、虚假评价、侵权词或无法兑现的承诺。

## 3. 证据层级与防止过拟合

运营判断按以下优先级形成：

1. 当前店铺同口径数据：曝光、点击、CTR、访客、TM、询盘、订单及来源词。
2. 当前平台规则、类目字段、选词参谋、产品参谋和公开页实际展示。
3. 同类高销量/高质量同行的商品卡、标题、图组和采购承接方式。
4. 多位国际站卖家或 B2B 运营者可重复验证的经验。
5. 贝强历史执行结果和专业启发式判断。

任何一次建议、单一同行、单个热词或一周小样本不能单独改变全局策略。重大方向至少需要“店铺数据 + 平台信号”或“平台信号 + 多个同行样本”两类证据交叉支持。竞品可以提供表达方式，不能提供贝强产品事实。

## 4. 主动执行边界

### 默认主动推进，不重复询问

- 拉取和整理店铺、关键词、商品与公开页数据。
- 研究平台规则、热销同行和运营经验。
- 核验产品身份、图片、标题、关键词和流量来源。
- 制作标题/关键词方案、候选首图、联系表、提交载荷和回滚快照。
- 对已明确授权的 BQ 扩展链接执行标题、关键词和图片优化，并完成 API、审核态与公开页回读。
- 发现明显错词、错图、低相关流量或兄弟链接互相抢同一意图时，主动提出并排入任务队列。

### 只有以下情况需要负责人决策

- 新的价格、MOQ、交期、库存、样品费用、包装或运输承诺。
- 没有 SKU 证据的材料、功能、宽楦、认证或供货事实。
- 付费广告预算、充值、自动扣费或显著改变推广范围。
- 新增真实货源、外部采购、品牌/IP风险或下架/删除商品。
- 不可恢复或会影响客户、订单、账户权限的操作。

## 5. 持续工作状态机

每条扩展链接必须按顺序进入以下状态，状态写入 `任务队列.csv`：

`QUEUED → SOURCE_VERIFIED → BASELINE_CAPTURED → INTENT_ASSIGNED → COPY_READY → IMAGE_READY → VISUAL_QA_PASS → PAYLOAD_READY → SUBMITTED → AUDIT_PASS → PUBLIC_QA_PASS → MONITORING → REVIEWED`

任一事实、资产、平台或经营类目阻断分别标记：`HOLD_SOURCE`、`HOLD_FACTS`、`HOLD_ASSETS`、`HOLD_PLATFORM`、`HOLD_CATEGORY_SCOPE`。阻断只暂停该链接，不让整项长期任务失去目标；继续处理下一条无阻断任务。

## 6. 每次恢复工作时的固定入口

1. 读取本文件、`任务队列.csv`、`执行日志.md` 最后一节。
2. 读取 `00_总控台/当前状态.md` 和商品全生命周期 SOP 的当前版本。
3. 读取当周数据；若数据不可用，优先做不依赖当周数据的事实核验、图像准备和草稿工作。
4. 选择最高优先级且未阻断的下一条任务。
5. 执行后写回状态、证据路径、平台回执和下一动作。
6. 不以“已提交”作为完成；公开页与关键字段验收通过后才进入监测。

## 7. 短期、中期、长期节奏

### 短期：0–14 天

- 完成批次 A 的 24 条扩展链接当前态回读和搜索意图重分配。
- BQ009 源链接只读保护；先优化其 R1/W1/O1 三条扩展链接。
- 为每条链接形成标题、3–5 个关键词、M1–M3 图组和可回滚快照。
- 每个候选首图必须通过实物锚定、缩略图、同款联系表和六图联系表复核。

### 中期：15–60 天

- 按链接、款号族、关键词簇复盘曝光、CTR、访问和有效询盘。
- 强化产生相关流量和询盘的入口；重做低相关曝光或持续无点击的扩展链接。
- 将 BQ 其余多链接款号按系带运动、套脚休闲、宽鞋头、厚底/大码、低帮等真实结构重新聚类。
- 把有效词组和视觉结构沉淀为“适用条件明确”的模板，不形成全店一刀切模板。

### 长期：60–180 天及以后

- 建立按买家意图、季节、地区和采购角色更新的关键词库。
- 将自然流量、P4P、RFQ、询盘质量和成交反馈联动，判断真正有商业价值的词和产品。
- 对赢家链接增加橱窗、内容、视频和小预算推广，对弱链接继续优化或暂停推广，但不无依据删除。
- 每季度复查平台规则、类目变化、同行新品和 BQ 货源/素材变化，更新策略而不偏离北极星目标。

## 8. 核心指标

| 层级 | 指标 | 用途 |
| --- | --- | --- |
| 覆盖 | 相关搜索曝光、有效关键词数 | 判断是否进入正确流量池 |
| 点击 | 搜索点击、CTR、商品卡访问 | 判断标题和首图是否匹配意图 |
| 承接 | 访问人数、TM、收藏、停留/互动 | 判断前 3 图与页面是否继续说服 |
| 转化 | 询盘人数、有效询盘率、样品/报价推进 | 判断是否带来真实采购机会 |
| 商业 | 样品、订单、复购、毛利和履约质量 | 判断长期价值，不用虚假低价换表面流量 |

质量分 5.0、链接数量和图片 URL 数量只是基础状态，不是成功指标。

## 10. 不间断运营闭环

长期任务按“数据发现 → 家族诊断 → 整组优化 → 审核验收 → 7/14/30 天复盘 → 下一家族”的闭环滚动，不以单次批次结束为终点。

- 每日：轮询 `SUBMITTED` 与异常链接；审核通过即做公开页标题、首图、颜色、尺码、型号、价格单位和图组像素验收。平台无变化时不重复提交。
- 每周：拉取产品曝光、点击、CTR、访客、询盘及来源词；按款号族比较源链接与 W1/R1/O1 的流量来源是否互补，识别低相关曝光、首图同质化和买家意图重叠。
- 每批：允许对同一弱链接同步优化标题表达、首图颜色/构图和关键词簇，追求完整商品卡升级；但保持价格、MOQ、详情与产品事实稳定，避免把商业条件变化混入内容优化。
- 每 7 天：检查审核、收录、新增相关词和异常曝光；样本不足只记录，不因单周偶然值推翻策略。
- 每 14 天：评价搜索 CTR、有效访问和不同颜色/构图的相对表现；赢家表达进入“适用条件模板”，失败项回到真实买家意图重新设计。
- 每 30 天：以有效询盘、买家国家、报价/样品推进和订单质量决定是否强化橱窗、P4P、RFQ 与内容联动；只带来无关点击的词降级。
- 每季度：复查平台规则、类目 Schema、同行高销量页面结构、买家用词及贝强新增原始素材，更新方法论但不改变北极星目标。
