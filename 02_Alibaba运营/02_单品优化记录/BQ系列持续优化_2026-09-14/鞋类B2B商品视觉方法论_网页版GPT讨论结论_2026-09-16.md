# 鞋类 B2B 商品视觉方法论

来源：2026-09-16 与网页版 ChatGPT 的专项讨论，经贝强现有事实边界复核后整理。

原对话：<https://chatgpt.com/c/6aaa417c-d798-83e9-9c3f-e693516451e4>

## 1. 核心原则

商品视觉不是“把鞋做漂亮，再补一张 OEM 海报和几张工厂照”。正确逻辑是：

> 买家产生问题 → 用真实证据回答 → 降低采购风险 → 引导进入下一步询盘。

图库负责快速建立理解和信任；详情页负责完整解释和证明；询盘负责处理 MOQ、价格、交期、打样、付款及物流等动态条件。三者不能混为一体。

所有内容划分三个证据等级：

- `VERIFIED`：有真实产品、企业资料或负责人确认，可以发布。
- `CONDITIONAL`：存在订单条件，只能条件化表达或留到详情/询盘。
- `UNKNOWN`：尚未确认，不得进入正式视觉，也不得让 AI 推测。

## 2. 六张图库的决策漏斗

### M1 白底搜索首图：找到我

- 回答：这是不是买家正在寻找的产品？
- 内容：同一 SKU 的真实鞋体、白底、完整、大主体、易识别三分之四角度。
- 不承担：OEM、参数、工厂、功能、认证。
- AI仅可：抠图、白底、去污、曝光、白平衡、清晰度、自然阴影、轻微透视和构图。

### M2 真实多角度：看懂我

- 回答：这双鞋到底长什么样？
- 原则：同一款、同一颜色、同一真实实物。
- 可选择真实侧面、内外侧、后跟、俯视；不强制凑满角度。
- 宁缺勿假：缺少真实角度就减少展示或补拍，不从单张照片生成未知角度冒充实拍。

### M3 结构与细节：相信产品

- 回答：具体做工和结构是什么？
- 可展示：真实针织纹理、鞋口、鞋头、缝线、后跟、鞋带、中底侧墙、标签、真实鞋底等。
- 不把客观结构升级成未经证明的性能承诺；`Anti-slip`、`Shock absorption`、`Orthopedic`、`Arch Support` 等不能仅凭图片推断。
- 鞋底纹路、鞋内部、鞋垫结构、隐藏缝线和未拍摄区域绝不能由 AI 猜测。

### M4 To B采购入口：知道怎么采购

- 回答：如果买家要采购，需要提供什么？
- 推荐表达：`OEM / ODM / Wholesale`（仅限已确认能力）以及准确报价所需的 `Quantity / Size Range / Color Requirement / Logo Requirement / Packaging Requirement / Destination / Trade Term`。
- 可以补充买家输入项：参考样、目标市场、材料要求；这些是买家需提供的信息，不等于工厂已经承诺全部可定制。
- MOQ、样品天数、大货周期、产能、免费样品、认证等未经当前商品确认，不固定写进图片。

### M5 颜色体系：判断SKU空间

- 回答：同一个鞋型有哪些真实颜色？
- 所有颜色必须使用同一角度，并先核对鞋楦、鞋底、鞋头、鞋口、后跟、针织分区、鞋带、中底厚度和比例。
- 明显不同的颜色图直接排除或拆成不同款式，不能放进同一个 `Available Colors`。
- 真实已有颜色与可开发的 Pantone/custom color 要分开表达；不能用 AI 生成大量不存在的“现有颜色”。

### M6 供应商证明快照：相信供应商

- 回答：这个供应商是否值得进一步询盘？
- 从真实资料选择 3–4 个证明点：企业/厂房身份、真实生产环节、真实质量检查、真实包装交付。
- 不用十几张小图堆砌“实力”，不因原图存在就强行使用。
- AI仅可改善曝光、清晰度、透视、裁切、排版和轻度杂乱；不得增加设备、人员、流水线、库存、厂房面积、包装数量或不存在的生产行为。

完整路径：`找到我 → 看懂我 → 相信产品 → 知道怎么采购 → 判断SKU空间 → 相信供应商`。

## 3. 详情页顺序

1. 产品快速识别：产品名称、主图及已确认分类信息。
2. 产品多角度证明：比图库更完整的真实角度，有素材才展示。
3. 产品结构与细节：照片对应客观说明，不先写营销词再找图硬套。
4. 已确认规格：Upper、Lining、Insole、Outsole、Closure、Size、Weight、Packaging；未知项不填行业默认值。
5. 颜色与尺码：真实颜色和定制颜色分开；尺码、脚长、内长和公差来自真实资料。
6. OEM/ODM服务：Logo、Color、Material、Insole、Outsole、Packaging、Label、Hangtag、Carton逐项确认后再展示。
7. 开发与询价流程：只使用符合贝强真实业务的步骤。
8. 工厂身份与供应商证明：回答我们是谁、在哪里生产、公司与工厂是什么关系。
9. 质量控制：实际有什么检查就展示什么，不虚构 AQL、ISO、100% Inspection 或标准化体系。
10. 包装与交付：真实鞋盒、标签、外箱、装箱、仓储和装柜证据。
11. FAQ：处理定制、样品、MOQ、Logo文件、包装和报价输入，动态信息条件化表达。
12. 询盘 CTA：明确买家为获得准确报价需要提交什么。

## 4. 工厂实力必须“需求倒推”

| 买家疑虑 | 要证明什么 | 需要寻找或补拍的真实素材 |
| --- | --- | --- |
| 是否真实供应商 | 企业和生产场所身份 | 门头、厂区、车间、主体对应资料 |
| 能否开发我的款 | 产品开发能力 | 真实打样、材料、版型和样品过程 |
| 能否稳定生产 | 生产组织 | 真实工序、工位和订单组织 |
| 大货会不会失控 | QC流程 | 真实检查动作、记录和检查位置 |
| Logo如何执行 | 定制执行能力 | 已完成Logo样品与真实工艺过程 |
| 包装能否适配 | 包装能力 | 鞋盒、标签、外箱和包装工位 |
| 出货是否规范 | 交付管理 | 成品仓、装箱、装柜资料 |
| 认证是否真实 | 合规证明 | 可核验的证书或测试报告 |

没有合适素材时的顺序是：补拍 → 不展示 → 留到询盘确认。不能由 AI 制造证据。

## 5. AI定位与红线

AI只能是 `Visual Enhancement Tool`，不能成为 `Evidence Creation Tool`。

允许：抠图、白底、清理背景、提升分辨率、去噪、曝光、白平衡、锐度、污点清理、排版、统一画布、自然阴影和不改变事实的轻微环境整理。

禁止补造：

- 产品：鞋底纹路、底面结构、鞋底厚度/材料层次、鞋垫、内部结构、未拍摄后跟、针织纹理、拼接、缝线、标签、尺码标、未知颜色和材料。
- 工厂：设备、工人、生产线、库存、厂房结构与面积、实验室、检测仪器、仓库规模和生产繁忙程度。
- 企业数据：MOQ、样品周期、交期、产能、认证、成立年份、出口国家、合作品牌、月产量和客户数量。

每张正式图必须回答：图中每个事实可以回溯到哪一张原图、哪一份资料或哪一次负责人确认？回答不了就不发布。

## 6. 此前失败的根因

1. 从现有素材出发，而不是从买家问题出发。
2. 把视觉丰富误认为信息丰富。
3. 没有做 SKU 身份校验，只因“看起来像”就当成同款。
4. 混淆颜色图和角度图的职责。
5. 把 AI 当成事实补全工具。
6. 没有区分 VERIFIED、CONDITIONAL 和 UNKNOWN。
7. 缺少产品真实性、业务信息和视觉质量三方验收。

## 7. 下一步

在重新出图前，先完成 BQ019/A206 的 `SKU真实性审计 + 素材缺口清单`：

- 哪些照片确定属于同一鞋型、同一颜色；
- 当前真实具备哪些角度和细节；
- 哪些颜色能进入同款颜色合集；
- 哪些 To B 能力已确认，哪些需要负责人确认；
- 工厂图分别可以证明什么，缺少什么应补拍；
- 每张计划图对应哪份来源证据。

审计完成前不再继续生成正式商品图。
