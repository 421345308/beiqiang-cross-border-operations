## 一、执行命令与参数

### 使用的命令

```
workctl icbu other product-edit-draft-basic-info --json-file <params.json> --format json
workctl icbu other submit-draft --json-file <params.json> --yes --format json
```

### 字段映射

| 目标字段 | Schema字段名 | 写入格式 |
|:---|:---|:---|
| 标题 | `productTitle` | 纯文本字符串 |
| 关键词 | `productKeywords` | 空格分隔短语（平台不接受逗号） |

### 注意事项

- `submit-draft` 为敏感操作，需显式 `--yes` 确认
- `productKeywords` 平台校验非法字符：逗号 `,` 被拒绝，改用空格分隔
- `product-edit-draft-basic-info` 仅修改 title/keywords/attr/images，本次未传入 attr/images 参数，其他字段未被触及
